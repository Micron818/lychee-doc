# 速查：采购管理（SCM）

> 版本：2026-08-28 | 语言：zh | vi 同步：待同步

## 入口（界面菜单）

| 菜单路径 | 训练深度 |
|----------|----------|
| `采购管理 → 供应商管理` | PB-01 / PB-06 |
| `采购管理 → 物料供应商` | PB-01 / PB-03 |
| `采购管理 → 采购申请(PR)` | PB-03（仅内部请购） |
| `采购管理 → 采购订单(PO)` | PB-03 / PB-06（三页签：采购单 / MRP 待转 / 请购待转） |
| `采购管理 → 委外加工订单(OSO)` | PB-08 |

## 典型动作

原物料：`采购订单(PO)`「MRP 待转」→ 生成草稿 → 「采购单」审核 →（打印/PDF）→ 等待 GR。  
内部请购：PR 审核 → 「请购待转」生成 PO。  
无来源：列表「新增」手工单后手键明细。  
OSO → 发料/收货协同仓储。

## 禁忌

- 原物料不要先转采购申请；MRP 结果页没有「转采购申请」。  
- 「新增」只能出手工单；MRP / 请购类型 PO 不能手键新增行。  
- 「从采购申请导入」仅出现在来源类型为「采购申请」的草稿上。  
- 不打算下的草稿请删除，否则占用下一轮 MRP。  
- 草稿 PO 勿外发给供应商。  
- 导出需 `export` 权限。  
- 界面缩写为 **OSO**（非 OO）。  
详见 [PB-03](../03-process-playbooks/PB-03-procure-to-pay.md)、[PB-06](../03-process-playbooks/PB-06-export-and-print.md)、[PB-08](../03-process-playbooks/PB-08-outsource-loop.md)。
