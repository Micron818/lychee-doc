# 速查：报表中心（REPORT）

> 版本：2026-08-01 | 语言：zh | vi 同步：待同步

## 入口

导出中心（`报表中心 → 导出中心`）。

## 典型动作

查看本人导出作业状态 → 下载 →（可选）删除历史作业。  
业务页上的「导出」「下载 PDF」是作业的发起点。

## 禁忌

- 下载链接有时效，过期回中心重取。  
- 勿转发签名 URL。  
详见 [导出中心](../01-getting-started/02-export-center.md)、[PB-06](../03-process-playbooks/PB-06-export-and-print.md)。
