# 菜单与权限开通

> 受众：系统管理员 | 模块：ADM | 版本：2026-08-08  
> 预计时长：30 分钟 | 语言：zh | 状态：草稿 | vi 同步：待同步

## 1. 业务目标

按岗位角色完成菜单可见性与动作权限配置，使业务用户能按训练手册操作。

## 2. 前置条件

- 使用具备系统管理权限的账号。
- 已明确角色清单（见总纲角色矩阵）。
- 新功能路由与 locale 已随版本发布（例如导出中心）。

## 3. 操作步骤

1. **菜单**
   - 进入 `系统管理 → 菜单管理`。
   - 确认一级模块与子菜单路径正确（示例：`/report/export-jobs` →「报表中心 → 导出中心」；`/report/import-jobs` →「报表中心 → 导入中心」）。
   - 缺失时新增菜单：填写名称、路径、排序、父级；locale key 与前端语言包约定一致（如 `menu.report.exportJobs`、`menu.report.importJobs`）。
   - 功能清单可对照 `menus_20260808`；**界面显示名以系统当前语言界面为准**。
2. **权限定义**  
   - 进入 `系统管理 → 权限管理`（或角色内权限配置，以界面为准）。  
   - 为菜单配置动作：至少 `read`；按需 `create` / `update` / `delete` / `export` 等。  
3. **角色**  
   - `系统管理 → 角色管理`：为每个岗位角色勾选菜单与动作。  
4. **用户**  
   - `系统管理 → 用户管理`：为训练用户分配角色。  
5. **验证**  
   - 使用业务测试账号**重新登录**，逐项确认菜单与按钮。  

## 4. 状态与权限说明

| 层级 | 作用 |
|------|------|
| 菜单未挂 | 用户完全看不到入口 |
| 有菜单无 read | 可能无法打开或列表报错 |
| 无 export | 不显示导出/部分 PDF 下载入口 |
| 改权限未重登 | 客户端仍用旧权限缓存——先重登再排障 |

## 5. 验收标准

- [ ] 角色矩阵中每个角色有对应测试用户  
- [ ] 采购测试用户可见供应商导出与 PO 打印/PDF  
- [ ] 无权限用户无法进入系统管理  

## 6. FAQ / 禁忌

- 生产环境权限变更建议工单化，避免口头临时加权。  
- 不要把菜单「对全体可见」当作偷懒方案。  

## 7. 练习题

故意去掉某角色的 `export`，用该角色登录确认按钮消失，再恢复权限验证重登后出现。
