# 导出功能上线检查清单

> 受众：系统管理员 / 实施 | 模块：REPORT / SCM / 基础设施 | 版本：2026-08-01  
> 预计时长：20 分钟 | 语言：zh | 状态：草稿 | vi 同步：待同步

## 1. 业务目标

确保「供应商 Excel 导出」「采购订单 PDF」「导出中心」在训练或生产环境可用，避免用户按手册操作却找不到按钮或下载失败。

## 2. 前置条件

- 对应版本前后端已部署。
- 可登录管理账号与采购测试账号。

## 3. 操作步骤（检查清单）

### A. 菜单与权限（运行时配置）

- [ ] 新增或确认菜单：`报表中心 → 导出中心`，路径 `/report/export-jobs`，locale `menu.report.exportJobs`（父级 `menu.report`）  
- [ ] 导出中心权限：至少 `read`；若提供删除则配置 `delete` 并仅授予合适角色  
- [ ] `/scm/suppliers` 菜单追加 `export` 动作并授予采购（及需要的）角色  
- [ ] `/scm/purchase-orders` 菜单追加 `export` 动作并授予采购（及需要的）角色  
- [ ] 用采购测试账号重登，确认：供应商「导出」、PO「下载 PDF」、导出中心入口可见  

### B. 功能冒烟

- [ ] 供应商列表筛选后导出，能得到 Excel  
- [ ] 非草稿 PO：打印视图可打开；PDF 可下载（直下或导出中心）  
- [ ] 草稿 PO：打印/PDF 带草稿水印  
- [ ] 人为制造或等待一笔异步作业（若环境易触发），在导出中心看到成功并可下载  

### C. 基础设施（上线环境；训练环境按实际）

- [ ] 对象存储（OSS）已可上传导出文件  
- [ ] 建议：为导出前缀（如 `*/exports/`）配置生命周期（例如 30 天），与系统保留天数配置对齐  
- [ ] 下载签名链路可用（过期后可自中心重新获取）  

## 4. 状态与权限说明

本清单不替代 [菜单与权限开通](./01-menu-and-permission.md)；权限问题优先按该文档排障。

## 5. 验收标准

- [ ] A/B 两项在目标环境全部勾选完成  
- [ ] 采购角色可独立完成 [PB-06](../03-process-playbooks/PB-06-export-and-print.md)  

## 6. FAQ / 禁忌

- 仅发版不配菜单：用户会认为「功能没上线」。  
- 生命周期过短可能导致用户第二天无法从中心下载——保留天数需与业务沟通。
