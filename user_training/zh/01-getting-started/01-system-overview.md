# 系统入门

> 受众：全体用户 | 模块：通用 | 版本：2026-08-01  
> 预计时长：20 分钟 | 语言：zh | 状态：草稿 | vi 同步：待同步

## 1. 业务目标

完成登录、认识主界面与菜单结构，并能切换语言、进入账户中心。为后续模块训练做准备。

建议配套阅读：[OV-01 系统整体流程地图](../00-overview/01-system-process-map.md)（建立跨模块全景后再进角色与剧本）。

## 2. 前置条件

- 已获得训练环境账号与初始密码（或 SSO 入口）。
- 管理员已为账号分配角色与菜单权限。
- 浏览器建议使用 Chrome 或 Edge 最新稳定版。

## 3. 操作步骤

1. 打开训练环境网址，按提示完成登录（含企业认证回调，若适用）。
2. 登录成功后确认：左侧（或顶部）出现业务菜单；右上角可进入账户相关操作。
3. 对照岗位核对可见菜单是否包含本角色所需模块（见总纲「角色矩阵」）。
4. 进入任一列表页，熟悉通用操作：
   - 查询 / 筛选后刷新列表
   - 新建、编辑（抽屉或表单）
   - 行内操作（查看、提交、审核等，视单据而定）
5. 退出：通过账户菜单「退出登录」安全退出，勿直接关浏览器代替登出（共享电脑时尤其重要）。

## 4. 状态与权限说明

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| 登录成功但几乎无菜单 | 未分配角色或菜单权限 | 联系系统管理员 |
| 看得到菜单但按钮灰掉 / 不显示 | 缺少对应动作权限（如导出、删除） | 见 [菜单与权限开通](../05-admin-ops/01-menu-and-permission.md) |
| 提示无权限 | 角色未授权该路径动作 | 管理员调整角色权限后重新登录 |

## 5. 验收标准

- [ ] 能独立登录与退出  
- [ ] 能说出本岗位日常会用到的 2～3 个一级菜单  
- [ ] 能在任意列表完成一次筛选查询  

## 6. FAQ / 禁忌

- 勿在生产环境用训练账号做真实业务单据（除非实施明确要求）。
- 勿截图外传含真实客户 / 供应商联系方式的画面。
- 多人共用训练租户时，先约定示例单号前缀，避免互相改单。

## 7. 练习题

1. 登录后找到「报表中心 → 导出中心」是否可见；若不可见，记录现象交给管理员。  
2. 在「基础资料」或本岗位主数据菜单打开任一列表，用编码或名称筛选出一条记录。
