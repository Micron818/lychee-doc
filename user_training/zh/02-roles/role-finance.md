# 角色手册：财务

## 1. 业务目标

维护财务主数据与期间；处理应收应付、收付款与凭证；执行成本结算与固定资产相关作业；与仓储协同关账。

## 2. 前置条件

- 总账科目、业务伙伴、评估类/科目确定、成本策略等主数据已由实施初始化。
- 会计期间已开启对应年月。

## 3. 日常工作清单

1. **主数据**：总账科目、业务伙伴、公司/伙伴银行账户、评估与科目确定、成本策略等。  
2. **应收应付**：AR/AP 发票的录入、审核、过账。  
3. **收付款**：按「先资金后核销」等公司流程处理收付款单。  
4. **日记账**：手工凭证与过账、冲销。  
5. **成本**：成本分摊、成本结算（Cost Run）定稿与过账；作废须由财务执行。  
6. **固定资产**：资产建档、资本化、折旧、处置（按授权）。  
7. **关账**：会计期间结账；配合仓储库存期末——**存在活跃成本结算时仓储无法重开库存期**。  

跟练：[PB-03](../03-process-playbooks/PB-03-procure-to-pay.md)（AP 段）、[PB-05](../03-process-playbooks/PB-05-period-close.md)。

## 4. 状态与权限说明

| 对象 | 用户需记住的点 |
|------|----------------|
| 发票 / 收付款 / 凭证 | 多遵循草稿 → 审核 → 过账；作废/冲销有前置条件 |
| 成本结算 | 定稿、过账、作废权限分离；作废影响仓储重开 |
| GR/IR 余额 | 收货与发票暂估差异分析入口 |

## 5. 验收标准

- [ ] 能完成一张训练 AP 从录入到过账（或教员指定的最简路径）  
- [ ] 能说明库存期末与成本结算的互锁关系  
- [ ] 知道作废成本结算的入口与责任人是财务  

## 6. FAQ / 禁忌

- 勿在仍有活跃成本结算时要求仓储强行重开期间。  
- 过账后更正优先走冲销/贷项，勿篡改历史凭证。  

## 7. 练习题

阅读 PB-05，与仓储角色互问互答「谁先关、谁先作废」。
