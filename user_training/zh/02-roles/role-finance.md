## 1. 业务目标

维护财务主数据与期间；处理应收应付、收付款与凭证；执行成本结算与固定资产相关作业；与仓储协同关账；按需使用导入中心批量维护标准成本等数据。

## 2. 前置条件

- 总账科目、业务伙伴、评估类/科目确定、成本核算策略等主数据已由实施初始化。
- 会计期间已开启对应年月。

## 3. 日常工作清单

1. **主数据**：`财务会计 → 主数据` 下总账科目、业务伙伴、公司/伙伴银行账户。  
2. **评估与科目**：`物料评估与科目确定`（实施期维护；日常故障排查）。  
3. **应收应付**：应收发票、应付发票的录入、审核、过账；`GR/IR 余额分析` 按需。  
4. **收付款**：按公司流程处理收付款单并核销。  
5. **日记账**：手工凭证与过账、冲销。  
6. **成本核算**：成本分摊、**成本结算**完成与过账；作废须由财务执行；`物料成本` / `物料采购成本分析` 按需。  
7. **导入**：批量维护标准成本等 → [PB-07](../03-process-playbooks/PB-07-import-center.md)。  
8. **固定资产**：资产类别、固定资产、资产折旧（按授权）。  
9. **关账**：会计期间结账；配合仓储库存期末——**存在活跃成本结算时仓储无法重开库存期**。  

跟练：[PB-03](../03-process-playbooks/PB-03-procure-to-pay.md)（AP 段）、[PB-05](../03-process-playbooks/PB-05-period-close.md)、[PB-07](../03-process-playbooks/PB-07-import-center.md)、[PB-10](../03-process-playbooks/PB-10-order-to-cash.md)。

## 4. 状态与权限说明

| 对象 | 用户需记住的点 |
|------|----------------|
| 发票 / 收付款 / 凭证 | 多遵循草稿 → 审核 → 过账；作废/冲销有前置条件 |
| 成本结算 | 完成、过账、作废权限分离；作废影响仓储重开 |
| GR/IR 余额 | 收货与发票暂估差异分析入口 |
| 导入中心 | 与业务页导入按钮配合；看成功/失败行与错误报告 |

## 5. 验收标准

- [ ] 能完成一张训练 AP 从录入到过账（或教员指定的最简路径）  
- [ ] 能说明库存期末与成本结算的互锁关系  
- [ ] 知道作废成本结算的入口与责任人是财务  
- [ ] （增量）能完成 PB-07 或 PB-10 之一  

## 6. FAQ / 禁忌

- 勿在仍有活跃成本结算时要求仓储强行重开期间。  
- 过账后更正优先走冲销/贷项，勿篡改历史凭证。  

## 7. 练习题

阅读 PB-05，与仓储角色互问互答「谁先关、谁先作废」。
