# 角色手册：销售

> 受众：销售 | 模块：SD | 版本：2026-08-01  
> 预计时长：35 分钟 | 语言：zh | 状态：草稿 | vi 同步：待同步

## 1. 业务目标

维护客户，录入并推进销售订单（SO），协同仓储完成交货单（DN）。

## 2. 前置条件

- 客户、物料、工厂等主数据可用。
- 角色具备 SO / DN 读写及必要审核权限。

## 3. 日常工作清单

1. 维护或确认 `销售管理 → 客户资料`。
2. 创建 / 修改 `销售订单(SO)`，维护明细交期与数量。
3. 按公司流程提交、审核 SO。
4. 在可交货状态下创建或跟进 `交货单(DN)`，与仓储确认出货。
5. 关注订单未交数量与异常关闭。

跟练剧本：[PB-02 销售出货](../03-process-playbooks/PB-02-sales-to-delivery.md)。

## 4. 状态与权限说明

以界面状态为准，典型链路：草稿 → 提交/审核 → 可交货相关状态 → 关闭。  
具体按钮是否可见取决于单据状态与角色动作权限。

## 5. 验收标准

- [ ] 能独立创建一张训练 SO 并推进到可交货  
- [ ] 能关联生成或打开 DN 并理解与仓储的交接点  

## 6. FAQ / 禁忌

- 未确认库存与计划前，勿对客户承诺不可达交期（业务纪律）。  
- 已审核单据的改单须按公司变更流程，勿强行删单。  

## 7. 练习题

用 PB-01 产出的客户与物料跑通 PB-02。
