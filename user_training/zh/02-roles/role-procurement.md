# 角色手册：采购

> 受众：采购 | 模块：SCM | 版本：2026-08-01  
> 预计时长：40 分钟 | 语言：zh | 状态：草稿 | vi 同步：待同步

## 1. 业务目标

处理采购申请（PR）、采购订单（PO）、委外加工订单（OSO）；完成打印/PDF 与供应商清单导出；与仓储收货、财务应付衔接。

## 2. 前置条件

- 供应商、物料、工厂主数据可用。
- 具备 PR/PO（及 OSO，若岗位需要）权限；导出/打印相关权限已开通。

## 3. 日常工作清单

1. 维护 `供应商管理`；需要时导出供应商清单。  
2. 处理 `采购申请(PR)`：创建、审核、转单。  
3. 维护 `采购订单(PO)`：价格、交期、数量；提交与审核。  
4. 打印 PO 或下载 PDF 发给供应商。  
5. 跟进收货进度（协同仓储 GR）；异常交期与数量变更。  
6. 委外场景维护 `委外加工订单(OSO)`（发料/收货协同仓储与生产）。  

跟练：[PB-03](../03-process-playbooks/PB-03-procure-to-pay.md)、[PB-06](../03-process-playbooks/PB-06-export-and-print.md)。

## 4. 状态与权限说明

| 能力 | 依赖 |
|------|------|
| 列表「导出」 | 菜单 export 动作 |
| 「打印」/「下载 PDF」 | 读权限 + 导出权限（PDF） |
| 草稿水印 | 草稿单打印/PDF 会带草稿标识，勿直接外发 |

## 5. 验收标准

- [ ] 能完成 PR→PO 训练闭环至可收货  
- [ ] 能打印或下载一张已审核 PO  
- [ ] 知道异步导出时去「导出中心」取文件  

## 6. FAQ / 禁忌

- 勿将带草稿水印的文件发给供应商。  
- 大批量导出前先筛选，避免超时或失败。  

## 7. 练习题

完成 PB-03 至 GR 前的采购段，并执行 PB-06 的打印与 PDF 各一次。
