# 角色手册：生产计划

## 1. 业务目标

维护 BOM 与 MRP 参数，运行 MRP，将计划转化为生产执行（PLO→MO），并处理产量回馈（MOR）与倒扣料异常。

## 2. 前置条件

- 物料、工厂物料、BOM、需求来源（如 FO/SO 相关计划）已就绪。
- 理解本公司是「倒扣料」还是「按单发料」为主。

## 3. 日常工作清单

1. 维护 `BOM 管理`。  
2. 维护 `工厂订单(FO)`（若流程需要从销售汇总到工厂）。  
3. 检查 `MRP 参数`，执行 `物料需求计划(MRP)`。  
4. 处理 `计划工单(PLO)` → 转为 `生产工单(MO)`。  
5. 录入或审核 `工单产量回馈(MOR)`。  
6. 监控 `倒扣料异常处理`，协同仓储补料/豁免。  

跟练：[PB-04 计划到生产回馈](../03-process-playbooks/PB-04-mrp-to-production.md)。  
委外协同见 [PB-08](../03-process-playbooks/PB-08-outsource-loop.md)（采购主责，计划旁听）。

## 4. 状态与权限说明

状态名称以界面为准。关键纪律：

- MRP 结果需人工确认后再转工单，勿盲目全量转换。  
- 工单结案前处理完倒扣料异常（除非流程允许豁免）。  

## 5. 验收标准

- [ ] 能维护一笔训练 BOM  
- [ ] 能跑通一次 MRP 并看到计划供应建议  
- [ ] 能将计划落到 MO 并完成一笔 MOR（训练数据）  

## 6. FAQ / 禁忌

- 参数错误会导致计划爆炸或短缺误报：改参数后先在训练环境验证。  
- 倒扣料异常未处理可能导致库存与工单不一致。  

## 7. 练习题

按教员给定的成品物料完成 PB-04；记录 MRP 运行编号与生成的 PLO/MO 单号。
