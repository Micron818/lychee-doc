# 角色手册：主数据维护

> 预计时长：40 分钟 | 语言：zh | 状态：草稿 | vi 同步：待同步

## 1. 业务目标

保证公司、工厂、物料、客户、供应商等主数据完整、可用，使销售、采购、生产、仓储单据可以正确引用。

## 2. 前置条件

- 组织架构（公司 / 工厂 / 部门）已由实施或管理员初始化框架。
- 已明确物料编码、客户/供应商编码规则。

## 3. 日常工作清单

1. **组织**：维护 `基础资料 → 公司管理` / `工厂管理` / `部门管理`。  
2. **物料基础**：`物料类别`、`物料分类(分层)`、`物料单位`、`物料颜色`、`产品尺寸`、`产品型号` 等辅助资料。  
3. **物料资料**与**工厂物料**：建立物料并分配到工厂、维护计划/仓储相关属性。  
4. **单位转换**：`标准单位转换`与`物料单位转换`按需维护。  
5. **客户 / 供应商**：`销售管理 → 客户资料`、`采购管理 → 供应商管理`。  
6. **批量导入**：若财务/实施开放导入类型，配合 [导入中心](../01-getting-started/03-import-center.md) 在训练环境先验证。  
7. **变更**：停用前确认无未结单据依赖；编码一经启用勿随意复用。  

跟练剧本：[PB-01 主数据就绪](../03-process-playbooks/PB-01-master-data-ready.md)；可选 [PB-07](../03-process-playbooks/PB-07-import-center.md)。

## 4. 状态与权限说明

| 对象 | 注意点 |
|------|--------|
| 物料未分配工厂 | 后续 FO / 库存 / MRP 可能无法选用 |
| 客户/供应商停用 | 新建单据通常不可再引用 |
| 单位缺失转换 | 采购/库存单位不一致时会阻碍过账或计算 |

## 5. 验收标准

- [ ] 能新建一条训练用物料并分配到指定工厂  
- [ ] 能新建客户与供应商各一笔且状态可用  
- [ ] 销售/采购同事能在单据中选到上述主数据  

## 6. FAQ / 禁忌

- 勿在未沟通的情况下修改已用于未结订单的关键计量单位。  
- 批量导入须先在训练环境验证，并使用官方模板。  

## 7. 练习题

完成 PB-01 全部分步，并把产生的编码记入课堂练习表供后续剧本引用。
