## 1. 业务目标

完成收货、领料、调拨、盘点与库存查询；在期间末配合财务完成库存结账，并遵守关账禁忌。

## 2. 前置条件

- 仓库主数据、物料与工厂物料已就绪。
- 上游单据（PO/OSO/DN/MO 等）状态允许出入库。
- 当前库存期间未错误关闭（训练环境按教员说明）。

## 3. 日常工作清单

1. 维护 `仓储管理 → 仓库管理`。  
2. `收货单(GR)`：按 PO/OSO 等来源收货过账。  
3. `库存领料(SI)` / `库存调拨(ST)`：生产发料、委外发料或仓间调拨。  
4. 查询 `库存现存量`、`库存流水`、`进耗存汇总表`。  
5. `库存盘点(PI)`：见 [PB-09](../03-process-playbooks/PB-09-physical-inventory.md)。  
6. `库存期末结账`：关账前确认单据与盘点已处理；**重开期间前须确认财务侧无活跃成本结算**。  

跟练：[PB-03](../03-process-playbooks/PB-03-procure-to-pay.md)、[PB-05](../03-process-playbooks/PB-05-period-close.md)、[PB-08](../03-process-playbooks/PB-08-outsource-loop.md)、[PB-09](../03-process-playbooks/PB-09-physical-inventory.md)。

## 4. 状态与权限说明

| 场景 | 说明 |
|------|------|
| 期间已关闭 | 通常不可再过账该期库存异动 |
| 重开期间被拒 | 财务仍有活跃成本结算时系统拒绝；联系财务先作废 |
| 来源单不可收 | 检查 PO 是否「已核准」、未收数量是否仍大于 0 |

## 5. 验收标准

- [ ] 能根据训练 PO 完成一张 GR 并看到库存变化  
- [ ] 能说明库存期末结账与财务成本结算的先后禁忌  
- [ ] 能用现存量表核对一笔物料数量  
- [ ] 能完成一张训练 PI（PB-09） 

## 6. FAQ / 禁忌

- 关账后发现漏单：按公司流程申请重开，**不要**绕过系统补账。  
- 盘点未完成前勿强行关账。  

## 7. 练习题

与采购同学接力完成 PB-03 的 GR 段；再阅读 PB-05 禁忌表并口头复述。
