# PB-01 主数据就绪

> 受众：主数据维护 | 模块：BASIS / MM / SD / SCM | 版本：2026-08-01  
> 预计时长：40 分钟 | 语言：zh | 状态：草稿 | vi 同步：待同步

## 1. 业务目标

在训练环境准备一套可被后续剧本引用的最小主数据：公司/工厂、物料（含工厂物料）、客户、供应商。

## 2. 前置条件

- 管理员已创建训练用户并授予主数据相关菜单。
- 已知训练用编码前缀（例如 `T2608-`），避免与他人冲突。
- 公司与工厂若已由实施预置，可跳过新建、仅核对。

## 3. 操作步骤

1. **核对组织**  
   - 进入 `基础资料 → 公司管理` / `工厂管理`，确认训练用公司、工厂存在且可用。  
2. **准备物料辅助资料（按需）**  
   - `物料管理 → 物料类别 / 物料单位` 等，确保至少有可用类别与单位。  
3. **新建物料**  
   - `物料管理 → 物料资料` → 新建，填写编码、名称、基本单位等必填项并保存。  
4. **分配工厂物料**  
   - `物料管理 → 工厂物料` → 将物料分配到训练工厂，保存计划/仓储所需字段（以界面必填为准）。  
5. **新建客户**  
   - `销售管理 → 客户资料` → 新建并保存为可用状态。  
6. **新建供应商**  
   - `采购管理 → 供应商管理` → 新建并保存为可用状态。  
7. **登记练习表**  
   - 记录：公司、工厂、物料、客户、供应商编码，供 PB-02～PB-06 使用。

## 4. 状态与权限说明

| 检查项 | 期望 |
|--------|------|
| 物料可被单据选到 | 已存在且已分配工厂 |
| 客户/供应商可选 | 状态为启用/可用（以界面为准） |
| 无权限保存 | 联系管理员授予写权限 |

## 5. 验收标准

- [ ] 物料在销售订单、采购订单物料选择中可见  
- [ ] 客户可被 SO 引用；供应商可被 PO 引用  
- [ ] 编码已写入课堂练习表  

## 6. FAQ / 禁忌

- 不要删除他人正在使用的训练主数据。  
- 编码规则变更须全班同步，否则后续剧本对不上。  

## 7. 练习题

额外再建一笔「仅采购用」物料（若类别允许），说明与成品物料在后续流程中的差异。
