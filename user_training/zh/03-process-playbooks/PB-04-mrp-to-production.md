# PB-04 计划到生产回馈（BOM → FO → MRP → PLO → MO → MOR）

> 受众：生产计划（仓储协助） | 模块：PP / WM / SCM | 版本：2026-08-28  
> 预计时长：60 分钟 | 语言：zh | 状态：草稿 | vi 同步：待同步

## 1. 业务目标

理解从物料清单、需求，到 MRP 计划、生产工单与产量回馈的主路径；知道「建议采购」交给采购订单「MRP 待转」，以及倒扣料异常出现时去哪里处理。

## 2. 前置条件

- 成品与组件物料、工厂物料已就绪；组件建议有可用库存或教员允许的训练设定。
- 已维护或可新建一笔多层/单层 BOM。
- MRP 参数已由教员确认可用。

## 3. 操作步骤

1. **BOM**  
   - `生产计划 → BOM 管理`：为训练成品维护组件用量并保存/生效（以界面为准）。  
2. **需求入口（FO，若流程启用）**  
   - `生产计划 → 工厂订单(FO)`：建立或确认工厂侧需求。  
   - 若课堂改为「已有独立需求来源」，按教员指示跳过或替换本步。  
3. **MRP 参数**  
   - `生产计划 → MRP 参数`：核对工厂、范围、关键开关，勿随意改生产参数。  
4. **运行 MRP**  
   - `生产计划 → 物料需求计划(MRP)`：启动运行，等待完成，查看结果。  
5. **建议采购（交给采购，本剧本不下单）**  
   - 在运算结果过滤「建议采购」。确认有待买行后，点击「前往 MRP 转采购订单」（将打开采购订单「MRP 待转」）。  
   - 无采购订单新建权限时该按钮不可用。原物料**不再**「转采购申请」。下单步骤见 [PB-03](./PB-03-procure-to-pay.md)。  
6. **计划工单**  
   - 运算结果过滤「建议生产」，勾选后「转计划单」（与建议采购的跳转入口不同）。  
   - 再到 `生产计划 → 计划工单(PLO)`：挑选训练相关计划，执行为生产工单的转换。  
7. **生产工单**  
   - `生产计划 → 生产工单(MO)`：确认开工所需组件、仓库等字段。  
8. **产量回馈**  
   - `生产计划 → 工单产量回馈(MOR)`：录入完工数量并过账/确认。  
9. **异常**  
   - 若提示倒扣料失败：进入 `倒扣料异常处理`，按教员指引补处理或豁免。  

## 4. 状态与权限说明

| 节点 | 培训要点 |
|------|----------|
| MRP 运行中/失败 | 等待或查看失败原因，勿重复狂点 |
| 建议采购 | 点「前往 MRP 转采购订单」；不要在结果页下单，也不再转 PR |
| PLO → MO | 转换前确认数量与日期 |
| MOR 后库存 | 倒扣料模式会扣组件；异常须清零或豁免 |
| 工单结案 | 未清异常可能阻止结案（以防呆设计为准） |

## 5. 验收标准

- [ ] BOM 可被计划/工单使用  
- [ ] 一次 MRP 运行成功并产生可解释的计划输出  
- [ ] 能说明「建议生产」转计划单、「建议采购」跳转采购订单，二者入口不同  
- [ ] 至少一张 MO 与一笔 MOR 完成  
- [ ] 若出现倒扣料异常，学员知道处理入口  

## 6. FAQ / 禁忌

- 勿在他人运行的同一工厂参数上互相覆盖关键开关。  
- 生产环境改 BOM 生效策略须走工程变更纪律。  
- 草稿采购订单会占用下一轮 MRP 供给；重跑前请采购处理不打算下的草稿。  

## 7. 练习题

对比「组件库存充足」与「故意缺料」两次 MOR 的系统反应（第二次在教员指导下进行）。
