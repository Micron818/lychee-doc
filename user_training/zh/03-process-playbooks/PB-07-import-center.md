# PB-07 导入中心（模板 → 上传 → 跟踪 / 错误报告）

> 受众：财务（主数据可旁听） | 模块：RPT / FI | 版本：2026-08-08  
> 预计时长：30 分钟 | 语言：zh | 状态：草稿 | vi 同步：待同步

## 1. 业务目标

跑通一条训练环境可用的 Excel 导入闭环：下载模板 → 填写 → 上传 → 在导入中心确认结果；学会用错误报告纠错。当前首例以「物料标准成本」导入为主（以界面实际提供的导入类型为准）。

## 2. 前置条件

- 管理员已完成 [导入导出上线检查清单](../05-admin-ops/02-export-go-live-checklist.md) 中与导入相关的项。  
- 学员具备业务页导入权限与 `报表中心 → 导入中心` 读权限。  
- 训练公司、物料、会计期间已存在；建议使用教员指定的编码前缀。  
- 建议先读 [导入中心使用说明](../01-getting-started/03-import-center.md)。  

## 3. 操作步骤

### 3.1 准备模板数据

1. 进入 `财务会计 → 成本核算 → 物料成本`（或教员指定的导入入口）。  
2. 下载官方 Excel 模板。  
3. 填写至少 2 行有效数据、1 行故意错误数据（如不存在的物料编码），保存文件。  

### 3.2 执行导入

1. 点击「导入」，上传文件，确认选项后提交。  
2. 若同步完成：阅读成功/失败行数摘要。  
3. 若异步：打开 `报表中心 → 导入中心`，等待作业完成。  

### 3.3 错误处理与重导

1. 下载「错误报告」，定位失败行原因。  
2. 修正源文件中的错误行（保留正确行或按教员策略整表重导）。  
3. 再次导入，确认失败行清零或符合预期。  
4. 回到 `物料成本` 列表，用公司/物料/期间筛选核对落库结果。  

### 3.4 导入中心清理（可选）

按权限删除本次训练产生的历史作业。

## 4. 状态与权限说明

| 现象 | 处理 |
|------|------|
| 无「导入」按钮 | 检查权限并重新登录 |
| 无导入中心菜单 | 管理员挂菜单 `menu.report.importJobs` 并授权 |
| 部分行失败 | 属正常；用错误报告修正，勿假定整批回滚（以界面结果为准） |
| 来自成本计算的行不可改 | 换手工标准成本行或教员指定物料 |

## 5. 验收标准

- [ ] 成功下载模板并完成至少一次导入  
- [ ] 能解释成功行 / 失败行含义  
- [ ] 能从导入中心或结果弹窗取得错误报告并完成一次纠错重导  
- [ ] 能在物料成本列表核对到导入成功的数据  

## 6. FAQ / 禁忌

- 勿使用自建 Excel 列结构。  
- 勿在生产当期大批量试导；训练请用教员指定期间。  
- 导入会改写主数据/成本，操作前确认筛选与文件内容。  

## 7. 练习题

向教员询问当前环境还开放哪些导入类型；若仅有标准成本，口述「换一种导入类型时步骤哪些不变」。
