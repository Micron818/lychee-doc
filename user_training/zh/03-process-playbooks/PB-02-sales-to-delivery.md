# PB-02 销售出货（SO → DN）

> 受众：销售（仓储协助） | 模块：SD / WM | 版本：2026-08-01  
> 预计时长：35 分钟 | 语言：zh | 状态：草稿 | vi 同步：待同步

## 1. 业务目标

从销售订单创建到交货单推进，理解销售与仓储在出货节点的交接。

## 2. 前置条件

- 已完成 [PB-01](./PB-01-master-data-ready.md)（客户、物料、工厂可用）。
- 库存或教员允许「负库存/跳过实发」的训练设定已说明（以环境为准）。
- 销售角色可操作 SO；创建 DN 的权限已授予（销售或仓储，按公司分工）。

## 3. 操作步骤

1. 进入 `销售管理 → 销售订单(SO)`，新建订单：选择客户、工厂/组织字段（以表单为准）、录入物料明细数量与交期。  
2. 保存为草稿，检查明细无误后按界面流程「提交」/「审核」（按钮以环境为准）。  
3. 确认 SO 进入可交货相关状态。  
4. 创建或生成 `交货单(DN)`（入口可能在 SO 行操作或 DN 列表「新建」并引用 SO——以界面为准）。  
5. 维护实发数量，提交/过账 DN（若仓储负责过账，则转交仓储角色）。  
6. 回到 SO 查看已交/未交数量是否更新。

## 4. 状态与权限说明

| 步骤 | 常见卡住原因 |
|------|----------------|
| 无法选客户/物料 | 主数据未启用或未分配工厂 |
| 无提交/审核按钮 | 状态不符或权限不足 |
| 无法建 DN | SO 状态未到可交；或数量已交完 |

> 状态显示名以界面为准；培训师可在课堂补充本公司状态对照表。

## 5. 验收标准

- [ ] 存在一张已审核（或等效）的训练 SO  
- [ ] 存在关联的 DN，且数量逻辑与 SO 一致  
- [ ] 销售能向仓储清楚交接：单号、物料、数量、交期  

## 6. FAQ / 禁忌

- 已过账出货的纠错走公司退货/冲销流程，勿直接删历史单。  
- 修改已审核 SO 须符合变更纪律。  

## 7. 练习题

同一 SO 分两笔 DN 交货（若系统允许部分交货），观察未交量变化。
