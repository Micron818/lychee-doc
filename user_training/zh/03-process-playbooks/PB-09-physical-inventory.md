# PB-09 库存盘点（PI）

> 受众：仓储 | 模块：WM | 版本：2026-08-08  
> 预计时长：35 分钟 | 语言：zh | 状态：草稿 | vi 同步：待同步

## 1. 业务目标

完成一笔训练用库存盘点：建盘点单 → 录入实盘 → 过账差异 → 用现存量表核对；理解盘点宜在关账前完成。

## 2. 前置条件

- 仓库、物料、工厂物料就绪；库存期间开放。  
- 选定少量物料做课堂盘点（避免全仓盘点耗时）。  
- 学员具备 `仓储管理 → 库存盘点(PI)` 读写与过账权限。  
- 建议在 PB-05 关账演练之前完成本剧本。  

## 3. 操作步骤

1. **查看账面**  
   - `仓储管理 → 库存现存量`：记录训练物料当前数量。  

2. **建立盘点**  
   - 进入 `仓储管理 → 库存盘点(PI)` → 新建。  
   - 选择工厂、仓库、库存期间（以界面必填为准），加入训练物料行。  

3. **录入实盘**  
   - 将实盘数量录入为「账面 ± 教员指定差异」（课堂可人为制造差异）。  
   - 保存。  

4. **过账差异**  
   - 按界面流程提交/审核/过账（以实际按钮为准）。  
   - 回到 `库存现存量` 与 `库存流水`，确认数量与差异流水。  

5. **（可选）进耗存**  
   - `仓储管理 → 进耗存汇总表`：按工厂与期间筛选，理解盘点对期间进出的影响口径（教员讲解即可）。  

## 4. 状态与权限说明

| 现象 | 处理 |
|------|------|
| 无法过账 | 检查期间是否已关、单据状态、权限 |
| 差异为 0 | 仍可走完流程；课堂建议保留小差异便于观察流水 |
| 期间已关闭 | 不可再盘；先按公司流程处理期间 |

## 5. 验收标准

- [ ] 完成一张训练 PI 并达到教员要求的最终状态（已过账）  
- [ ] 能用现存量表解释盘点前后数量变化  
- [ ] 能说明「盘点未完成不宜强行库存期末结账」  

## 6. FAQ / 禁忌

- 训练勿对生产真实全仓做破坏性盘点。  
- 过账后纠错走公司冲销/再盘流程，勿私自改历史流水。  
- 关账剧本见 [PB-05](./PB-05-period-close.md)。  

## 7. 练习题

故意盘盈与盘亏各一笔物料，对比流水方向后口头汇报。
