# PB-06 导出与打印（供应商 Excel、订购单打印 / PDF、导出中心）

> 受众：采购（全员可了解导出中心） | 模块：SCM / RPT | 版本：2026-08-28  
> 预计时长：25 分钟 | 语言：zh | 状态：草稿 | vi 同步：待同步

## 1. 业务目标

掌握三类交付：供应商清单 Excel 导出、采购订单浏览器打印、采购订单 PDF 下载；并会使用导出中心处理异步任务。

## 2. 前置条件

- 管理员已完成 [导出功能上线检查清单](../05-admin-ops/02-export-go-live-checklist.md)。
- 学员具备供应商 `export`、采购订单读/导出权限，以及导出中心读权限。
- 至少一张**非草稿**训练 PO（打印外发练习）；另备一张草稿 PO（观察水印）。
- 建议先读 [导出中心使用说明](../01-getting-started/02-export-center.md)。

## 3. 操作步骤

### 3.1 供应商 Excel

1. 进入 `采购管理 → 供应商管理`。  
2. 设置筛选（例如仅启用状态），点击「导出」。  
3. 若直接下载：打开 Excel 核对列头语言与筛选结果。  
4. 若提示异步：打开 `报表中心 → 导出中心`，待成功后下载。  

### 3.2 订购单浏览器打印

1. 进入 `采购管理 → 采购订单(PO)` 的「采购单」页签，打开目标单据（不要在「MRP 待转」「请购待转」里找已下的单）。  
2. 在列表操作或详情中点击「打印」（新标签打开打印视图）。  
3. 核对抬头、供应商、明细、金额；草稿单应有草稿水印。  
4. 使用浏览器打印对话框（可保存为 PDF 作对比）；课堂可用「取消」避免真实出纸。  

### 3.3 订购单 PDF（导出作业）

1. 在打印视图工具条或详情中点击「下载 PDF」。  
2. 小单可能直接下载；否则到导出中心取文件。  
3. 打开 PDF：核对版式、页码、草稿水印（若适用）。  

### 3.4 导出中心清理（可选）

1. 在导出中心确认本人作业记录。  
2. 按权限删除测试作业（若界面提供）。  

## 4. 状态与权限说明

| 现象 | 处理 |
|------|------|
| 无「导出」「下载 PDF」 | 检查 export 权限并重新登录 |
| 无导出中心菜单 | 管理员挂菜单并授权 |
| 下载失败/链接过期 | 回到导出中心重新下载 |
| 草稿水印 | 勿发给供应商；先审核单据 |

## 5. 验收标准

- [ ] 成功取得一份供应商 Excel  
- [ ] 成功打开 PO 打印视图并识别草稿水印差异  
- [ ] 成功取得一份 PO PDF（直下或经导出中心）  
- [ ] 能说明何时需要去导出中心  

## 6. FAQ / 禁忌

- 导出范围过大易失败：先筛选。  
- 签名下载链接勿对外转发。  
- 浏览器打印与服务器 PDF 在分页上可能略有差异，以公司归档要求选用通道。  

## 7. 练习题

对同一张已审核 PO，分别用「浏览器打印保存 PDF」与「下载 PDF」各一份，对比页眉页脚与水印。
