# PB-03 采购入库与应付（工作台 → PO → GR → AP）

> 受众：采购、仓储、财务 | 模块：SCM / WM / FI | 版本：2026-08-28  
> 预计时长：60 分钟 | 语言：zh | 状态：草稿 | vi 同步：待同步

## 1. 业务目标

跑通从待买需求到收货、再到应付发票的最小闭环。原物料以 MRP 建议为准，在采购订单页一次生成订单并审核；采购申请只用于内部手工请购。明确三角色交接物（单号、数量、金额）。

## 2. 前置条件

- [PB-01](./PB-01-master-data-ready.md) 供应商、物料、工厂可用；建议已维护 `物料供应商`（默认供应商、采购单位、末次价）。  
- **主路径**需要该厂最新一次已完成的 MRP，且结果含「建议采购」。可由教员预跑，或与 [PB-04](./PB-04-mrp-to-production.md) 连堂。课堂若尚无建议，改走本节 A2 或 A3，仍能练到 GR / AP。  
- 库存期间开放；会计期间开放（财务段需要）。  
- 采购账号具备采购订单新建与审核权限；仓储、财务各用本岗位账号（或一人分饰三角）。

## 3. 操作步骤

### A. 采购 — 主路径：MRP 待转（有建议时必练）

1. 进入 `采购管理 → 采购订单(PO)`，打开「MRP 待转」页签。  
   - 计划员也可在 `生产计划 → 物料需求计划(MRP)` 打开运行、过滤「建议采购」，点击「前往 MRP 转采购订单」跳入本页签。  
2. 核对列表：物料、工厂、需求日期、剩余数量、建议供应商。此处只显示各厂**最新**一次已完成且生效的 MRP 建议。  
3. 勾选行。可改供应商、本次转单数量（须大于 0 且不超过剩余数量）、采购单位、末次采购价（即本次单价）。  
   - 换供应商会刷新单位与最小订购量。  
   - 末次价仅在物料供应商的报价币与供应商当前交易币一致时带出；不一致则为 0，请按开单币重填（界面会提示）。未维护物料供应商时单价为 0、单位回退物料采购单位。  
   - 本次数量须不小于最小订购量（把该行剩余量一次转完时除外）。  
4. 点击「生成采购订单」，核对「按工厂+供应商拆单预览」（几张单、数量、单位、单价），确认。  
5. 系统按工厂+供应商拆成一张或多张「草稿」PO（主档与明细一次生成，来源类型为「MRP」），并切回「采购单」页签。  
6. 打开刚生成的草稿：补税率、预计交货日期（单价仍可改），点击「审核」，状态变为「已核准」。  
7. （可选）打印或下载 PDF，见 [PB-06](./PB-06-export-and-print.md)。  

### A2. 并行路径：手工请购（课堂可选）

内部请购不走 MRP。原物料日常不要用本路径代替 A。

1. `采购管理 → 采购申请(PR)` 新建，录入物料与数量，保存后「审核」，状态变为「已核准」。  
2. 回到 `采购订单(PO)` → 「请购待转」页签：勾选已核准明细，指定供应商与本次转单数量，点击「生成采购订单」。预览拆单后确认。  
3. 生成的草稿来源类型为「采购申请」。后续同 A 第 6～7 步审核。  
4. 漏勾的请购明细可再在「请购待转」生成**另一张**同供应商 PO。也可打开已有「采购申请」类型草稿，用「从采购申请导入」补行（工厂、供应商须与主档一致）。  

### A3. 无来源：列表新增手工单（课堂可选）

1. 在「采购单」页签点击「新增」，填写工厂、供应商等并保存。来源类型固定为「手工」，不要指望在此选择 MRP 或请购。  
2. 明细只手键新增。本类型**没有**「从采购申请导入」。  
3. 审核后可收货。  

### B. 仓储

8. `仓储管理 → 收货单(GR)`，按已核准 PO 收货，录入实收数量并过账。  
9. 在 `库存现存量` 核对物料数量增加。  

### C. 财务

10. `财务会计 → 应付发票`，依据 PO/GR 信息创建 AP（具体「从收货创建」或手工录入以界面为准）。  
11. 提交、审核、过账；必要时查看关联凭证。  

## 4. 状态与权限说明

| 界面用语 | 含义 |
|----------|------|
| 来源类型 = MRP | 从「MRP 待转」一次生成主档+明细；草稿上不能手键行、不能汇入 PR |
| 来源类型 = 采购申请 | 从「请购待转」生成；草稿上可「从采购申请导入」补行，不能手键行 |
| 来源类型 = 手工 | 列表「新增」先建主档；只能手键明细 |
| PO 草稿 | 已占用 MRP 需求；通常不可收货；打印带水印 |
| PO 已核准 | 仓储可按未收量收货 |
| 无「生成采购订单」/ 按钮灰掉 | 未勾选行，或缺少采购订单新建权限；计划员侧「前往 MRP 转采购订单」同样校验该权限 |

| 环节 | 说明 |
|------|------|
| PO 未审核 | 通常不可收货 |
| GR 过账失败 | 检查期间、仓库、数量、权限 |
| AP 过账失败 | 检查期间、科目确定、业务伙伴、金额 |

## 5. 验收标准

- [ ] 主路径（或教员指定的 A2/A3）生成至少一张已核准 PO，来源类型与路径一致  
- [ ] 勾选两家供应商时拆成两张草稿 PO（主路径或请购路径）  
- [ ] PO / GR / AP 单号齐全并可互相追溯（界面关联或手工记录）  
- [ ] 收货后库存数量符合预期  
- [ ] AP 达到教员要求的最终状态（已过账或已审核）  

## 6. FAQ / 禁忌

- **不要**在 MRP 结果页直接下单，也**没有**「转采购申请」。采购建议一律到「MRP 待转」。  
- **不要**用列表「新增」去汇入请购或 MRP；「新增」只能出手工单。  
- 无供应商且物料供应商也没有默认供应商时，无法生成 PO。  
- 本次数量低于最小订购量且未转完全部剩余时，系统会拒绝。  
- 草稿 PO 不打算下单：请删除后再请计划重跑 MRP。否则下一轮建议会把草稿当成已订，数量偏少。  
- 删除草稿后若已经重跑过 MRP，「MRP 待转」不会自动拿出历史运行再转，须再跑一次才会出现缺口。  
- 未收货先开票：仅在公司允许的流程下练习，须教员说明。  
- 收货数量不得超过可收量（除非系统与流程明确允许超收）。  

## 7. 练习题

1. 主路径勾选多行、两家供应商，确认拆单预览与生成结果。  
2. 同一建议只转一半数量，回到「MRP 待转」核对剩余数量。  
3. 制造一次「部分收货」，观察 PO 未清数量与后续第二次 GR。
