# PB-03 采购入库与应付（PR → PO → GR → AP）

> 受众：采购、仓储、财务 | 模块：SCM / WM / FI | 版本：2026-08-01  
> 预计时长：50 分钟 | 语言：zh | 状态：草稿 | vi 同步：待同步

## 1. 业务目标

跑通从采购申请到收货，再到应付发票的最小闭环，明确三角色交接物（单号、数量、金额）。

## 2. 前置条件

- [PB-01](./PB-01-master-data-ready.md) 供应商与物料可用。
- 库存期间开放；会计期间开放（财务段需要）。
- 三角色测试账号或一人分饰三角（训练环境）。

## 3. 操作步骤

### A. 采购

1. `采购管理 → 采购申请(PR)` 新建申请，录入物料与数量，提交/审核。  
2. 将 PR 转为 `采购订单(PO)`（或直接建 PO，按教员指定路径）。  
3. 维护供应商、价格、交期，提交/审核 PO。  
4. （可选）打印或下载 PDF，见 [PB-06](./PB-06-export-and-print.md)。  

### B. 仓储

5. `仓储管理 → 收货单(GR)`，按 PO 收货，录入实收数量并过账。  
6. 在 `库存现存量` 核对物料数量增加。  

### C. 财务

7. `财务会计 → 应付发票`，依据 PO/GR 信息创建 AP（具体「从收货创建」或手工录入以界面为准）。  
8. 提交、审核、过账；必要时查看关联凭证。  

## 4. 状态与权限说明

| 环节 | 说明 |
|------|------|
| PO 未审核 | 通常不可收货 |
| GR 过账失败 | 检查期间、仓库、数量、权限 |
| AP 过账失败 | 检查期间、科目确定、业务伙伴、金额 |

## 5. 验收标准

- [ ] PR/PO/GR/AP 单号齐全并可互相追溯（界面关联或手工记录）  
- [ ] 收货后库存数量符合预期  
- [ ] AP 达到教员要求的最终状态（已过账或已审核）  

## 6. FAQ / 禁忌

- 未收货先开票：仅在公司允许的流程下练习，须教员说明。  
- 收货数量不得超过可收量（除非系统与流程明确允许超收）。  

## 7. 练习题

制造一次「部分收货」，观察 PO 未清数量与后续第二次 GR。
