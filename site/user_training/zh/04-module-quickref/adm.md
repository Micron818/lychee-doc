# 速查：系统管理（ADM）

> 版本：2026-08-08 | 语言：zh | vi 同步：待同步

## 入口（界面菜单）

| 菜单路径 | 训练深度 |
|----------|----------|
| `系统管理 → 选项管理` | 按授权维护 |
| `系统管理 → 菜单管理` | 管理员必练 |
| `系统管理 → 权限管理` | 管理员必练 |
| `系统管理 → 用户管理` | 管理员必练 |
| `系统管理 → 角色管理` | 管理员必练 |

## 典型动作

开户 → 建角色 → 挂菜单/动作 → 分配角色 → 用户重登验证。

## 禁忌

- 勿将高权限角色随意授予业务账号。  
- 改权限后未重登不要判定「系统坏了」。  
详见 [菜单与权限开通](../05-admin-ops/01-menu-and-permission.md)。
