# 速查：物料管理（MM）

> 版本：2026-08-08 | 语言：zh | vi 同步：待同步

## 入口（界面菜单）

| 菜单路径 | 训练深度 |
|----------|----------|
| `物料管理 → 物料分类(分层)` | 按需 |
| `物料管理 → 物料类别` | PB-01 按需 |
| `物料管理 → 物料单位` | PB-01 按需 |
| `物料管理 → 产品型号` | 按需 |
| `物料管理 → 产品尺寸` | 按需 |
| `物料管理 → 物料颜色` | 按需 |
| `物料管理 → 物料资料` | PB-01 必练 |
| `物料管理 → 标准单位转换` | 按需 |
| `物料管理 → 物料单位转换` | 按需 |
| `物料管理 → 工厂物料` | PB-01 必练 |

> 注意：「物料类别」与「物料分类(分层)」是两个不同菜单，勿混称。

## 典型动作

建物料 → 分配工厂物料 → 维护单位转换（按需）。

## 禁忌

- 未分配工厂的物料勿期望在工厂级单据中可选。  
- 已用于未结单据的单位变更须评估影响。  
详见 [PB-01](../03-process-playbooks/PB-01-master-data-ready.md)。
