# 角色手册：采购

> 受众：采购 | 模块：SCM | 版本：2026-08-28  
> 预计时长：40 分钟 | 语言：zh | 状态：草稿 | vi 同步：待同步

## 1. 业务目标

在采购订单页完成原物料转单与审核；处理内部采购申请；维护物料供应商；完成打印/PDF 与供应商清单导出；与仓储收货、财务应付衔接。委外走 OSO。

## 2. 前置条件

- 供应商、物料、工厂主数据可用；日常原物料建议已维护物料供应商。  
- 具备采购订单新建/审核权限（及 PR、OSO，若岗位需要）；导出/打印相关权限已开通。

## 3. 日常工作清单

1. 维护 `采购管理 → 供应商管理`；需要时导出供应商清单。  
2. 维护 `物料供应商`：默认供应商、采购单位、最小订购量、末次价（报价币尽量与供应商当前交易币一致）。  
3. **原物料（日常主路径）**：打开 `采购订单(PO)` → 「MRP 待转」，勾选建议、确认供应商/数量/单价，点击「生成采购订单」，再在「采购单」页签补交期与税率并「审核」。不要先开 PR。  
4. **内部请购（并行）**：处理 `采购申请(PR)` 的创建与审核；已核准明细在采购订单「请购待转」一键生成 PO。  
5. 无来源的临时采购：在「采购单」页签「新增」手工单，再手键明细。  
6. 打印 PO 或下载 PDF 发给供应商（须已核准、无草稿水印）。  
7. 跟进收货进度（协同仓储 GR）；异常交期与数量变更。不打算下的草稿及时删除，以免占用下一轮 MRP。  
8. 委外场景维护 `委外加工订单(OSO)`（发料/收货协同仓储与生产）→ [PB-08](../03-process-playbooks/PB-08-outsource-loop.md)。  

跟练：[PB-03](../03-process-playbooks/PB-03-procure-to-pay.md)、[PB-06](../03-process-playbooks/PB-06-export-and-print.md)、[PB-08](../03-process-playbooks/PB-08-outsource-loop.md)。

## 4. 状态与权限说明

| 能力 | 依赖 |
|------|------|
| 「MRP 待转」「请购待转」生成订单 | 采购订单新建权限 |
| 改单价/交期、审核 PO | 采购订单更新 / 审核（原物料实质控制点） |
| 列表「导出」 | 菜单 export 动作 |
| 「打印」/「下载 PDF」 | 读权限 + 导出权限（PDF） |
| 草稿水印 | 草稿单打印/PDF 会带草稿标识，勿直接外发 |

来源类型与明细工具见 [PB-03](../03-process-playbooks/PB-03-procure-to-pay.md) 状态表。

## 5. 验收标准

- [ ] 能从「MRP 待转」（或教员指定的请购/手工路径）生成 PO 并审核至可收货  
- [ ] 能说明原物料不走 PR、控制点在 PO 审核  
- [ ] 能打印或下载一张已审核 PO  
- [ ] 知道异步导出时去「导出中心」取文件  
- [ ] 能说明 OSO 与 PO 的发料差异，或完成 PB-08  

## 6. FAQ / 禁忌

- 勿将带草稿水印的文件发给供应商。  
- 大批量导出前先筛选，避免超时或失败。  
- 勿在 MRP 结果页寻找「转采购申请」。  
- 列表「新增」不能用来源类型下拉改成 MRP 或请购。  

## 7. 练习题

完成 PB-03 至 GR 前的采购段（优先主路径），并执行 PB-06 的打印与 PDF 各一次。
