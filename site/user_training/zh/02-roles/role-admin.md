# 角色手册：系统管理员

> 受众：系统管理员 | 模块：ADM | 版本：2026-08-08  
> 预计时长：45 分钟 | 语言：zh | 状态：草稿 | vi 同步：待同步

## 1. 业务目标

保障各业务角色能登录、看见正确菜单、执行被授权的动作；完成训练环境与上线环境的权限基线配置。

## 2. 前置条件

- 拥有系统管理全部或必要菜单权限。
- 明确本公司角色划分（可对照总纲角色矩阵裁剪）。

## 3. 日常工作清单

1. **选项**：按实施交付范围维护 `系统管理 → 选项管理`。  
2. **菜单**：维护菜单树与路由，确保新功能菜单已挂载（如导出中心、导入中心）；确认界面菜单中文名正确。  
3. **权限**：为菜单配置动作（读、写、删、导出、导入等）。  
4. **角色**：按岗位建立角色并勾选菜单与动作。  
5. **用户**：开户、分配角色、停用离职账号。  
6. **验收**：用业务测试账号登录，确认菜单与按钮可见性符合矩阵。  

详细步骤见 [菜单与权限开通](../05-admin-ops/01-menu-and-permission.md)。

## 4. 状态与权限说明

| 配置对象 | 要点 |
|----------|------|
| 菜单 | 决定「看不看得到入口」 |
| 动作权限 | 决定「能不能点导出/删除/审核」 |
| 角色 | 权限的打包单位；用户通过角色获得权限 |
| 用户 | 一人可多角色；以并集生效（以系统实际为准） |

## 5. 验收标准

- [ ] 每个训练角色至少有一个测试用户可登录  
- [ ] 导出中心、供应商导出、采购订单导出等新动作已授予对应角色  
- [ ] 无业务权限的账号不能进入无关高危菜单  

## 6. FAQ / 禁忌

- 勿把「超级管理员」角色随意发给业务用户。  
- 配置权限后若用户仍无按钮：请对方**重新登录**再试。  
- 生产改权限建议双人复核，并留下变更记录。  

## 7. 练习题

按 [导出功能上线检查清单](../05-admin-ops/02-export-go-live-checklist.md) 在训练环境走通一遍，并指定一名采购测试用户验证按钮可见。
