# 导入中心使用说明

> 受众：有导入权限的用户（常见：财务、主数据） | 模块：RPT / FI | 版本：2026-08-08  
> 预计时长：15 分钟 | 语言：zh | 状态：草稿 | vi 同步：待同步

## 1. 业务目标

理解批量 Excel 导入的交付方式：从业务页下载模板、上传文件；小文件可能同步完成，大文件进入异步作业，在「导入中心」查看进度、下载源文件与错误报告。

## 2. 前置条件

- 角色具备相关业务页的导入动作权限（以界面提供的「导入」按钮为准）。
- 角色具备 `报表中心 → 导入中心` 的查看权限（异步任务与历史需要）。
- 管理员已完成导入相关菜单开通（见 [导入导出功能上线检查清单](../05-admin-ops/02-export-go-live-checklist.md)）。
- 训练环境已有可用的公司、物料、会计期间等（按导入类型要求）。

## 3. 操作步骤

### 3.1 从业务页发起导入（推荐）

1. 进入提供导入能力的业务页（示例：`财务会计 → 成本核算 → 物料成本`）。  
2. 先下载**官方模板**（勿自建列序或改列头）。  
3. 按「说明」页或教员指引填写业务编码（公司编码、物料编码等），保存为 Excel。  
4. 点击「导入」，选择文件并确认选项（如仅新建 / 允许更新，以界面为准）。  
5. 观察结果：  
   - **同步完成**：弹出结果摘要（成功行 / 失败行）；有失败时可下载错误报告。  
   - **异步作业**：提示处理中；前往导入中心查看状态。  

### 3.2 在导入中心跟踪与取件

1. 进入 `报表中心 → 导入中心`。  
2. 找到本人发起的作业，确认状态（进行中 / 成功 / 失败）。  
3. 需要时下载：源文件、错误报告（若有失败行）。  
4. 按权限删除不再需要的历史作业。  

## 4. 状态与权限说明

| 界面状态（示例） | 含义 | 用户动作 |
|------------------|------|----------|
| 进行中 / 处理中 | 后台读表校验落库 | 等待；可刷新列表 |
| 成功 / 已完成 | 作业结束（可能仍有部分行失败） | 看成功/失败行数；下载错误报告修正后重导 |
| 失败 | 作业级失败（文件损坏、类型不匹配等） | 查看原因后重试 |
| 看不到「导入」 | 无导入权限 | 联系管理员 |
| 看不到导入中心 | 未挂菜单或无 read | 见运维开通清单 |

## 5. 验收标准

- [ ] 能下载一种训练用导入模板并正确填写至少一行  
- [ ] 能完成一次导入并看懂成功/失败行数  
- [ ] 能在导入中心找到作业并下载错误报告（若有失败）  

## 6. FAQ / 禁忌

- 勿改动模板列顺序与列头；系统按列头校验。  
- 使用**业务编码**而非内部 ID。  
- 部分行失败时：修正错误报告中的行后，可只重导失败行或整表按教员策略重导。  
- 来自成本计算生成的标准成本行通常不可被导入覆盖——见业务页说明与 [PB-07](../03-process-playbooks/PB-07-import-center.md)。  

## 7. 练习题

1. 故意填错一个物料编码，导入后下载错误报告，修正后再导一次全部成功。  
2. 对照 [导出中心](./02-export-center.md)，用一句话说明导入中心与导出中心各自管什么。
