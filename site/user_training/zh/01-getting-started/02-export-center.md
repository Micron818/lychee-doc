# 导出中心使用说明

> 受众：有导出权限的用户 | 模块：RPT / SCM | 版本：2026-08-08  
> 预计时长：15 分钟 | 语言：zh | 状态：草稿 | vi 同步：待同步

## 1. 业务目标

理解清单导出与单据 PDF 的两种交付方式：小数据量可直接下载；大数据量进入异步作业，在「导出中心」查看进度并重复下载。

## 2. 前置条件

- 角色具备相关业务页的「导出」动作权限（例如供应商、采购订单）。
- 角色具备「报表中心 → 导出中心」的查看权限（异步任务需要）。
- 管理员已完成导出相关菜单开通（见 [导出功能上线检查清单](../05-admin-ops/02-export-go-live-checklist.md)）。

## 3. 操作步骤

### 3.1 从业务页发起导出

1. 进入业务列表（示例：`采购管理 → 供应商管理`）。
2. 先设置筛选条件（导出通常按**当前筛选**范围生成，避免无筛选导出过大）。
3. 点击工具栏「导出」（或页面提供的「下载 PDF」等按钮）。
4. 观察结果：
   - **同步完成**：浏览器直接开始下载文件。
   - **异步作业**：提示任务已创建；前往导出中心查看状态。

### 3.2 在导出中心跟踪与下载

1. 进入 `报表中心 → 导出中心`。
2. 在列表中找到本人发起的作业，确认状态（进行中 / 成功 / 失败）。
3. 成功后点击下载；签名链接有时效，过期可再次从中心申请下载。
4. 不再需要的历史作业可按权限删除（以界面提供的操作为准）。

### 3.3 订购单打印与 PDF（关联）

完整步骤见 [PB-06 导出与打印](../03-process-playbooks/PB-06-export-and-print.md)。摘要：

- **浏览器打印**：打开打印视图后使用系统打印对话框。
- **PDF 下载**：走导出作业框架；小单可直下，批量或大单可能进导出中心。

## 4. 状态与权限说明

| 界面状态（示例） | 含义 | 用户动作 |
|------------------|------|----------|
| 进行中 / 处理中 | 后台生成文件 | 等待；可刷新列表 |
| 成功 / 已完成 | 文件已就绪 | 下载 |
| 失败 | 生成出错 | 查看失败原因；缩小筛选后重试 |
| 看不到「导出」按钮 | 无 export 权限 | 联系管理员 |
| 下载提示过期 | 签名 URL 失效 | 回到导出中心重新下载 |

## 5. 验收标准

- [ ] 能在有权限的列表完成一次导出并拿到文件  
- [ ] 能说明同步直下与异步进导出中心的差异  
- [ ] 能在导出中心找到自己的作业并下载  

## 6. FAQ / 禁忌

- 导出范围过大可能被系统拒绝或排队很久：先收窄筛选条件。  
- 下载链接勿转发到公共频道（含时效签名，仍属内部文件通道）。  
- 导出文件会按策略过期清理；需长期归档请自行保存到公司文档库。  

## 7. 练习题

1. 在供应商列表按状态筛选后导出 Excel，确认文件列头为当前界面语言。  
2. （可选）对一张非草稿采购订单执行「下载 PDF」，并在导出中心确认记录。
