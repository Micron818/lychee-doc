# PB-08 委外闭环（OSO → 发料 → GR → AP）

> 受众：采购、仓储（财务可选） | 模块：SCM / WM / FI | 版本：2026-08-08  
> 预计时长：45 分钟 | 语言：zh | 状态：草稿 | vi 同步：待同步

## 1. 业务目标

跑通委外加工订单（OSO）最小闭环：建单 → 按组件发料 → 成品收货 →（可选）应付；理解 OSO 与标准 PO 在发料/收货上的差异。

## 2. 前置条件

- 供应商、成品与组件物料、工厂物料、BOM（若从计划/BOM 生成发料）已就绪。  
- 库存期间开放；组件建议有可发库存。  
- 学员具备 `采购管理 → 委外加工订单(OSO)`、领料/收货相关权限。  
- 建议已完成 PB-01；了解 PB-03 标准采购（工作台 → PO → GR）便于对比。  

## 3. 操作步骤

1. **创建 OSO**  
   - 进入 `采购管理 → 委外加工订单(OSO)` → 新建。  
   - 选择工厂、供应商、成品明细（数量、交期、价格等）。  
   - 维护或生成发料组件（可从计划单导入 / 按 BOM 生成，以界面按钮为准）。  
   - 保存后按公司流程「发布」或等效动作。  

2. **发料（仓储）**  
   - 进入 `仓储管理 → 库存领料(SI)`（或界面提供的从 OSO 发料入口）。  
   - 按 OSO 组件行发料并过账；核对组件现存量减少。  
   - 若流程使用调拨到委外仓：使用 `库存调拨(ST)`，按教员说明执行。  

3. **收货（仓储）**  
   - 进入 `仓储管理 → 收货单(GR)`，以来源「委外加工订单」收货。  
   - 录入实收数量并过账；核对成品库存增加、OSO 已收数量更新。  

4. **应付（财务，可选）**  
   - `财务会计 → 应收应付 → 应付发票`：依据 OSO/GR 创建 AP（深度由教员定）。  

5. **结案**  
   - 回到 OSO 查看状态；若需强制结案，仅在教员许可下操作。  

## 4. 状态与权限说明

| 节点 | 培训要点 |
|------|----------|
| OSO 未发布 | 通常不可发料/收货 |
| 供方自备组件 | 可能无需本厂发料，以明细勾选为准 |
| 部分收货 | 未清数量继续跟踪 |
| GR 失败 | 检查期间、仓库、未收数量、OSO 状态 |

## 5. 验收标准

- [ ] 一张训练 OSO 已发布且含组件行  
- [ ] 至少完成一笔与 OSO 关联的发料（或教员确认的豁免路径）  
- [ ] 至少一笔 OSO 来源 GR 过账成功  
- [ ] 能口头对比「标准 PO 收货」与「OSO 发料+收货」差异  

## 6. FAQ / 禁忌

- 草稿/未发布 OSO 勿当作已下给供应商的正式单。  
- 勿与标准 PO 混用同一套收发习惯而不看组件行。  
- 强制结案可能影响未清数量，生产环境须审批。
