# PB-05 库存与财务关账

> 受众：仓储、财务 | 模块：WM / FI | 版本：2026-08-01  
> 预计时长：40 分钟 | 语言：zh | 状态：草稿 | vi 同步：待同步

## 1. 业务目标

理解库存期末结账与会计/成本结算的协作关系；掌握「活跃成本结算会阻止库存期重开」这一关键禁忌，避免关账死锁。

## 2. 前置条件

- 训练环境有可操作的库存期间与会计期间（建议用专用训练期，勿动生产当期）。
- 仓储与财务角色在场；教员准备好示范用成本结算数据或说明可否实操过账。
- 已阅读角色手册中关账相关章节。

## 3. 操作步骤

> 下列为**协作剧本**。部分按钮在训练环境可能只做「讲解 + 只读演示」，以教员宣布的可写范围为准。

1. **关账前检查（仓储）**  
   - 确认当期收发、盘点差异已处理。  
   - 查看 `仓储管理 → 库存期末结账` 当前期间状态。  
2. **关账前检查（财务）**  
   - 确认发票、收付款、成本相关作业进度。  
   - 查看 `财务会计 → 成本结算` 是否仍有草稿/已定稿/已过账且未作废的活跃作业。  
3. **库存期末结账（仓储）**  
   - 在教员许可下执行结账；记录结账前后状态。  
4. **成本结算（财务）**  
   - 按公司流程：启动 → 定稿 → 过账（或教员指定停在某步）。  
5. **演练互锁（重点）**  
   - 在仍存在活跃成本结算时，尝试「重开库存期间」：系统应拒绝并提示需财务先处理。  
   - 财务对成本结算执行「作废」（权限仅财务）：后再由仓储重开（若教员允许）。  
6. **会计期间**  
   - 浏览 `会计期间结账` 与库存期的先后顺序（以公司制度 + 教员说明为准）。  

## 4. 状态与权限说明

| 规则（用户语言） | 含义 |
|------------------|------|
| 活跃成本结算 | 成本结算处于草稿 / 已定稿 / 已过账等未作废状态（以界面状态名为准） |
| 仓储重开被拒 | 同公司同期仍有活跃成本结算 → 先联系财务作废 |
| 作废成本结算 | 仅财务可执行；已过账者可能需先冲销凭证 |

## 5. 验收标准

- [ ] 能口述关账前仓储与财务各自检查清单  
- [ ] 能复述「有活跃成本结算时不能重开库存期」  
- [ ] 知道成本结算作废入口在财务侧  

## 6. FAQ / 禁忌

- 禁止为「赶进度」绕过系统互锁。  
- 生产当期关账必须双人确认；训练请使用教员指定期间。  

## 7. 练习题

两人一组：一人扮仓储申请重开，一人扮财务解释拒绝原因与解除步骤。
