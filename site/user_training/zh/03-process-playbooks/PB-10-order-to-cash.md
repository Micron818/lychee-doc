# PB-10 销货到收款（DN → AR → 收付款）

> 受众：财务（销售旁听） | 模块：SD / FI | 版本：2026-08-08  
> 预计时长：40 分钟 | 语言：zh | 状态：草稿 | vi 同步：待同步

## 1. 业务目标

在已出货的交货单基础上，完成应收发票与收款核销的最小闭环，补齐 OV-02 概念图中「应收」段的动手路径。

## 2. 前置条件

- 已完成 [PB-02](./PB-02-sales-to-delivery.md) 或教员提供一张已过账/可开票的训练 DN。  
- 客户对应业务伙伴、会计期间开放；科目确定等财务主数据已由实施初始化。  
- 学员具备 `财务会计 → 应收应付 → 应收发票`、`收付款` 相关权限。  

## 3. 操作步骤

1. **核对出货**  
   - 打开训练 DN，记录客户、物料、数量、金额（或可开票信息）。  

2. **创建应收发票**  
   - 进入 `财务会计 → 应收应付 → 应收发票`。  
   - 依据 DN/销售信息创建 AR（「从来源生成」或手工，以界面为准）。  
   - 按公司流程：保存 → 提交/审核 → 过账。  

3. **收款**  
   - 进入 `财务会计 → 应收应付 → 收付款`。  
   - 新建收款单：选择公司银行账户、客户/业务伙伴、金额。  
   - 核销到上一步 AR（以界面核销操作为准）。  
   - 审核并过账。  

4. **核对**  
   - 回到 AR 查看已收/未清状态；必要时查看日记账是否生成（教员演示）。  

## 4. 状态与权限说明

| 节点 | 培训要点 |
|------|----------|
| AR 过账失败 | 检查期间、业务伙伴、科目确定、金额 |
| 收款无法核销 | 检查币别、未清余额、单据状态 |
| 过账后更正 | 优先冲销/贷项，勿改历史 |

## 5. 验收标准

- [ ] 一张训练 AR 达到教员要求的最终状态（已过账）  
- [ ] 一笔收款与 AR 完成核销（或教员认可的最简收款路径）  
- [ ] 能复述 SO → DN → AR → 收付款 的责任交接  

## 6. FAQ / 禁忌

- 未出货强开票须符合公司政策；训练以已出货 DN 为准。  
- 收付款涉及资金账户，训练环境使用教员指定银行账户。  
- 销货出货段仍以 PB-02 为准；本剧本不重复录 SO。
