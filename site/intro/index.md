# 系统介绍

Lychee ERP 面向制造企业，把主数据、销售、采购、仓储、计划生产和财务放在同一套业务系统里。

## 模块

| 模块 | 做什么 |
|------|--------|
| 基础资料 | 公司、工厂等组织数据 |
| 物料 | 物料、型号与变体 |
| 销售 | 销售订单到出货、开票与收款 |
| 采购 | 采购订单、委外、收货与应付 |
| 仓储 | 收发、调拨、盘点与库存 |
| 生产计划 | BOM、MRP、工单与产量回馈 |
| 财务 | 应收应付、收付款与关账协作 |
| 系统管理 | 用户、角色、菜单与导入导出 |

各模块的操作步骤在 [用户训练](/user_training/)。

## 怎么进入系统

本站只提供产品介绍和帮助，不办理登录。

- 已有账号：使用贵司专属地址打开系统。本站不列出各公司的地址。
- 想先看系统：打开 [演示环境](https://footwear-demo.lycheetech.com)。演示里是虚构资料，与任何正式公司的业务数据无关。

## 帮助文档的语言

用户训练以中文编写，越南文按相同目录后续补齐。系统界面可以切换英文，用户手册不单独维护英文版。
