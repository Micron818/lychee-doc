# 委外加工系統：取得委外單待發料明細實作計劃

本計劃旨在實作類似生產訂單中 `getPendingIssueProductionOrderComponentPage` 的機制，讓前端能夠查詢委外單 (Outsource Order) 底下所有尚未發料完畢的用料明細 (Outsource Order Component)，以供倉管人員後續勾選並呼叫 `batchCreateItemsFromOutsource`。

## 1. 擴充 Response DTO
為提供前端發料數量的計算依據，需擴充回傳的 DTO。
*   於 `lychee-erp-scm/src/main/java/com/lychee/erp/scm/dto/response/OutsourceOrderComponentResponse.java` 新增欄位：
    *   `private BigDecimal draftIssueQuantity;` (草稿領料數量)
    *   `private BigDecimal availableToIssueQuantity;` (可發放數量：`requiredQuantity - issuedQuantity - draftIssueQuantity`)

## 2. 實作 SCM 模組 Service 邏輯
於 `OutsourceOrderComponentManageService` 中新增並實作查詢待發料明細的方法。

*   **新增介面方法**：
    *   於 `OutsourceOrderComponentManageService` 新增：
        `Page<OutsourceOrderComponentResponse> getPendingIssueOutsourceOrderComponentPage(Long orderId, ProPageRequest request);`
*   **實作查詢邏輯 (`OutsourceOrderComponentManageServiceImpl`)**：
    *   實作 `getPendingIssueOutsourceOrderComponentPage`，參數傳入 `orderId`。
    *   **建立 Specification 過濾條件**：
        1.  **關聯委外單**：透過 `root.join("outsourceOrderItem").get("outsourceOrderId")` 必須等於傳入的 `orderId`。
        2.  **客供料限制**：必須是本廠提供 (`isSupplierProvided` 為 `false` 或 `null`)。
        3.  **數量未滿限制**：`issuedQuantity < requiredQuantity`。
    *   利用上述 Specification 執行分頁查詢取得 `Page<OutsourceOrderComponent>`。
*   **計算與回填數量 (`enrichIssueFeedback`)**：
    *   從查詢結果中搜集所有的 Component ID，呼叫已實作的 `remoteStockIssueService.sumDraftBaseQuantityByOutsourceOrderComponentIds(ids)`，取得每項用料在 WM 模組中的草稿發料數量。
    *   將 Component 轉換為 Response DTO，並將取得的草稿數量填入 `draftIssueQuantity`。
    *   計算 `availableToIssueQuantity = requiredQuantity - issuedQuantity - draftIssueQuantity` (若小於 0 則設為 0)。

## 3. 暴露 Controller API 端點
提供前端調用的 HTTP 端點。

*   於 `lychee-erp-scm/src/main/java/com/lychee/erp/scm/controller/OutsourceOrderController.java` 新增 API：
    *   路由：`POST /api/v1/scm/outsource-orders/{id}/components/pending-issue/page`
    *   權限：`@PreAuthorize("hasAuthority('/scm/outsource-orders:read')")`
    *   接收 `@PathVariable("id") Long id` 與 `@RequestBody ProPageRequest request`。
    *   呼叫 `outsourceOrderComponentManageService.getPendingIssueOutsourceOrderComponentPage(id, request)` 並回傳結果。
