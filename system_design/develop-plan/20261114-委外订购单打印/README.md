# 委外加工单打印（Outsource Order PDF）

本目录描述 **一张委外加工订单** 交给加工厂商的订购 PDF。  
**不是**委外进度报表（多单 Excel、看收回与备料执行），**不是**采购订单，**不是**工厂订单，**不是**发料当时的仓库送料单。

中文打印标题、文件名统一为 **委外加工单**。英文 `OUTSOURCE ORDER`。越南文 `ĐƠN GIA CÔNG NGOÀI`。  
系统单据、菜单、表名、API 资源仍叫 **委外加工订单** / `outsource-orders` / OSO。不要把菜单改名为委外加工单。

```text
委外加工订单（一张 order_no，一个加工厂商）
  → 【本打印】按单号打委外加工单 PDF → 交给厂商
       收回件（加工什么、多少、单价、需求日）
       本厂应发组件（约定应发数量）
       厂商自备组件（约定数量，标明自备）
       收回件样品图 + 表头备注
  → 进度与已发 / 已耗仍走委外进度报表
  → 实际出库的仓库、批次、本次实发另走发料单据，不印在本 PDF
```

**状态：已实现。** 入口：委外加工订单列表操作列 + 详情抽屉「打印」；`GET /api/v1/scm/outsource-orders/{id}/pdf`。预览工具栏的下载走 `SCM_OUTSOURCE_ORDER_PDF`。版式以 [03-数据模型与版式.md](./03-数据模型与版式.md) 为准；改列、分页、样品区时先改那一章。
