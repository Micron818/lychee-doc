## 3. API

### 3.1 物料保存

`POST/PUT /api/v1/mm/materials` 的 `MaterialRequest` 增加可选 `isFashionVariant`。

- 变体分类：服务端强制 true。
- 其它：`true` 须过变体维度校验；`false`/省略视为 false。
- 更新：`code` 仍不可变、仍不发号。

### 3.2 物料图片（门面，路径不变）

`/api/v1/mm/materials/{materialId}/images` 现网动词不变。

- 物料注记 true：读写该物料 `(productModelId, colorId)` 的款色图。
- 物料注记 false：现网 SKU 图。
- 变体物料调用 delete/set-primary 的 `imageId` 必须属于该款色，禁止用 SKU 图表 id 误删。

### 3.3 款色图（新）

权限：`/mm/product-models:read` / `:update`。

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/v1/mm/product-models/{modelId}/images?colorId=` | `colorId` 省略表示不分色键（NULL）。分色款必须传本款色 |
| POST | `.../images/upload?colorId=` | multipart，规则同物料图（含前端 100KB） |
| DELETE | `.../images/{imageId}` | |
| POST | `.../images/{imageId}/set-primary` | |

上传前校验：款号存在；**与本款色池一致**——分色则 `colorId` 必须在 `product_model_colors`；不分色则禁止传 `colorId`（键为 NULL）。池外色 400，不落库。

## 4. 改动面

### 4.1 后端

| 点 | 做 |
|----|----|
| `MaterialRequest` + Mapper | 字段纳入；**create/update 不再 ignore 后无条件抄分类**。变体分类仍强制 true |

## 7. 明确不做

- 变体分类允许 `is_fashion_variant = false`
- 按 `productModelId` 自动 true
- 注记单向门（只许 false→true）
- Wave C `copyImages`
- 图挂 `product_model_colors.id`
- 多态一张 `owner_type` 图片表
- 指定「规范 SKU」当图主人
- 手工变体占用尺码流水 token
- 本期开放跨 `FASHION_VARIANT` 改分类
- 把 BOM / 工厂物料提升到款色
- 本款删色 / 删款号时级联删图或 OSS
- 运行时从 `material_images` copy/并入 `product_model_images`（勾选 true 的逆向提升）
