# 12 — 示例：收货单可打印格式表单

> 编写日期：2026-08-18  
> 状态：**已实现**  
> 前置：单据 PDF 版式收敛（01 §3 / 04）、订购单 PDF 范本（04）已落地

## 1. 需求

从收货单（GoodsReceipt）列表或详情抽屉发起「打印」，以 **A4 纵向**标准单据版式呈现收货单（公司抬头、供应商 / 送货单号、明细表、签核栏）。打印件与预览 PDF 像素级一致；多页明细正确分页，表头每页重复。仓务联**不印单价、金额、币别与汇率**。

收货单为仓务作业单据，**无归档下载需求**：省略 `ExportJobType` / `*PdfExportHandler` / 前端 `ExportButton`（对齐 04 §6 请购单分支）。

**报工入库（`PRODUCTION_REPORT`）不提供打印**：列表 / 详情隐藏打印入口；后端 `GET /{id}/pdf` 返回业务错误。报工单本身即为入库依据。

## 2. 总体流程

```
前端 GR 列表 / 详情 [打印]
   │  PdfPreviewModal + getGoodsReceiptPdfBlob(id)
   ▼
GET /api/v1/wm/goods-receipts/{id}/pdf     ← read，inline，不建作业、不落 OSS
   │
   ▼
GoodsReceiptPdfRenderer.renderOne(id, locale)
   ├─ GoodsReceiptPrintService.getPrintData(id)
   │     ├─ PRODUCTION_REPORT → ValidationException（不提供打印）
   │     ├─ 抬头：factory → company
   │     ├─ 供应商：RemoteSupplierService.findById（code / name / taxId）
   │     └─ 明细：material / transactionUnit fetch；warehouse 批量解析（warehouseId 可空）
   └─ Thymeleaf templates/print/goods-receipt-pdf.html → PDF bytes
   │
   ▼
前端 blob → objectURL → iframe；工具栏 print()
```

禁止再开前端 HTML 打印页 / `/print` 深链 / `autoPrint` / 对外 `print-data` REST。

## 3. 业务决策

| # | 决策点 | 结论 |
|---|--------|------|
| 1 | 产出物 | **仅 PDF 预览 + 浏览器打印**；无归档 Export |
| 2 | 纸张 | **A4 portrait**（对齐订购单） |
| 3 | 数据范围 | 一张 GoodsReceipt + 全量明细（按 itemNo） |
| 4 | 收货类型 | **PURCHASE / OUTSOURCE / MISC 可打**；**PRODUCTION_REPORT 不提供打印** |
| 5 | 供应商 | PURCHASE / OUTSOURCE 显示；其余可空 |
| 6 | 金额 / 币别 | **不展示**单价、金额、币别、汇率（仓务联只打数量；财务快照留在单据主档） |
| 7 | 仓务栏 | 仓库、批次、来源单号写入明细（来源类型 + 单号叠在品名区）；非库存料（如固定资产）仓库可空 |
| 8 | DRAFT | **允许打印**，模板加「草稿」水印 |
| 9 | REVERSED | **允许打印**，模板加「已冲销」水印 |
| 10 | POSTED | 正式版式，无水印 |
| 11 | 权限 | 预览 `/wm/goods-receipts:read` |
| 12 | 签核栏 | **制单**（印 `createdBy` 姓名 + 签字线）／**仓管**（留白签字）；无送货人／收货栏 |

## 4. 打印数据模型

`GoodsReceiptPrintResponse`（一次性返回、全部名称已解析）：

```
公司抬头：companyName / companyAddress / companyPhone / companyTaxId
单据头：receiptNo / receiptDate / status(+Label) / receiptType(+Label)
        factoryName / deliveryNoteNo / remarks
        draft / reversed
供应商：supplierCode / supplierName / supplierTaxId
明细 Item：
        itemNo / materialCode / materialName / materialSpec
        transactionQuantity / unitName / warehouseName
        batchNo / expiryDate / isFoc
        sourceDocType(+Label) / sourceDocNo / sourceDocItemNo / remarks
打印元：createdByName / printedBy / printedAt
```

不组装、不展示单价、金额、币别与汇率。

| 层 | 文件 |

## 7. 验收标准

1. Chrome/Edge：Modal 预览正常；明细少时一页呈现；40+ 行正确分页且每页含表头，签核栏不被截断。
2. 工具栏「打印」仅唤起一次系统对话框；无 autoPrint。
3. 数量右对齐、千分位；中/英/越标签正确；不展示单价、金额、币别与汇率。
4. DRAFT 带草稿水印；REVERSED 带已冲销水印；POSTED 无水印。
5. FOC 行在品名区标注 FOC；非库存料仓库栏可空。
6. `PRODUCTION_REPORT` 无打印按钮；直调 PDF 返回业务错误。
7. 无 `read` 权限访问预览 PDF 返回 403。
