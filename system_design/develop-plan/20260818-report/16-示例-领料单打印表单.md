# 16 — 示例：领料单可打印格式表单

> 编写日期：2026-10-25  
> 状态：**已实现**  
> 前置：单据 PDF 版式收敛（01 §3 / 04）、收货单 PDF 范本（12）、库存盘点 PDF 范本（14）已落地

## 1. 需求

从领料单（`StockIssue` + `StockIssueItem`）列表或详情抽屉发起「打印」，按 **单张领料单号** 打在 **Letter 纵向多联穿孔纸**上（针式击打）。版式是工厂内部领用单：工厂 / 部门 / 类型、明细表、签核栏。打印件与预览 PDF 像素级一致；多页明细正确分页，表头每页重复。仓务联只印拣货所需的数量、单位、仓库、批次，不印单价、金额、成本与凭证。

领料是生产线向本厂仓库领用，不是对外单据。表头不印公司地址、电话、税号和 logo。无归档下载需求：省略 `ExportJobType` / `*PdfExportHandler` / 前端 `ExportButton`（对齐 04 §6、12 收货单、14 盘点单）。

**报工倒冲领料（`PRODUCTION_REPORT`）不提供打印**：列表 / 详情隐藏打印入口；后端 `GET /{id}/pdf` 返回业务错误。倒冲由报工单生成，报工单本身即为依据（对齐收货单对 `PRODUCTION_REPORT` 入库的处理）。

## 2. 为何不用清单 Excel / 进耗存 / 送货单

领料单本身已收束：一张 SI = 单一工厂 × 单一领料日 × 单一领料类型 × 可选部门。仓务要的是「按单号拿这一张去拣货」，不是期间分析。


| 维度 | 05 进耗存 | 10 工单进度 | 送货单（交货单 PDF） | **16 领料单（本设计）** |
| --- | --- | --- | --- | --- |
| 数据 | 期间余额 | 工单齐套 / 备料 | 一张交货单，给客户签收 | **一张领料单，给仓库发料** |
| 产出 | 模板 Excel | 清单或模板 Excel | 仅 PDF 打印 | **仅 PDF 打印** |
| 入口 | 列表工具栏导出 | 列表按筛选导出 | 交货单列表 / 详情 | **领料单列表 / 详情「打印」** |
| 范围 | 期间 × 工厂 | 单厂 + 计划日期 | 交货单 id | **领料单 id（单号）** |
| 数量 | 进耗存结存 | 工单组件需求 / 已领 | 交货行计划量 | **本单 `transactionQuantity`** |
| 仓库 / 批次 | 无拣货栏 | 备料 Sheet | 不印 | **印在明细** |


已有报表填不满这个缺口：

- 进耗存是期间结存，不是某一张领料单。
- 工单进度里的组件领料是工单视角的备料汇总，不是仓务签字联。
- 送货单打在交货单上，标题是「送货单」，数量认交货计划量，给客户签收。`SALES_DELIVERY` 领料仍要一张内部拣货联（仓库、批次、本单实发数量）。两张单不互相替代。送货单专题把「用领料单套打送货单」明确排除在外。

跨多单「期间领料汇总」若需要，另立作业，不与本打印混用。退料单（`stock_issue_returns`）、客户退货单各自是反向单据，本期不打。

## 3. 总体流程

```
前端 SI 列表 / 详情 [打印]
   │  须已有 id；PRODUCTION_REPORT 不显示按钮
   │  PdfPreviewSession + getStockIssuePdfBlob(id)
   ▼
GET /api/v1/wm/stock-issues/{id}/pdf     ← read，inline，不建作业、不落 OSS
   │
   ▼
StockIssuePdfRenderer.renderOne(id, locale)
   ├─ StockIssuePrintService.getPrintData(id)
   │     ├─ PRODUCTION_REPORT → ValidationException
   │     ├─ 无明细 → ValidationException
   │     ├─ 抬头：工厂名；不解析公司地址 / 电话 / 税号 / logo
   │     ├─ 部门：departmentId 可空，有值则解析 code / name
   │     └─ 明细：全量按 itemNo；fetch material / transactionUnit / baseUnit；仓库批量解析
   └─ Thymeleaf templates/print/stock-issue-pdf.html → PDF bytes
   │
   ▼
前端 blob → objectURL → iframe；工具栏 print()
```

禁止再开前端 HTML 打印页 / `/print` 深链 / `autoPrint` / 对外 `print-data` REST。

工厂数据范围与列表一致：`stock_issues` 的 `@Filter` 对 `findById` 生效（`applyToLoadByKey = true`）。范围外的单号按不存在处理。

## 4. 业务决策


| # | 决策点 | 结论 |
| --- | --- | --- |
| 1 | 粒度 | **按单张领料单号打印**；一次一份 PDF。不做批量多单合并 |
| 2 | 产出物 | **仅 PDF 预览 + 浏览器打印**；无 Excel；无归档 Export |
| 3 | 纸张 | **Letter 纵向 216mm × 279mm**，`@page { size: 216mm 279mm; margin: 10mm 6mm 8mm 6mm; }`（对齐送货单 `delivery-note-pdf.html`）。给多联穿孔纸、针式打印机。PDF 只排一联内容，第二联、第三联由复写纸打出，不在 PDF 里复制同样的页 |
| 4 | 数据范围 | 一张 StockIssue + **该单全部明细**（按 `itemNo` 升序读取）；忽略抽屉内物料筛选。打印行按物料 + 仓库 + 批次 + 领料单位 + 基本单位汇总，项次从 1 重编。库存明细仍按来源组件分行 |
| 5 | 可打类型 | **PRODUCTION / COST_CENTER / SCRAP / SAMPLE / SALES_DELIVERY 可打**。标题不随类型改名，类型印在头档 |
| 6 | 倒冲 | **PRODUCTION_REPORT 不提供打印** |
| 7 | 销售交货 | **可打**，作为仓库拣货联。客户签收件仍是交货单上的送货单，不在本模板印价税、尺码矩阵或客户栏 |
| 8 | 空明细 | **拒绝打印**（与过账 `post_requires_lines` 同一前提，文案单独一条） |
| 9 | 未保存 | 无 id 不显示打印、不发请求 |
| 10 | 金额 / 成本 | **不印**单价、金额、成本、币别、`journalEntryId`。过账成本留在库存流水与凭证 |
| 11 | 数量 | 印 **`transactionQuantity` + 领料单位**。交易单位与基本单位不同时，数量格下再印一行基本数量 + 基本单位；相同时不印第二行 |
| 12 | 已退数量 | **不印** `returnedQuantity`。退料、客户退货各有自己的单据，补打领料单仍是当时的发料数 |
| 13 | 来源单 | 印在品名区副行，不单开列，不印来源类型，不印行备注。同一打印行内按原明细顺序用顿号并列 `{sourceDocNo} / {sourceDocItemNo}`；单号空白的来源省去，项次空白则只印单号。一张领料单可混多个来源，来源不能上收到单头。单头备注仍印在表尾 |
| 14 | 仓库 / 批次 | 仓库必有，印在明细，格式 `code - name`。`batchNo` 空串印成空白。**不上收到部门 / 类型那一行**：仓库按行分配，一张领料单可以混仓（生产批量领料、交货批量领料）。只在「全部相同」时改挂表头，列会时有时无，针式联的栏位不固定 |
| 15 | 部门 | 单头可空。有 `departmentId` 时印 `code - name`；没有则该格留空 |
| 16 | DRAFT | **允许打印**。状态印在头档（「草稿」）。不用彩色水印：浅色字在针式复写上打不出来 |
| 17 | REVERSED | **允许打印**。状态印在头档（「已冲销」）。同样不用彩色水印 |
| 18 | POSTED | 正式版式，头档状态为「已过账」 |
| 19 | 合计 | **不做数量合计**。跨物料、跨单位加总没有拣货意义 |
| 20 | 权限 | 预览 `/wm/stock-issues:read`。不新增 `export` 权限 |
| 21 | 签核栏 | **领料**（留白）／**审核**（留白，必有）／**仓管**（留白）／**制单**（印 `createdBy` 姓名 + 签字线）。审核栏是手签空位，不预填 `approvedBy`（该字段是过账人，不是纸面审核人） |
| 22 | 抬头 | **不印**公司地址、电话、税号、logo。抬头左侧是工厂名 |
| 23 | 入口 | 列表操作列 + 详情抽屉「打印」。不做列表工具栏按筛选导出 |


**报表名称（三语）**（单据标题，不随类型改名；类型、状态印在头档）


| locale | 名称 |
| --- | --- |
| zh-CN | 领 料 单 |
| en-US | MATERIAL ISSUE |
| vi-VN | PHIẾU LĨNH LIỆU |


文件名：`SI_{code}.pdf`。

## 5. 打印数据模型

`StockIssuePrintResponse`（一次性返回、全部名称已解析；不对外 REST）：

```
单据头：issueNo / issueDate / status(+Label) / issueType(+Label)
        factoryName / departmentName        ← 部门可空，格式 code - name
        remarks
        draft / reversed                    ← 只驱动头档状态文案，不画彩色水印
明细 Item：
        itemNo / materialCode / materialName / materialSpec
        transactionQuantity / unitName
        baseQuantity / baseUnitName / showBaseQuantity   ← 仅单位不同时 showBaseQuantity=true
        warehouseName / batchNo                         ← 空批号为 null
        sourceDoc                                   ← 已拼好的副行文本，见下
打印元：createdByName / printedBy / printedAt
```

打印行是拣货汇总，不是库存行的 1:1。同一物料、仓库、批次、领料单位、基本单位合成一行；`itemNo` 从 1 重编。行备注不进入打印模型。

来源副行由 PrintService 拼好，模板只判断非空再输出。多个来源按原明细顺序用顿号连接：

```
{sourceDocNo} / {sourceDocItemNo}、{sourceDocNo} / {sourceDocItemNo}
```

单号空白的来源不出现。项次空白时只印单号。不印来源类型。

数量在 Renderer 内预格式化（`#,##0.######`，`Locale.US`，对齐收货单）；模板纯展示。

不组装公司地址、电话、税号、logo，也不组装单价、金额、成本、凭证号、已退数量。

## 6. 版式示意

纸张与页边距对齐送货单，信息区改成内部领用。线条用黑色实线，字号不低于送货单的 8pt，不放 logo、浅灰字和彩色水印，保证针式击打后复写联仍可读。

```
┌──────────────────────────────────────────────┐
│  {工厂名}          领 料 单                     │  Letter 216 × 279 mm
│                    单号: …  日期: …  状态: …   │  ← 三项同一行，收在标题下方，右缘对齐
├──────────────────────────────────────────────┤
│ 部门 / 类型                                    │
├──────────────────────────────────────────────┤
│ 明细（跨页表头重复）                           │
│ 项次 | 物料 | 品名 | 数量 | 单位 | 仓库 | 批次 │
│      品名下：规格、来源副行（单号 / 项次，顿号并列） │
│      数量下：仅单位不同时印基本数量             │
├──────────────────────────────────────────────┤
│ 备注                                           │
│ 领料: ________    审核: ________               │
│ 仓管: ________    制单: {createdByName} ______ │
│ 打印人 / 时间                                  │
└──────────────────────────────────────────────┘
```

签核栏 `page-break-inside: avoid`。审核栏只有标签和签字线，不印姓名。

## 7. 交付物


| 层 | 文件 |
| --- | --- |
| 后端 wm | `StockIssuePrintService` + `Impl`、`StockIssuePrintResponse`、`StockIssuePdfRenderer`、`templates/print/stock-issue-pdf.html`、`GET /{id}/pdf` |
| 后端 i18n | `print.stock_issue.*` 三语（标题、列头、签核）；`validation.stock_issue.production_report_print_not_allowed`；`validation.stock_issue.print_requires_lines` |
| 前端 | `endpoints.stockIssues.pdf` + `getStockIssuePdfBlob` + `print/StockIssuePdfPreviewModal.tsx`；列表操作列与详情抽屉「打印」 |


实现要点：

1. 抬头只取工厂名（`FactoryRepository`）。不查公司地址、电话、税号，不嵌 logo。部门用 basis `DepartmentRepository.findById`，展示 `code - name`。仓库批量 `findAllById`，同样 `code - name`。
2. 明细 `DynamicSpecifications.fetch` material / transactionUnit / baseUnit，按 `itemNo` 排序后，按物料、仓库、批次、交易单位、基本单位汇总，再从 1 编号。规格取 `material.specification`。来源副行只含单号与来源项次。
3. `showBaseQuantity`：`transactionUnitId` 与 `baseUnitId` 不同才为 true。
4. `batchNo` 空白串写成 null，模板不输出空批号。
5. 控制器对齐收货单：`Content-Disposition: inline`，文件名 `SI_{code}.pdf`，权限 `hasAuthority('/wm/stock-issues:read')`。
6. 前端 `PRODUCTION_REPORT` 不渲染打印按钮（列表 `extraActions` 与抽屉均判断 `issueType`）。无 id 不显示。预览 Modal 复用 `PdfPreviewSession`，预览标题 `pages.wm.stockIssue.print.previewTitle`（三语）。
7. 单测对齐 `PhysicalInventoryPrintServiceImplTest`：倒冲拒绝、空明细拒绝、销售交货可组装、同单位不带基本数量、异单位带基本数量、草稿 / 已冲销标记。

校验与文案：

1. 单据不存在：`NotFoundException.resource("entity.stock_issue")`。
2. `PRODUCTION_REPORT`：`validation.stock_issue.production_report_print_not_allowed`。
3. 明细为空：`validation.stock_issue.print_requires_lines`。
4. 以后端为准。前端隐藏按钮只是入口，直调 PDF 仍拒绝。

## 9. 验收标准

1. Chrome / Edge：Modal 预览正常；明细少时一页呈现；40+ 行正确分页且每页含表头，签核栏不被截断。
2. 工具栏「打印」仅唤起一次系统对话框；无 autoPrint。
3. 数量右对齐、千分位；中 / 英 / 越标签正确。页面上没有单价、金额、成本、凭证号、已退数量。
4. 交易单位与基本单位相同只印一行数量；不同时数量下有基本数量。
5. 品名区能看到规格（有则印）和来源单号 + 项次（多个来源顿号并列，无来源类型、无行备注）。空批号为空白。同物料、同仓库、同批次、同单位合并为一行，数量相加，项次从 1 编号。
6. 页面尺寸为 Letter 216mm × 279mm。表头没有公司地址、电话、税号和 logo。草稿、已冲销、已过账都靠头档状态文字区分，没有彩色水印。五种可打类型标题都是「领料单」，类型在头档。
7. `PRODUCTION_REPORT` 无打印按钮；直调 PDF 返回业务错误。0 行直调 PDF 返回业务错误。
8. 无 `read` 权限访问预览 PDF 返回 403。工厂数据范围外的 id 与列表不可见一致。
9. `SALES_DELIVERY` 能打出仓库、批次和本单领料数量；版式不是送货单。
10. 表尾同时有领料、审核、仓管、制单四栏。审核栏为空白签字线；制单栏印创建人姓名。
