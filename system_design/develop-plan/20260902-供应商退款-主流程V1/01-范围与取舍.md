# 01. 主流程 V1：范围、取舍与现状要点

> 评估对象不变：已付款 AP 因数量型采购退货产生应付贷项后，供应商把现金退回公司。  
> As-Is 细节见 [../供应商退款/01-现状与问题.md](../供应商退款/01-现状与问题.md)。本文只保留实施必须知道的缺口，并锁定相对完整设计的简化。

---

## 1. 现状缺口（必须修）

现网应付贷项 V1：

```text
creditMemo.total ≤ apInvoice.remaining
remaining = total − paid − credited
```

全额已付后 `remaining = 0`，贷项无法过账。前端「从发票生成贷项」还用 `remainingAmount > 0` 挡住入口。后端 `createDraftFromApInvoice` 只看可贷数量，不过账公式仍会失败。

`payments` 把方向与子账写死：

```text
RECEIPT      → CUSTOMER → AR Invoice
DISBURSEMENT → SUPPLIER → AP Invoice
```

不能表达供应商退回现金。付款 VOID 会冲银行凭证并回减 `paid_amount`，不能用来记录后来真实发生的入账。

付款核销 `applyAp / restoreAp` 用普通 `findById`，与贷项过账并发时有丢更新风险。本波改 remaining 公式时必须顺手加行锁。

现网 FI 测试几乎不覆盖贷项过账和 Payment 过账。改 remaining 之前先补回归。

---

## 2. 为什么不按完整设计一次做满

完整设计把四条轴绑在同一交付：

1. 贷项开放金额（主路径承重墙）
2. 共享 Payment 的核销状态机与单行 reverse
3. `clearing_date` / `reversal_date` 与凭证换日冲销
4. 外币开放项尾差 + 普通 AP 付款汇兑前置

后三条不是「银行入账核销贷项」的必要条件，却打在每天使用的收付款主路径上。主流程 V1 只做第 1 条，外加最小的退款资金与退款段汇兑。

## 3. 取舍对照

### 3.1 必须留下

| 项 | 原因 |
|----|------|
| 贷项可超过 `remaining`，拆 `applied / refundable` | 否则已付不能贷 |
| `remaining = total − paid − applied_credit` | `credited` 仍表示贷项总额 |
| 新收款用途 `SUPPLIER_REFUND`，不 VOID 原付款 | 银行流水与审计 |
| 退款核贷项，不改原票 `paid_amount` | 原付款仍真实发生 |
| 有有效退款则禁止 VOID 贷项 | 后置阻断前置 |
| 有 `refundable > 0` 的贷项则禁止撤原付款核销 | 拆分按过账时已付状态冻结 |
| 付款与贷项共享 AP 行锁 | 避免 remaining 丢更新 |

### 3.2 本波明确不做（完整设计里有）

| 项 | 本波做法 |
|----|----------|
| 未分配退款、资金先行 | 过账必须一行核销且 `allocated = amount` |
| 一张退款核多张贷项 | 一单核一张；多张贷项开多张退款 |
| 全表 `allocation_status` | STANDARD 行为不变 |
| 单行 reverse | 只整单 VOID |
| 核销日 / 冲销日独立 | 核销随 `payment_date`；冲销走现网 `reverseEntry` |
| 普通 AP/AR 付款汇兑改造 | 不接入 `applyAp / applyAr` |
| 折扣比例转回 | 用实付现金封顶，见 02 §4 |
| 交叉货币（退款币别 ≠ 贷项币别） | 拒绝 |
| 通用供应商开放项账龄 | 不做；用贷项退款状态 + 可退款查询 |

### 3.3 外币与折扣：改闸，不改主模型

完整设计把外币退款绑在「普通 AP 付款汇兑已落地」，并把「原票有任一折扣」当成形成 `refundable` 的禁令。两者都宽于主路径。

本波：

- **外币**：同币即可退。本位币快照与退款段汇兑按贷项汇率 **重乘**。不读 AP 未结本位币。原付款对 AP 留下的本位币残差不在本期修。
- **折扣**：待退款不得超过该票剩余实付现金（`Σ allocated_amount`，不含 `discount_amount`）。部分退货通常可通过；会吃到折扣切片的贷项仍拒绝。

## 4. 会计边界（与完整设计相同）

```text
应付贷项：借 AP / 贷 GR/IR、费用与税；释放收货占用
采购退货：库存与暂估
供应商退款：借银行 / 贷 AP；结清贷项待退款
```

部分已付示例（无折扣）：AP 100 已付 60，贷项 70 → `applied=40`、`refundable=30`。贷项凭证仍按 70；拆分不另出总账。退款只处理 30。

真实退款必须是新 `RECEIPT`。VOID 只纠正原付款本身错误或银行交易未成立。

## 5. 后续增强（回到完整设计时再做）

1. 无行过账与后补核销、`clearing_date`
2. 开放期间 `reversal_date` 换日冲销
3. 核销行 `REVERSED` 审计、单行反向后再核同一贷项
4. 一张退款核多张贷项
5. 普通 AP 付款汇兑 + 开放项 `remaining_base`；之后禁止再重乘
6. 付款折扣比例转回
7. 交叉货币退款、短款容差、贷项冲未来 AP
