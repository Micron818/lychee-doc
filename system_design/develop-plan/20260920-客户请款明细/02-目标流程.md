# 02. 客户请款明细目标流程（To-Be）

> 原则：用户选 **一个客户** 和 **实际出货日闭区间**，系统把该期间已出货行打成一张 PDF。  
> 不落请款单、不改 Delivery / AR / 占用。打印基座对齐销售订单报表（仅预览，禁止前端 HTML 双轨）。

系统未上线：**一次交付**查询组装 + PDF + 出货单列表入口。不做 Excel、邮件、归档 Export、账龄、对账单。

---

## 1. 在作业链上的位置

```text
SO 确认
  → 开 Delivery → 领料发货 StockIssue(SALES_DELIVERY)
  → Delivery 整单出完：status = DELIVERED，actualDeliveryDate 有值
         │
         ├─【本报表】按客户 + actualDeliveryDate 汇总 → 寄客户请款
         │
         └─ 财务从 Delivery 开 AR（可合并）→ 收款核销
```

请款与开票并行：已开票的出货仍进本表（列上标开票状态）。本表 **不** 创建或更新 `ar_invoices`。

## 3. 已锁定决策

| # | 决策点 | 结论 |
|---|--------|------|
| 1 | 产出物 | **PDF 预览 + 浏览器打印**；无 `ExportJobType` / `ExportButton` |
| 2 | 纸张 | **A4 landscape**（尺码动态列 + 价税，对齐 09） |
| 3 | 版式 | **尺码矩阵**（对齐 09 / 15：型号本款色字母、rowspan）。**不印**料号/名称列，**不印**样图。出货单 `remarks`、交货行 `remarks` 必须印 |
| 4 | 入口 | **出货单列表工具栏**「预览/打印」；无行操作 `/{id}/pdf` |
| 5 | 强制条件 | **必须**单一 `customerId` + **必须** `actualDeliveryDate` 闭区间（两端齐全） |
| 6 | 勾选 | 支持 `id_in`（对齐 SO 报表后补能力）；勾选覆盖筛选，仍须同一客户 / 公司 / 币别 |
| 7 | 出货日 | **`deliveries.actualDeliveryDate`**。不用计划出货日、不用订单日、本期不读 `stock_issues.issue_date` |
| 8 | 表头范围 | 只纳入 `status = DELIVERED` 且 `actualDeliveryDate` 非空。`DRAFT` / `RELEASED` / `CANCELLED` 排除 |
| 9 | 交货类型 | 只纳入 `deliveryType = NORMAL`。`SAMPLE`（赠样）、`RETURN`（退回）排除 |
| 10 | 行范围 | 行 `status = DELIVERED` 且 `sourceDocType = SALES_ORDER`。`CANCELLED` 行排除 |
| 11 | 数量 | **净出货** = `issuedQuantity − returnedQuantity`。净量 ≤ 0 跳过该行 |
| 12 | 金额 | 整单已出完时 `issuedQuantity = transactionQuantity`，用行上落库未税/税/含税。净量小于交易量时按净量 / `transactionQuantity` 分摊落库金额（2 位，末行吃尾差见 §5.3） |
| 13 | 币别 / 公司 | 范围内 Delivery 的 `currencyOptionId`、以及 `factoryId → companyId` **必须唯一**；混合则拒绝 |
| 14 | 税率 / 含税 | **展示并合计**（与 SO 报表相反；请款要价税） |
| 15 | 开票状态 | **印在矩阵行**（交货行 `invoiceStatus`），**不**默认过滤。已开票出货仍请款列示。状态不同的尺码**不合并**（进分组键） |
| 16 | 付款条件 | 从行来源 SO 取 `paymentTermId`。唯一则印名称，并以区间截止日 `dateTo` 为基准日算到期日（`RemotePaymentTermService.resolveSchedule`）。多种则印「多种」、不印单一到期日。**不因混条件拒绝** |
| 17 | 收款账号 | 公司默认银行账户（`isDefault = true`）。无默认户留空，**不拒绝** |
| 18 | 金额大写 | 含税合计走 `AmountInWordsSupport`（对齐收款单） |
| 19 | 签核 | 制表人 = 当前用户；审核留白；客户确认留白 |
| 20 | 水印 | **不做**整页水印（只打已出货正式数据） |
| 21 | 权限 | `/sd/deliveries:read` |
| 22 | 行数上限 | 事实行 > 5000 → 业务错误，提示缩小区间 |
| 23 | 无数据 | 范围内无有效行 → `validation.delivery.billing_statement.noPrintableItems` |
| 24 | 模块 | **`lychee-erp-sd`** 直读 Delivery / SO。公司抬头走 Factory→Company。付款条件 / 默认银行走 common Remote。**不**经 `RemoteDeliveryService`（本模块报表） |
| 25 | 部分出货 | 表头未到 `DELIVERED` 的单（`actualDeliveryDate` 仍空）**本期不纳入**。二期再评估按 `StockIssue.issue_date` 行级纳入 |
| 26 | 贷项 / 退货单 | 不列 AR 贷项、不列 `deliveryType = RETURN`。退货只通过行 `returnedQuantity` 净出货 |
| 27 | 开票动作 | 本报表 **不** 调用 `ArInvoiceFromDeliveryService` |

## 4. 总体流程

```
前端 Delivery 列表工具栏 [预览/打印]
   │  勾选非空 → id_in（先校验同一客户/公司/币别）
   │  否则读 ProTable 搜索条件
   │  前端校验：customerId 单一 + actualDeliveryDate between 两端齐全
   │  DeliveryBillingStatementPdfPreviewModal + post blob
   ▼
POST /api/v1/sd/deliveries/billing-statement/pdf     ← read，inline，不建作业、不落 OSS
   │  body: 与列表同源筛选，或 { id_in }
   ▼
DeliveryBillingStatementPdfRenderer.render(params, locale)
    ├─ DeliveryBillingStatementService.getReportData(params)
    │     ├─ requireCustomerAndActualDeliveryDateRange 或 loadByIds
    │     ├─ 查 Delivery：客户、actualDeliveryDate 闭区间、DELIVERED、NORMAL
    │     ├─ 校验币别一致、公司一致（factory → company）
    │     ├─ 查 DeliveryItem（DELIVERED + SALES_ORDER）→ Fact：净量 / 分摊金额 / 备注
    │     ├─ 回追 SalesOrder / SalesOrderItem（PO、内部参号、付款条件）
    │     ├─ Material → Model / Color / Size / Unit
    │     ├─ 按 §3 / 03 §4 分组为尺码矩阵 + rowspan
    │     ├─ 付款条件唯一则 resolveSchedule(dateTo, 含税合计)
    │     ├─ 默认公司银行账户（可空）
    │     └─ 抬头 + 区间 + 合计 + 大写 + 制表人
    └─ Thymeleaf templates/print/delivery-billing-statement-pdf.html → PDF bytes
   │
   ▼
前端 blob → objectURL → iframe；工具栏 print()
```

禁止再开 `/print` 深链、前端 HTML 版式、`autoPrint`、对外 `print-data` REST。

## 5. 筛选与纳入规则

### 5.1 表头

| 条件 | 规则 |
|------|------|
| 客户 | `customerId` 等于所选 |
| 实际出货日 | `actualDeliveryDate >= from AND <= to`（闭区间，含两端） |
| 状态 | `DELIVERED` |
| 类型 | `NORMAL` |
| 作废 | `CANCELLED` 永不纳入 |

勾选路径：先按 id 加载，再套同一套状态/类型硬过滤；客户/公司/币别从命中单派生，不一致拒绝。

### 5.2 明细行

```
纳入：status = DELIVERED
    AND sourceDocType = SALES_ORDER
    AND (issuedQuantity − returnedQuantity) > 0
```

无来源 SO 的行（`sourceDocId` 空）仍可出货展示，PO / 订单号 / 付款条件留空；不因此整表失败。

### 5.3 数量与金额（先 Fact，再矩阵）

```
netQty        = issuedQuantity − returnedQuantity
amountFactor  = netQty / transactionQuantity          // transactionQuantity 必须 > 0

若 netQty = transactionQuantity：
    fact 未税/税/含税 = 行上落库值
否则（该交货行单独分摊，2 位 HALF_UP）：
    factSubtotal = round(subtotalAmount * amountFactor, 2)
    factTax      = round(taxAmount * amountFactor, 2)
    factTotal    = factSubtotal + factTax
```

矩阵行金额 = **Σ 组内 Fact 已分摊金额**（对齐 09 `rowAmount = Σ subtotalAmount`）。  
**不要**再做出货单「末行吃尾差」：矩阵一行跨多尺码，末行语义不成立。合计以 Σ Fact 为准。

禁止用销售订单行 `quantity` / `unitPrice` 重算。单价列印交货行 `unitPrice`（4 位）。

`transactionQuantity <= 0` → 该行跳过并记 warn，不抛整表失败。

无型号物料：不另开料号列；型号格印 `materialCode + " " + materialName`，尺码格空，数量仍进行合计。无 `productModelId` 时分组键带 `materialId`，避免不同无型号料被合成一行。

### 5.4 抬头派生

| 字段 | 来源 |
|------|------|
| 公司抬头 | 唯一 `companyId` → Company（名称 / 地址 / 电话 / 税号 / logo，对齐 SO 报表） |
| 客户 | `Customer` code + name + 账单地址（有则印） |
| 币别 | 唯一 `currencyOptionId` → 字典 code |
| 付款条件 | 行上来源 SO 的 `paymentTermId` 去重 |
| 到期日 | 条件唯一时：`resolveSchedule(termId, dateTo, 含税合计)` 取排程最晚 `dueDate` |
| 收款账号 | `RemoteCompanyBankAccountService.findDefaultByCompanyId`：银行名 / 账号 / 户名；无则空 |

## 6. API

```
POST /api/v1/sd/deliveries/billing-statement/pdf
@PreAuthorize("hasAuthority('/sd/deliveries:read')")
Content-Type: application/json
Accept: application/pdf
Content-Disposition: inline; filename="..."
```

Body 与出货单列表 `DynamicSpecifications` 同源，至少：

```
customerId_eq
actualDeliveryDate_between: "yyyy-MM-dd,yyyy-MM-dd"
```

或：

```
id_in: [1, 2, 3]
```

不建 `export_jobs`，不传 OSS。校验失败用现有 `ValidationException` + `messages*.properties`。

前端：`postDeliveryBillingStatementPdfBlob(params)`，Modal 复用 `PdfPreviewSession`。

## 10. 与销售订单报表的差异

| 维度 | 09 销售订单报表 | 本报表 |
|------|-----------------|--------|
| 数据 | `SalesOrder` / 订购量 | `Delivery` / 净出货量 |
| 日期 | `orderDate` | `actualDeliveryDate` |
| 版式 | 跨单尺码矩阵 + 样图 | **同一套尺码矩阵**；按出货单+型号+色分组；**不印**样图、**不印**料号列 |
| 备注 | SO 头备注进 PO 复合格；行备注进客户订单号下 | 出货单 `remarks` 进出货复合格；交货行 `remarks` 进客户订单号下（`appendDistinctRemark`） |
| 税 | 不印 | 印未税 / 税率 / 税额 / 含税 |
| 账期 / 账号 | 无 | 有（可空 / 多种） |
| 金额大写 | 无 | 含税合计 |
