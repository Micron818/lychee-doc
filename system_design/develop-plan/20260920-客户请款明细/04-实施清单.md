## 2. 已锁定决策（编码时勿改）

见 [02 §3](./02-目标流程.md)。摘要：

1. 强制单一客户 + `actualDeliveryDate` 闭区间  
2. `DELIVERED` + `NORMAL` + 行（`sourceDocType` 空或 `SALES_ORDER`）+ 净出货 > 0  
3. 尺码矩阵 PDF，A4 landscape，仅预览；出货格在左；不印料号列；数量列带单位；出货单/行备注必印  
4. 混公司 / 混币别拒绝；混付款条件不拒绝  
5. 金额走 `LineTaxCalculator`；默认银行先配币别  
6. 不开票、不改库存、不建作业  
7. 分组键含 `deliveryId` + `invoiceStatus`；`unitPrice` / `taxRate` 用 `decimalKey`（`stripTrailingZeros`）；排序先出货再开票状态再型号；PO 合并不含 `colorId`；无型号 rowspan 比 `fallbackMaterialId`

## 5. 验收

- 选客户 A + 某月实际出货日：PDF 只含该客户、该月、`DELIVERED`+`NORMAL` 出货。  
- 数量是净出货；同款同色尺码在动态 Size 列；未税+税=含税，合计与矩阵行加总一致。  
- 左起出货复合格，再型号 / PO / 颜色；无料号/名称/独立单位列；数量格带单位；无型号时身份在型号格。  
- 出货单备注、交货行备注可见。  
- 已开票行仍出现，开票状态在出货复合格可见；同单部分尺码已开票时出货格按状态拆开。  
- 赠样 / 未出完 / 已取消不出现。  
- 缺客户或日期区间：按钮不可用或后端校验，不出空白 PDF。  
- 两个币别或两个公司：拒绝。  
- 两个付款条件：仍能打，条件显示「多种」，无到期日。  
- 无默认银行：仍能打，账号区空；有 USD 请款时不印 VND 默认户（有同币别户时）。  
- 打印件与预览同一 PDF；无导出中心作业。  
- 勾选 `DELIVERED` 可打；批量删除仍只能删 DRAFT。  
- 手工自建行（`sourceDocType` 空）能打，PO / 账期空；`RETURN_PO` 等非销售来源不出现。  
- 同价不同标度（`10.0` / `10.00`）在矩阵里合成一行。

## 6. 实现约定

### 6.1 公司

与 `RemoteDeliveryServiceImpl.getDeliveryForBilling` 相同：`Factory.companyId`。不要从第一张来源 SO 偷 `companyId` 再和 Factory 混用。

请款 Service：先收集命中 Delivery 的不重复 `factoryId`，一次 `factoryRepository.findAllById`，再派生公司集合。不要按单循环 `findById`。

### 6.2 付款条件基准日

用筛选截止日 `dateTo`（勾选路径用命中单 `actualDeliveryDate` 的 max）。不要用 `LocalDate.now()`，重打历史月会漂到期日。

`resolveSchedule` 的金额用本表含税合计。只取排程行最大 `dueDate` 印在表头。

### 6.3 租户

查询走 JPA `@TenantId`。Service **禁止**往 params 塞 `tenantId`。

### 6.4 金额

用 `LineTaxCalculator.calculate(netQty, item.getUnitPrice(), item.getTaxRate())`。不要手写 `divide`，不要按 `net/txn` 乘落库金额。单价展示 4 位。不要 `double`。

### 6.5 默认银行

`remoteCompanyBankAccountService.findDefaultByCompanyId(companyId, currencyOptionId)`。不要只传公司、不要 SD 直查 `company_bank_accounts`。

### 6.6 列表公司

`DeliveryResponse.companyId` 只读派生。`getDeliveryPage` 对本页 `factoryIds` 去重后一次 `findAllById`，再 `setCompanyId`：

```
Set<Long> factoryIds = items.stream().map(DeliveryResponse::getFactoryId)
        .filter(Objects::nonNull).collect(Collectors.toSet());
Map<Long, Long> companyIdByFactoryId = factoryRepository.findAllById(factoryIds).stream()
        .collect(Collectors.toMap(Factory::getId, Factory::getCompanyId));
items.forEach(item -> item.setCompanyId(companyIdByFactoryId.get(item.getFactoryId())));
```

禁止分页循环里逐条 `factoryRepository.findById`。`getDelivery` 单条可用 `findById`。前端勾选比 `companyId`，不要比 `factoryId`。

### 6.7 分组键小数

`GroupKey` 的单价、税率对齐 09 `unitPriceKey`：

```
decimalKey(value) = value == null ? "" : value.stripTrailingZeros().toPlainString()
```

不要把裸 `BigDecimal` 放进 record（`equals` 比标度，`10.0` ≠ `10.00`）。展示仍用原始 `BigDecimal` + `MoneyFormatSupport`。
