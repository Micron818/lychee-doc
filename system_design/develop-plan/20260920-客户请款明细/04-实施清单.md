## 5. 验收

- 选客户 A + 某月实际出货日：PDF 只含该客户、该月、`DELIVERED`+`NORMAL` 出货。  
- 数量是净出货；同款同色尺码在动态 Size 列；未税+税=含税，合计与矩阵行加总一致。  
- 无料号/名称列；无型号时身份在型号格。  
- 出货单备注、交货行备注可见。  
- 已开票行仍出现，开票状态在出货复合格 / 行上可见。  
- 赠样 / 未出完 / 已取消不出现。  
- 缺客户或日期区间：按钮不可用或后端校验，不出空白 PDF。  
- 两个币别或两个公司：拒绝。  
- 两个付款条件：仍能打，条件显示「多种」，无到期日。  
- 无默认银行：仍能打，账号区空。  
- 打印件与预览同一 PDF；无导出中心作业。  
- 批量删除仍只能删 DRAFT。

## 6. 实现约定

### 6.1 公司

与 `RemoteDeliveryServiceImpl.getDeliveryForBilling` 相同：`factoryRepository.findById(factoryId).companyId`。不要从第一张来源 SO 偷 `companyId` 再和 Factory 混用。

### 6.2 付款条件基准日

用筛选截止日 `dateTo`（勾选路径用命中单 `actualDeliveryDate` 的 max）。不要用 `LocalDate.now()`，重打历史月会漂到期日。

`resolveSchedule` 的金额用本表含税合计。只取排程行最大 `dueDate` 印在表头。

### 6.3 租户

查询走 JPA `@TenantId`。Service **禁止**往 params 塞 `tenantId`。

### 6.4 金额

用 `BigDecimal`；分摊 `setScale(2, HALF_UP)`。单价展示 4 位。不要 `double`。
