# 客户请款明细（Customer Billing Statement）

本目录描述 **按客户 + 出货日区间** 汇总已出货交货单，给客户对账、入应付、安排付款的请款明细。  
**不是**销售订单报表（订购量），**不是**单张应收发票，**不是**收款单，**不是**账龄 / 催款，**不是**期初余额对账单。

中文、报表标题、文件名统一为 **客户请款明细**。英文 `Customer billing statement`。越南文 `Bảng kê đề nghị thanh toán`。不要写成「对账单」「催款函」「Debit Note 单据」。

主口径：

```text
SO 确认
  → Delivery（交货）
  → StockIssue(SALES_DELIVERY) 过账
  → Delivery.status = DELIVERED，写入 actualDeliveryDate
  → 【本报表】按客户 + actualDeliveryDate 闭区间汇总已出货行
  → （作业链继续）从 Delivery 开 AR → 收款核销
```

本波只做 **查询 + 服务端 PDF 预览 / 打印**。不新建请款单、不开票、不改占用、不落导出作业。
