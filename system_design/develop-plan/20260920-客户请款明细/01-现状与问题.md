# 01. 客户请款明细现状与问题（As-Is）

> 依据当前代码与文档：`lychee-erp-sd` / `lychee-erp-wm` / `lychee-erp-fi` / `lychee-erp-report` / `lychee-frontend` / 本目录上级财务与报表专案。  
> 本文件只说明「现在有什么、差在哪」。To-Be 见 [02-目标流程.md](./02-目标流程.md)。

---

## 1. 业务缺口

工厂月结常见动作：把某客户本月（或任意出货闭区间）**已经领料发货**的明细列成一张请款件，寄给客户对账后付款。

现网销售侧作业能跑完，但没有这张对外件：

```text
SO → Delivery → StockIssue(SALES_DELIVERY) → Delivery.DELIVERED
                                              → ArInvoice（可合并多张 Delivery）
                                              → Payment(RECEIPT)
```

业务只能：

- 打开货单列表肉眼筛客户 / 日期，或
- 到应收发票列表看已立账的票（未开票的出货看不到），或
- 打销售订单报表（订购量，不是已出货量）

客户拿不到「本期间出了什么、多少钱、对应哪张 PO / 出货单」的套打件。

## 2. 现网各管什么

| 单据 / 报表 | 模块 | 现网能力 | 对请款的含义 |
|-------------|------|----------|--------------|
| `deliveries` / items | SD | 表头客户、计划/实际出货日、币别、金额、`invoiceStatus`；行上数量 / 价税 / `issuedQuantity` / `returnedQuantity` | **请款主数据在这里** |
| `StockIssue` `SALES_DELIVERY` | WM | 从 Delivery 导入、过账后回写出货行 `issuedQuantity`，整单出完写 `actualDeliveryDate` | 出货事实已回写 Delivery，请款**不必**再联 WM |
| `ar_invoices` 从出货生成 | FI | 可单张或合并多张 `DELIVERED` 且未完全开票的 Delivery | 立账作业，不是期间汇总表；发票本身无打印 |
| `payments` RECEIPT | FI | 核销 + 收款单 PDF | 钱进来之后，不是请款 |
| 销售订单报表 | SD | 强制客户 + `orderDate`；跨单尺码矩阵；数量 = `SalesOrderItem.quantity` | 接单确认，不是请款 |
| 收货单 PDF | WM | 采购入库；不印金额 | 采购侧，不是给客户 |
| 账龄 / 催款 | FI | [04-02](../20260817-财务/04-02.系统收款功能.md) 写过；[09](../20260817-财务/09.收付款先资金后核销实施计划.md) 明确本阶段不做 | 内部催收，不是出货请款 |
| 对账单 | 报表规划 | [05](../20260818-report/05-Excel模板填充与进耗存汇总导出.md) 仅提「可加模板」 | 期初 + 发票 − 收款，本波不做 |

`ExportJobType` 无 SD / FI 请款类型。出货单列表无打印按钮；客户搜索是名称 `like`，实际出货日只有表格列、没有日期区间搜索。

## 3. 数据已够、缺的是报表

出货开票已经把计价落到交货行：

- 表头：`customerId`、`actualDeliveryDate`（**仅整单行全部 `DELIVERED` 时**由 `refreshDeliveryHeaderStatus` 写入 `LocalDate.now()`；任一行未出完则表头退回 `RELEASED` 并清空该日）、`currencyOptionId`、`totalAmount`、`invoiceStatus`
- 行：`transactionQuantity` / `issuedQuantity` / `returnedQuantity`、`unitPrice`、`taxRate`、`subtotalAmount` / `taxAmount` / `totalAmount`
- 来源：`sourceDocType = SALES_ORDER` 时能回追 `customerPoNo`、`orderNo`、行上客户内部参号；手工自建行 `sourceDocType` 可为 `null`（现网允许不挂 SO）
- 公司：`factoryId` → Factory → `companyId`（与 `getDeliveryForBilling` 相同）

缺口是：

1. 没有「单一客户 + 实际出货日闭区间」的强制查询入口  
2. 没有把多张已出货 Delivery 打成一张客户件的 PDF  
3. 销售订单报表口径错误（订购不是出货）  
4. 合并开 AR 票不能替代期间请款（一张票 ≠ 一个月的出货清单；票也打不出来）

## 4. 容易用错的现网对象

| 对象 | 为什么不能当请款 |
|------|------------------|
| 销售订单报表 | 数量是订购量；日期是订单日；尺码矩阵给内部确认 |
| `Delivery.plannedDeliveryDate` | 计划日，月结请款认实际出货日 |
| `transactionQuantity` | 交货单计划出货量；未发完不等于已出货 |
| `RELEASED` 部分出货 | 现网未整单出完就不写 `actualDeliveryDate`；本期请款按表头日，这些行月结看不到 |
| `GoodsReceipt` | 采购入库；用户口语里的 delivery→GR→AR 是把采购链和销售链混在一起 |
| `ArInvoice` 列表 | 只覆盖已开票；未开票出货缺席；无套打 |
| 收款单 PDF | 已收款凭证 |

## 5. 与账龄、对账单的边界（本波不碰）

| 报表 | 口径 | 本波 |
|------|------|------|
| **客户请款明细** | 期间内已出货行 + 价税合计 | **做** |
| 应收账龄 / 催款 | 未结 AR 按到期日分段 | 不做 |
| 客户对账单 | 期初 + 本期发票/出货 − 收款 = 期末 | 不做 |
| 单张送货单 | 一单一张交货单，客户现场签收 | 见 [../20260921-送货单打印/README.md](../20260921-送货单打印/README.md)（本请款波不做） |
| AR 发票打印 | 一单一张 | 不做 |
