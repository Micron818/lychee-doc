# 销售订单月汇总表

本目录是单据 PDF 新架构的 **P1**：第一张用 `lychee-pdf` 出的业务报表。

销售订单列表上已有一张跨单尺码矩阵。那张报表的用户侧名称改为 **销售明细表**，继续用 Thymeleaf + openhtmltopdf，不在本阶段换引擎。本目录设计的是另一张表：**销售订单月汇总表**。

```text
销售订单列表
  ├─ [销售明细表]     客户 + 订单日期，或勾选订单
  │     尺码矩阵、原币金额、样图、签核
  │     POST /api/v1/sd/sales-orders/report/pdf
  │     引擎不变（P2 第 11 张才迁）
  └─ [销售订单月汇总表]  公司 + 订单年月（SalesOrder.orderDate）
        订单 / 状态 / 客户 / 产品代号 / 单位 / 数量 / 本位币金额
        数量按单位合计；金额先按状态，再总合计
        POST /api/v1/sd/sales-orders/monthly-summary/pdf
        ChromiumPdfClient → lychee-pdf
```

**状态：已实现**（2026-11-16）。无新表、无新菜单、不归档、不出 Excel。
