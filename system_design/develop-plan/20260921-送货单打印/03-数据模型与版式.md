# 03. 数据模型与版式

> 本波 **不建表、不改 Delivery / 领料 / AR schema**。只定义打印 DTO 与 PDF 版式。  
> 流程以 [02-目标流程.md](./02-目标流程.md) 为准。

---

## 1. 无新表

送货单是交货单的只读打印投影。不新增 `delivery_notes`、不写签收栏、不改 `issuedQuantity` / `invoiceStatus`。

复用：

```
deliveries
delivery_items
sales_orders / sales_order_items          // PO、内部参号、客户订单号
factories / companies / customers         // 抬头、送货地址回退
materials / product_models / colors / product_sizes / material_units
users                                     // 制单 createdBy
```

## 2. 查询关联

```
Delivery（id）
  ├─ factoryId → Factory.name + companyId → Company
  ├─ customerId → Customer（code / name / taxId / phone / contact* / addressShipping）
  ├─ shippingAddress / carrierName / trackingNumber
  ├─ plannedDeliveryDate / actualDeliveryDate
  ├─ deliveryNo / deliveryType / status / remarks / createdBy
  └─ DeliveryItem[]（非 CANCELLED + source 空或 SALES_ORDER + transactionQuantity > 0）
        ├─ transactionQuantity / remarks / transactionUnitId
        ├─ materialId → Material → Model / Color / Size / Unit
        └─ sourceDocId / sourceDocItemId → SalesOrder / SalesOrderItem
              ├─ customerPoNo / orderNo
              └─ customerInternalRefNo / customerOrderNo
```

无有效明细 → 校验错误，不渲染空表。

## 3. 打印数据模型

`DeliveryNotePrintResponse`（一次性返回、名称已解析）：

```java
public class DeliveryNotePrintResponse {
    // 公司抬头
    String companyName;
    String companyAddress;
    String companyPhone;
    String companyTaxId;
    String companyLogoDataUri;          // 可空

    // 单据头
    Long deliveryId;
    String deliveryNo;
    String deliveryType;                // NORMAL / SAMPLE
    String deliveryTypeLabel;
    String status;                      // DRAFT / RELEASED / DELIVERED
    String statusLabel;
    boolean draft;                      // status == DRAFT → 水印
    String factoryName;
    LocalDate plannedDeliveryDate;
    LocalDate actualDeliveryDate;       // 可空
    String shippingAddress;             // 已按 02 §3 #15 回退
    String carrierName;                 // 可空
    String trackingNumber;              // 可空
    String remarks;                     // 表头备注，可空

    // 客户
    String customerCode;
    String customerName;
    String customerTaxId;               // 可空
    String customerPhone;               // 可空
    String customerContactPerson;       // 可空
    String customerContactPhone;        // 可空

    List<SizeColumn> sizeColumns;       // 本单尺码联集，排序对齐 09 §6.3
    List<MatrixRow> rows;
    BigDecimal totalQuantity;
    boolean unitMixed;                  // 行 unitName 去重后 size ≠ 1
    String totalQuantityUnit;           // !unitMixed 时的单位名；混用必须 null

    String preparedByName;              // createdBy
    String printedBy;                   // 当前用户
    LocalDateTime printedAt;
}

public static class SizeColumn {
    Long productSizeId;
    String code;
    String name;
    Integer sequence;
}

public static class MatrixRow {
    Long salesOrderId;                  // 可空
    String salesOrderNo;
    String customerPoNo;
    String customerInternalRefNo;
    String customerOrderNo;
    String itemRemarks;                 // 组内交货行 remarks 去重拼接

    Long productModelId;
    String productModelCode;            // 纯款号；Renderer 拼 15 的 label
    String productModelName;
    String colorSkuCode;
    String productModelLabel;           // 无型号时 = materialCode + " " + materialName
    Long colorId;
    String colorName;
    String unitName;                    // 印在数量列，不另开单位列
    Long fallbackMaterialId;            // 仅 productModelId == null；rowspan 必须用

    Map<Long, BigDecimal> sizeQuantities;
    BigDecimal rowQuantity;

    int productModelRowspan;
    boolean showProductModel;
    int orderRefRowspan;
    boolean showOrderRef;
    int colorNameRowspan;
    boolean showColorName;
}
```

**不**建：`unitPrice` / `taxRate` / `subtotalAmount` / `currencyCode` / `invoiceStatus` / `materialCode` 独立列 / `companyLogo` 以外的图。  
无型号时身份只写在 `productModelLabel`。  
`compactSizes` **不**放进 PrintResponse：Renderer 按 `sizeColumns.size() > 6` 写入模板 model（Letter 纵向内容区约 204mm，阈值早于请款的 `> 8`）。

Renderer 预格式化日期 / 数量 / `totalQuantityDisplay`（千分位 + 可选单位）。模板只做 `th:text` / `th:if` / `th:rowspan` / 水印 class / `compact-sizes`。禁止模板里对 `rows` 做 Set 去重算混用单位。

## 4. 矩阵组装

对齐 [09 §6](../20260818-report/09-示例-销售订单报表.md) + [15](../20260818-report/15-工厂订单与销售订单型号色号展示.md)。数量改 `transactionQuantity`。  
**不要**复制请款的 `deliveryId` / `invoiceStatus` / `LineTaxCalculator` 分组。

### 4.1 平坦事实行（Fact）

每个纳入的 `DeliveryItem` 产出一条 Fact：

- 来源 SO：`salesOrderId` / `salesOrderNo` / `customerPoNo` / 内部参号 / 客户订单号
- 物料：`productModelId` / `colorId` / `productSizeId` / `unitId` / `materialId`
- 数量：`transactionQuantity`
- 行 `remarks`

### 4.2 分组键

```
groupKey = (
  salesOrderId,                 // Long，可空；null 与 null 视为同一来源（手工行）
  customerPoNo,                 // nullToEmpty
  customerInternalRefNo,        // nullToEmpty
  customerOrderNo,              // nullToEmpty
  productModelId,
  colorId,
  fallbackMaterialId,           // productModelId == null 时 = materialId，否则 null
  unitId
)
```

字符串字段进键前必须 `nullToEmpty`（请款 / `SalesOrderReportServiceImpl` 同名方法：`null → ""`）。禁止 `null` 与 `""` 分成两组。`salesOrderId` 保持 `Long`，不要改成 `"null"` 字符串。

**禁止**把 `materialId` 放进有型号行的键：一色一尺码是不同 Material，放进去就合不成矩阵。  
**禁止**把单价、税率、开票状态放进键：本单不印这些，放入会把同一款色拆成多行。

组内：

- `sizeQuantities[sizeId] += printQty`（`productSizeId == null` 只累加 `rowQuantity`，尺码格空）
- `rowQuantity = Σ printQty`
- `itemRemarks`：复用 `SalesOrderReportServiceImpl.appendDistinctRemark` 语义

手工自建行：`salesOrderId` / `salesOrderNo` / `customerPoNo` 均可空。同款（或无型号时同一 `fallbackMaterialId`）多色会进同一 `salesOrderId == null` 的 PO 合并（见 §4.5），这是允许的，不要为「空 PO」另造分组键去拆开。

### 4.3 动态尺码列

本单全部 Fact 的 `productSizeId` 去重，排序同 09 §6.3（`PrefixedCode`：prefix ASC、sequence ASC NULLS LAST、name ASC）。

### 4.4 行排序（服务视觉合并）

排序键必须是 **纯款号** `productModelCode`，**禁止**用 15 的展示标签 `productModelLabel`（带色字母，会把同款两色拆到不相邻位置，PO 列无法连续 rowspan）。

```
productModelCode ASC（无型号用 materialCode；再比 fallbackMaterialId）
→ salesOrderNo / customerPoNo ASC     // 字符串 nullToEmpty；salesOrderId 空排在有单号之前或之后均可，但须稳定
→ colorSkuCode / colorName ASC        // 15 §4.3：禁止把色提前到 PO/订单之前
→ customerInternalRefNo / customerOrderNo ASC
```

同款两个 PO、各两色时，排序后是「PO-1 的各色连续，再 PO-2 的各色」。同一款色字母会在两个 PO 段各出现一次、中间被另一色切开——**这是连续 rowspan 的固有结果，不要改成按色再按 PO 去粘第一列**（那会拆掉 PO 列合并）。继承 [15 §4.3](../20260818-report/15-工厂订单与销售订单型号色号展示.md)。

### 4.5 视觉合并（rowspan）

继承 15 的妥协，**不要**写成「树形：型号 → PO → 颜色」。HTML 第一列不是纯款父级。

15 之后：

- 型号列展示款色复合标签（`Z01139-A` / `Z01139-B`），rowspan 键含 `colorId`，**同款两色第一列拆开**
- 客户 PO 列仍按纯款 + 订单合并（**不含** `colorId`），同款两色共用一个 PO 格。格内只印 `customerPoNo`，不印 `salesOrderNo`

因此同款同单两色时，视觉是 **中间列（PO）跨过已拆开的第一列（型号）做横向交叉合并**，不是从左到右逐层包含。请款明细 [03 §5.3](../20260920-客户请款明细/03-数据模型与版式.md) 写的「树形」同样不适用于 15 之后的型号列，本专题不沿用该词。

`modelKey` = `productModelId != null ? productModelId : fallbackMaterialId`（对标请款 `DeliveryBillingStatementServiceImpl.modelKey`）。无型号必须比 `fallbackMaterialId`。**不要**抄 `SalesOrderReportServiceImpl.applyRowspans` 只比 `productModelId`：两笔无型号辅料的 `productModelId` 都是 null，会被合成一格。

| 列 | 连续相等键 |
|----|------------|
| 型号 | `modelKey` + `colorId` |
| 客户 PO | `modelKey` + `salesOrderId`（**不含** `colorId`；`salesOrderId` 双方均为 null 时 `Objects.equals` 为 true，空 PO 会合并。销售订单号不印，合并键仍含 `salesOrderId`） |
| 颜色 | 上一项 + `colorId` |

算法同 09 §6.5（连续扫描，不相邻不合并）。内部参号、客户订单号、尺码、数量每行都印。

空 PO 格：模板见 §5.3，必须保底高度，防止 `customerPoNo` 为空时单元格塌陷、边框走样。

## 5. PDF 版式

模板：`lychee-erp-sd/src/main/resources/templates/print/delivery-note-pdf.html`  
Renderer：`DeliveryNotePdfRenderer`  
共用：`PdfRenderSupport`、`StorageImageHelper`（仅公司 logo）、`ProductModelLabels`（15）。  
数量千分位 **不要**走 `MoneyFormatSupport`（该类只有 `moneyFormat` / `unitPriceFormat`，本单不印金额）。Renderer 与收货单 / 请款 / SO 报表相同：

```
DecimalFormat quantityFmt = new DecimalFormat("#,##0.######", DecimalFormatSymbols.getInstance(Locale.US));
```

仓务联风格对齐收货单：**无金额**。矩阵骨架对齐 09，去掉价税列与出货格。纸张 **Letter 纵向**（`@page { size: 216mm 279mm; margin: 10mm 6mm 8mm 6mm; }`），适配多联穿孔纸。上边距留给顶边撕线。

### 5.1 页头（每页重复）

- 左：公司 logo（可空）+ 名称 / 地址 / 电话。左栏吃掉标题与单号以外的宽度，公司名保持一行。**不印**公司税号  
- 中：标题「送货单」（固定约 52mm）  
- 右：交货单号、送货日期（有实际交货日才印，标签 `print.delivery_note.actualDeliveryDate` = 送货日期；固定约 52mm，不换行）。**不印**打印时间、状态、交货类型

`DRAFT` 时整页水印，文案 `print.delivery_note.draftWatermark`。水印按纵向页定位（约 `top: 90mm; left: 25mm`）。

### 5.2 信息区

客户信息与承运、备注同一条流式栏（`info-flow` 里 `inline-block`），短字段并排，不各占一行。可空项用 `th:if` 摘掉，不影响其余项。送货地址、承运/运单、备注允许在栏内换行。

顺序：客户代码 / 名称（必印）、电话、联系人 / 联系电话（有人无电话只印人）、送货地址、承运商 / 运单号（皆空则不印）、表头备注。

**不印**：客户税号、计划交货日、工厂、信息区里的实际交货日（已上页眉，称送货日期）。这些字段仍由 Service 组装，只是模板不输出。不要印账单地址、付款条件、银行、币别。

### 5.3 明细表（尺码矩阵）

**不设料号、名称、独立单位列、独立尺码列、价税列。** 列序：

| 型号* | 客户PO* | 颜色* | 内部参号 | 客户订单号 | S | M | … | 数量 |
|-------|---------|-------|----------|------------|---|---|-----|------|

`*` = rowspan，规则见 §4.5。不要在表头注释里写「树形：型号 → PO → 颜色」。

数量列印 `{rowQuantity} {unitName}`。

**客户 PO 格**只印 `{customerPoNo}`。`salesOrderNo` 不印；合并键仍含 `salesOrderId`。

PO 为空时（手工自建、无 SO）：单元格仍须占位。模板约定：

- `td.order-ref-cell` 设 `min-height`（建议 ≥ 24pt）+ `vertical-align: top`
- `div.order-ref-line` **始终输出**；无文本时用 CSS `:empty::before { content: '\00a0'; }`，禁止因 `th:text` 空串把 div 高度收成 0
- 不要用 `th:if` 把这一行摘掉

**客户订单号格**（对齐 09）：主行印 `customerOrderNo`；其下印 `itemRemarks`。

**无型号物料**：型号格 = `materialCode + " " + materialName`；颜色空；尺码格空；数量仍在「数量」列。

**紧凑尺码**（对齐请款，不是 09 文档里的口头「略缩字号」）：

| 项 | 锁定 |
|----|------|
| 判定 | Renderer：`compactSizes = sizeColumns.size() > 6`（Letter 纵向比请款 A4 横向窄，阈值早于请款的 `> 8`） |
| 模板 | `<table class="items-table" th:classappend="${o.compactSizes} ? 'compact-sizes'">` |
| CSS | `.items-table.compact-sizes th, .items-table.compact-sizes td { font-size: 7pt; padding: 1pt 2pt; }` |

漏掉 class 时 8+ 码会撑出页边。单测：6 列 `false`，7 列 `true`。

### 5.4 合计与签核

- Service 填 `totalQuantity`、`unitMixed`、`totalQuantityUnit`（混用则 unit 为 null）  
- Renderer 填模板 `totalQuantityDisplay`：`quantityFmt` 千分位 +（`!unitMixed` 时）空格 + `totalQuantityUnit`。模板只 `th:text` 这一串  
- 签核从左到右：客户签收（空线，其下「签收日期」再接一条日期线） / 送货人（空线） / 制单（已填姓名 + 线）。列印账号与时间在制单栏签字线下方，与「签收日期」同一行

多页：`thead` 重复；合计与签核只在最后一页（对齐订购单 / 收货单）。

`unitMixed` 判定：矩阵行 `unitName` 去重（忽略空白）后 size ≠ 1。不要在 Thymeleaf 里算。

### 5.5 文件名

```
{print.delivery_note.fileName}_{deliveryNo}.pdf
```

`deliveryNo` 做文件名安全截断（同 SO 报表 `safeCustomer` 的字符过滤）。

中文文件名片段：`送货单`；英文：`DeliveryNote`；越南文：`PhieuGiaoHang`。

## 7. 打印文案 key（新增）

`docTitle` / `fileName` / `draftWatermark` / `deliveryNo` / `status` / `deliveryType` / `plannedDeliveryDate` / `actualDeliveryDate` / `factory` / `customer` / `taxId` / `phone` / `contactPerson` / `contactPhone` / `shippingAddress` / `carrier` / `trackingNumber` / `remarks` / `productModel` / `orderRef` / `color` / `customerInternalRefNo` / `customerOrderNo` / `quantity` / `totalQuantity` / `preparedBy` / `deliveredBy` / `customerSign` / `signDate` / `printedBy` / `printedAt`
