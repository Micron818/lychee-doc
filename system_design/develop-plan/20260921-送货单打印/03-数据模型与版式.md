# 03. 数据模型与版式

> 本波 **不建表、不改 Delivery / 领料 / AR schema**。只定义打印 DTO 与 PDF 版式。  
> 流程以 [02-目标流程.md](./02-目标流程.md) 为准。

---

## 1. 无新表

送货单是交货单的只读打印投影。不新增 `delivery_notes`、不写签收栏、不改 `issuedQuantity` / `invoiceStatus`。

复用：

```
deliveries
delivery_items
sales_orders / sales_order_items          // PO、内部参号、客户订单号
factories / companies / customers         // 抬头、送货地址回退
materials / material_units
users                                     // 制单 createdBy
```

## 2. 查询关联

```
Delivery（id）
  ├─ factoryId → Factory.name + companyId → Company
  ├─ customerId → Customer（code / name / taxId / phone / contact* / addressShipping）
  ├─ shippingAddress / carrierName / trackingNumber
  ├─ plannedDeliveryDate / actualDeliveryDate
  ├─ deliveryNo / deliveryType / status / remarks / createdBy
  └─ DeliveryItem[]（非 CANCELLED + source 空或 SALES_ORDER + transactionQuantity > 0）
        ├─ transactionQuantity / remarks / transactionUnitId
        ├─ materialId → Material（code / name）/ Unit
        └─ sourceDocId / sourceDocItemId → SalesOrder / SalesOrderItem
              ├─ customerPoNo / orderNo
              └─ customerInternalRefNo / customerOrderNo
```

无有效明细 → 校验错误，不渲染空表。

## 3. 打印数据模型

`DeliveryNotePrintResponse`（一次性返回、名称已解析）：

```java
public class DeliveryNotePrintResponse {
    // 公司抬头
    String companyName;
    String companyAddress;
    String companyPhone;
    String companyEmail;                // 可空；有值才印
    String companyTaxId;
    String companyLogoDataUri;          // 可空

    // 单据头
    Long deliveryId;
    String deliveryNo;
    String deliveryType;                // NORMAL / SAMPLE
    String deliveryTypeLabel;
    String status;                      // DRAFT / RELEASED / DELIVERED
    String statusLabel;
    boolean draft;                      // status == DRAFT → 水印
    String factoryName;
    LocalDate plannedDeliveryDate;
    LocalDate actualDeliveryDate;       // 可空
    String shippingAddress;             // 已按 02 §3 #15 回退
    String carrierName;                 // 可空
    String trackingNumber;              // 可空
    String remarks;                     // 表头备注，可空

    // 客户
    String customerCode;                // 仍组装，模板不印（公司内部代码）
    String customerName;
    String customerTaxId;               // 可空
    String customerPhone;               // 可空
    String customerContactPerson;       // 可空
    String customerContactPhone;        // 可空

    List<MatrixRow> rows;               // 每个物料一行，不再做尺码矩阵
    BigDecimal totalQuantity;
    boolean unitMixed;                  // 行 unitName 去重后 size ≠ 1
    String totalQuantityUnit;           // !unitMixed 时的单位名；混用必须 null

    String preparedByName;              // createdBy
    String printedBy;                   // 当前用户
    LocalDateTime printedAt;
}

public static class MatrixRow {
    Long materialId;
    String materialCode;               // 排序用，不单独开列
    String materialName;               // 物料名称，印 material.name
    String customerPoNo;
    String customerInternalRefNo;
    String customerOrderNo;
    String itemRemarks;                 // 组内交货行 remarks 去重拼接
    String unitName;
    BigDecimal rowQuantity;

    int materialNameRowspan;
    boolean showMaterialName;
    int orderRefRowspan;
    boolean showOrderRef;
}
```

**不**建：`unitPrice` / `taxRate` / `subtotalAmount` / `currencyCode` / `invoiceStatus` / 尺码矩阵 / `companyLogo` 以外的图。  
物料名称印 `material.name`（时尚 SKU 的名称本身已含款色码）。不另拼料号，不另开颜色列、尺码列。

Renderer 预格式化日期 / 数量 / `totalQuantityDisplay`（千分位 + 可选单位）。模板只做 `th:text` / `th:if` / `th:rowspan` / 水印 class。禁止模板里对 `rows` 做 Set 去重算混用单位。

## 4. 明细组装

数量用 `transactionQuantity`。**不要**复制请款的 `deliveryId` / `invoiceStatus` / `LineTaxCalculator` 分组，也不要再做成尺码矩阵。

### 4.1 平坦事实行（Fact）

每个纳入的 `DeliveryItem` 产出一条 Fact：

- 来源 SO：`customerPoNo` / 内部参号 / 客户订单号（销售订单号不进打印行）
- 物料：`materialId` / `unitId`
- 数量：`transactionQuantity`
- 行 `remarks`

### 4.2 分组键

每个物料一行。同一物料只在客户 PO、客户订单号、内部参号或单位不同时拆成多行。

```
groupKey = (
  materialId,
  customerPoNo,                 // nullToEmpty
  customerOrderNo,              // nullToEmpty
  customerInternalRefNo,        // nullToEmpty
  unitId
)
```

字符串字段进键前必须 `nullToEmpty`（`null → ""`）。禁止 `null` 与 `""` 分成两组。  
**不要**把 `salesOrderId`、型号、颜色、尺码放进键：客户看到的是物料和客户 PO。两张销售订单若物料、客户 PO、客户订单号、内部参号、单位都相同，数量合并。  
**禁止**把单价、税率、开票状态放进键。

组内：

- `rowQuantity = Σ printQty`
- `itemRemarks`：复用去重拼接（相同备注只留一次）

手工自建行：`customerPoNo` 可空。同一物料上 `null` 与 `""` 的 PO 合成一行。

### 4.3 行排序

```
materialCode ASC
→ materialId ASC                 // 编号相同仍把不同物料分开，保证 rowspan 连续
→ customerPoNo ASC               // nullToEmpty
→ customerOrderNo ASC
→ customerInternalRefNo ASC
→ unitName ASC
```

主序是物料编号、客户 PO、客户订单号。后三项只在前三项相同时稳定次序。

### 4.4 视觉合并（rowspan）

连续扫描，不相邻不合并。

| 列 | 连续相等键 |
|----|------------|
| 物料名称 | `materialId` |
| 客户 PO | `materialId` + `customerPoNo`（`nullToEmpty`；双方皆空视为相同） |

客户订单号、内部参号、单位、数量每行都印。客户订单号格其下仍印 `itemRemarks`。

空 PO 格：模板见 §5.3，必须保底高度，防止 `customerPoNo` 为空时单元格塌陷、边框走样。

## 5. PDF 版式

模板：`lychee-erp-sd/src/main/resources/templates/print/delivery-note-pdf.html`  
Renderer：`DeliveryNotePdfRenderer`  
共用：`PdfRenderSupport`、`StorageImageHelper`（仅公司 logo）。  
数量千分位 **不要**走 `MoneyFormatSupport`（该类只有 `moneyFormat` / `unitPriceFormat`，本单不印金额）。Renderer 与收货单相同：

```
DecimalFormat quantityFmt = new DecimalFormat("#,##0.######", DecimalFormatSymbols.getInstance(Locale.US));
```

仓务联风格对齐收货单：**无金额**。纸张 **Letter 纵向**（`@page { size: 216mm 279mm; margin: 10mm 6mm 8mm 6mm; }`），适配多联穿孔纸。上边距留给顶边撕线。

### 5.1 页头（每页重复）

- 左：公司 logo（可空）+ 名称 / 地址 / 电话 / 邮箱（`companyEmail` 有值才印，标签 `print.delivery_note.email`）。左栏吃掉标题与单号以外的宽度，公司名保持一行。**不印**公司税号
- 中：标题「送货单」（固定约 52mm）
- 右：交货单号；其下送货日期标签**固定印出**（`print.delivery_note.actualDeliveryDate`，无实际交货日时值留空，避免抬头高度跳动）；再其下并列印打印时间（`print.delivery_note.printedAt`，`yyyy-MM-dd HH:mm`）。右栏约 58mm，不换行。**不印**列印账号、状态、交货类型

`DRAFT` 时整页水印，文案 `print.delivery_note.draftWatermark`。水印按纵向页定位（约 `top: 90mm; left: 25mm`）。

### 5.2 信息区

客户信息与承运、备注同一条流式栏（`info-flow` 里 `inline-block`），短字段并排，不各占一行。可空项用 `th:if` 摘掉，不影响其余项。送货地址、承运/运单、备注允许在栏内换行。

顺序：客户名称（必印）、电话、联系人 / 联系电话（有人无电话只印人）、送货地址、承运商 / 运单号（皆空则不印）、表头备注。

**不印**：客户代码（公司内部使用）、客户税号、计划交货日、工厂、信息区里的实际交货日（已上页眉，称送货日期）。客户代码与税号仍由 Service 组装，只是模板不输出。不要印账单地址、付款条件、银行、币别。

### 5.3 明细表（每个物料一行）

**不设尺码矩阵、颜色列、型号列、价税列。** 列序：

| 物料名称* | 客户PO* | 客户订单号 | 内部参号 | 单位 | 数量 |
|-----------|---------|------------|----------|------|------|

`*` = rowspan，规则见 §4.4。物料名称印 `material.name`。

数量列只印数量。单位在独立的单位列。

**客户 PO 格**只印 `{customerPoNo}`。不印销售订单号。

PO 为空时（手工自建、无 SO）：单元格仍须占位。模板约定：

- `td.order-ref-cell` 设 `min-height`（建议 ≥ 24pt）+ `vertical-align: top`
- `div.order-ref-line` **始终输出**；无文本时用 CSS `:empty::before { content: '\00a0'; }`，禁止因 `th:text` 空串把 div 高度收成 0
- 不要用 `th:if` 把这一行摘掉

**客户订单号格**：主行印 `customerOrderNo`；其下印 `itemRemarks`。

### 5.4 合计与签核

- Service 填 `totalQuantity`、`unitMixed`、`totalQuantityUnit`（混用则 unit 为 null）
- Renderer 填模板 `totalQuantityDisplay`：`quantityFmt` 千分位 +（`!unitMixed` 时）空格 + `totalQuantityUnit`。模板只 `th:text` 这一串
- 签核从左到右：客户签收（空线，其下「签收日期」再接一条日期线） / 送货人（空线） / 制单（已填姓名 + 线）。**不印**列印账号与打印时间（打印时间已在页眉）

多页：`thead` 重复；合计与签核只在最后一页（对齐订购单 / 收货单）。

`unitMixed` 判定：行 `unitName` 去重（忽略空白）后 size ≠ 1。不要在 Thymeleaf 里算。

### 5.5 文件名

```
{print.delivery_note.fileName}_{deliveryNo}.pdf
```

`deliveryNo` 做文件名安全截断（同 SO 报表 `safeCustomer` 的字符过滤）。

中文文件名片段：`送货单`；英文：`DeliveryNote`；越南文：`PhieuGiaoHang`。

## 7. 打印文案 key（新增）

前缀 `print.delivery_note.`，至少：

`docTitle` / `fileName` / `draftWatermark` / `deliveryNo` / `status` / `deliveryType` / `plannedDeliveryDate` / `actualDeliveryDate` / `factory` / `customer` / `taxId` / `phone` / `email` / `contactPerson` / `contactPhone` / `shippingAddress` / `carrier` / `trackingNumber` / `remarks` / `materialName` / `productModel` / `orderRef` / `color` / `unit` / `customerInternalRefNo` / `customerOrderNo` / `quantity` / `totalQuantity` / `preparedBy` / `deliveredBy` / `customerSign` / `signDate` / `printedBy` / `printedAt`

明细有独立单位列（`print.delivery_note.unit`）。合计在单位不混用时仍把单位拼在数量后面。不要临时发明 `contactTel` / `customerPhone2`。
