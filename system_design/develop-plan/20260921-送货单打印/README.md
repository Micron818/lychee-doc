# 送货单打印（Delivery Note）

本目录描述 **单张交货单** 的客户签收打印件：货到客户时跟车点货、签字盖章。  
**不是**交货单作业对象本身（菜单仍是交货单 DN），**不是**客户请款明细（期间汇总 + 价税），**不是**库存领料单，**不是**装箱单，**不是**电子签收（POD）。

中文打印标题、文件名统一为 **送货单**。英文 `Delivery Note`。越南文 `Phiếu giao hàng`。  
系统单据、菜单、表名、API 资源仍叫 **交货单** / `deliveries` / DN。不要把实体或菜单改名为送货单。不要写成「出货单」「发货单」作正式打印标题。

主口径：

```text
SO 确认
  → 开 Delivery（交货单）→ 下达 RELEASED
  → 【本打印】按一张 Delivery 打送货单 PDF → 跟车 → 客户签收
  → 领料 StockIssue(SALES_DELIVERY) 过账
  → Delivery.status = DELIVERED，写入 actualDeliveryDate
  → （作业链继续）客户请款明细 / 从 Delivery 开 AR → 收款核销
```

本波只做 **单张 PDF 预览 / 打印**。不新建送货单表、不改占用、不落导出作业、不记签收人/签收时间/回签扫描件。

**状态：待实现。** 入口：交货单列表操作列 + 详情抽屉「打印」；`GET /api/v1/sd/deliveries/{id}/pdf`。
