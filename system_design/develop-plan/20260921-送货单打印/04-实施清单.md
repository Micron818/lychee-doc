## 2. 已锁定决策（编码时勿改）

见 [02 §3](./02-目标流程.md)。摘要：

1. `GET /sd/deliveries/{id}/pdf`，仅预览打印  
2. `DRAFT`/`RELEASED`/`DELIVERED` × `NORMAL`/`SAMPLE`；拒绝 `CANCELLED` 与 `RETURN`  
3. 行：非 CANCELLED + source 空或 `SALES_ORDER` + `transactionQuantity > 0`  
4. 每个物料一行，Letter 纵向 216×279mm；列序物料名称 / 客户 PO / 客户订单号 / 内部参号 / 单位 / 数量；无价税、无样图、无尺码矩阵；不印客户代码 / 税号 / 状态 / 类型 / 计划交货日 / 工厂 / 销售订单号。物料名称与客户 PO 按 `materialId`、`materialId`+客户 PO 做 rowspan  
5. 签核从左到右：客户签收 / 送货人 / 制单，不印签收日期。页眉送货日期标签固定显示，其下印打印时间。签核栏不印列印账号与时间  
6. 地址：单据配送地址，空则客户送货地址。公司邮箱有值才印在页眉左侧  
7. 列表操作列 + 抽屉各自挂 Modal；请款工具栏不动；DRAFT 脏数据打印先拦截  
8. 合计单位走 `unitMixed` / `totalQuantityUnit`

## 5. 验收

- 打开一张 `RELEASED` + `NORMAL` 交货单：PDF 标题为「送货单」，单号为该交货单号。  
- 数量是行 `transactionQuantity`；每个物料一行。无单价/金额/币别/税率/开票状态/样图/尺码矩阵。  
- 列序：物料名称、客户 PO、客户订单号、内部参号、单位、数量。同一物料跨 PO 时物料名称合并；同一物料同一 PO 跨客户订单号时 PO 合并。PO 格不印销售订单号。  
- 数量与单位分列。物料名称印 `material.name`。  
- 客户名称、电话、联系人并排，不印客户代码；送货地址、承运、运单可见。页眉送货日期标签始终印出，其下印打印时间。不印税号、状态、类型、计划交货日、工厂。公司邮箱有值才印在左侧。  
- 赠样单能打；类型不印在 PDF 上。  
- 已取消 / 退回类型：无打印按钮；直调 PDF 业务错误。  
- 草稿带水印；已下达 / 已交货无水印。  
- 手工行无 PO/SO：PO 格空白但有高度。  
- 行备注可见。  
- 签核从左到右：客户签收（只留空线）、送货人留白、制单有姓名。不印签收日期，签核栏不印列印账号与时间。  
- 抽屉改了地址未保存：打印被拦截并提示；保存后再打才是新地址。  
- 打印件与预览同一 PDF；无导出中心作业。  
- 请款工具栏行为与本波前一致。  
- 中/英/越标题分别为送货单 / Delivery Note / Phiếu giao hàng。

## 6. 实现约定

### 6.1 公司

`Factory.companyId`，与请款 / `getDeliveryForBilling` 相同。不要从第一张来源 SO 偷 `companyId`。

### 6.2 数量

只用 `DeliveryItem.transactionQuantity`。不要 `issuedQuantity`，不要 `LineTaxCalculator`，不要 `double`。  
展示千分位用 `new DecimalFormat("#,##0.######", DecimalFormatSymbols.getInstance(Locale.US))`（对齐 `GoodsReceiptPdfRenderer`）。**不要**找或扩展 `MoneyFormatSupport` 的数量方法。

### 6.3 租户

查询走 JPA `@TenantId`。Service **禁止**往查询塞 `tenantId`。

### 6.4 明细行

每个物料一行。分组键：`materialId` + 客户 PO + 客户订单号 + 内部参号 + 单位。字符串 `nullToEmpty`。备注去重拼接。  
排序：组内最小 `delivery_items.item_no` → `materialId` → 客户 PO → 客户订单号。项次栏印 `lineNo`（1 起），不印原始 `item_no`。  
rowspan：物料名称比 `materialId`；客户 PO 比 `materialId` + 客户 PO。不要做成尺码矩阵，不要从请款 Service 整段复制。

### 6.5 路由

`GET /{id}/pdf` 与 `GET /{id}` 同控制器。Spring 映射按路径，`/billing-statement/pdf` 仍是 POST，互不影响。前端 blob 用 `skipErrorHandler`（现有 PDF 惯例）。

### 6.6 文件名安全

交货单号去掉路径分隔与空白后再拼。locale 决定前缀（`print.delivery_note.fileName`），不要写死中文。

### 6.7 术语

代码类名用 `DeliveryNote*`（打印件）。实体 / API 资源仍是 `Delivery`。注释与 UI 不要把 DN 改叫送货单。

### 6.8 合计单位

合计：Service 只给 `totalQuantity` + `unitMixed` + `totalQuantityUnit`；展示串由 Renderer 拼。明细数量与单位分列，合计在单位不混用时仍带单位。

### 6.9 前端 Modal

列表与抽屉各一份 `DeliveryNotePdfPreviewModal`。抽屉脏打印只 warning + return，不要 `saveRun` 再预览（打印不应隐式写库）。
