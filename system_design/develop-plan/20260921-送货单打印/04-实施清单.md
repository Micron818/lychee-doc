## 2. 已锁定决策（编码时勿改）

见 [02 §3](./02-目标流程.md)。摘要：

1. `GET /sd/deliveries/{id}/pdf`，仅预览打印  
2. `DRAFT`/`RELEASED`/`DELIVERED` × `NORMAL`/`SAMPLE`；拒绝 `CANCELLED` 与 `RETURN`  
3. 行：非 CANCELLED + source 空或 `SALES_ORDER` + `transactionQuantity > 0`  
4. 尺码矩阵，A4 landscape；无出货格、无价税、无样图、无料号列；rowspan 按 15 交叉合并，不是左到右树  
5. 签核：制单 / 送货人 / 客户签收  
6. 地址：单据配送地址，空则客户送货地址  
7. 列表操作列 + 抽屉各自挂 Modal；请款工具栏不动；DRAFT 脏数据打印先拦截  
8. `compactSizes`：尺码列 `> 8`；合计单位走 `unitMixed` / `totalQuantityUnit`

## 5. 验收

- 打开一张 `RELEASED` + `NORMAL` 交货单：PDF 标题为「送货单」，单号为该交货单号。  
- 数量是行 `transactionQuantity`；同款同色尺码在动态 Size 列；无单价/金额/币别/税率/开票状态/样图/料号列。  
- 左起型号（款色标签），再 PO / 颜色；同款两色时 PO 格跨色合并、型号格拆开。  
- 数量格带单位；无型号时身份在型号格。  
- 送货地址、承运、运单、计划日可见；未出完无实际交货日，信息区左右不因缺字段错位。  
- 赠样单能打，类型可见。  
- 已取消 / 退回类型：无打印按钮；直调 PDF 业务错误。  
- 草稿带水印；已下达 / 已交货无水印。  
- 手工行无 PO/SO：PO 格空白但有高度。  
- 9 个及以上尺码列走 `compact-sizes`。  
- 行备注可见。  
- 签核三栏：制单有姓名，送货人与客户签收留白。  
- 抽屉改了地址未保存：打印被拦截并提示；保存后再打才是新地址。  
- 打印件与预览同一 PDF；无导出中心作业。  
- 请款工具栏行为与本波前一致。  
- 中/英/越标题分别为送货单 / Delivery Note / Phiếu giao hàng。

## 6. 实现约定

### 6.1 公司

`Factory.companyId`，与请款 / `getDeliveryForBilling` 相同。不要从第一张来源 SO 偷 `companyId`。

### 6.2 数量

只用 `DeliveryItem.transactionQuantity`。不要 `issuedQuantity`，不要 `LineTaxCalculator`，不要 `double`。  
展示千分位用 `new DecimalFormat("#,##0.######", DecimalFormatSymbols.getInstance(Locale.US))`（对齐 `GoodsReceiptPdfRenderer`）。**不要**找或扩展 `MoneyFormatSupport` 的数量方法。

### 6.3 租户

查询走 JPA `@TenantId`。Service **禁止**往查询塞 `tenantId`。

### 6.4 矩阵

对照请款 `applyRowspans` + `modelKey`，以及 `SalesOrderReportServiceImpl` 的 Fact → group → sizeColumns、`nullToEmpty`、`appendDistinctRemark`。  
不要从 `DeliveryBillingStatementServiceImpl` 整段复制后只删金额——请款分组键含出货单与开票状态，漏删会拆行。  
不要抄 SO 报表 rowspan 只比 `productModelId`。  
排序用纯 `productModelCode`，禁止 `productModelLabel`。不要把文档里已废止的「树形」写进注释。

### 6.5 路由

`GET /{id}/pdf` 与 `GET /{id}` 同控制器。Spring 映射按路径，`/billing-statement/pdf` 仍是 POST，互不影响。前端 blob 用 `skipErrorHandler`（现有 PDF 惯例）。

### 6.6 文件名安全

交货单号去掉路径分隔与空白后再拼。locale 决定前缀（`print.delivery_note.fileName`），不要写死中文。

### 6.7 术语

代码类名用 `DeliveryNote*`（打印件）。实体 / API 资源仍是 `Delivery`。注释与 UI 不要把 DN 改叫送货单。

### 6.8 紧凑尺码与合计单位

`compactSizes` 只存在 Renderer → 模板 model，不要加到 `DeliveryNotePrintResponse`。阈值 `sizeColumns.size() > 8`。  
合计：Service 只给 `totalQuantity` + `unitMixed` + `totalQuantityUnit`；展示串由 Renderer 拼。

### 6.9 前端 Modal

列表与抽屉各一份 `DeliveryNotePdfPreviewModal`。抽屉脏打印只 warning + return，不要 `saveRun` 再预览（打印不应隐式写库）。
