本文件为 **MRP 需求运算（Material Requirements Planning）** 的独立 UI 设计说明，可作为：

* 前端页面设计规格
* 产品 PRD
* 与 PP / SCM 用户评审用文件

---

## 一、定位与设计目标

**所属模组**：PP（生产计划与控制）

**目标使用者**：

* 生产计划人员
* 供应链 / 计划主管

**核心设计目标**：

* MRP 必须是 **可控、可解释、可追溯** 的运算
* 明确区分「模拟」与「正式」
* 禁止一键黑盒式产单

---

## 二、Menu 位置

```text
PP
 └─ MRP 需求运算
```

## 四、运算条件区（MRP Parameters）

### 1️⃣ 基本条件

* 工厂（必填）
* 计划期间（From / To）
* MRP 策略
* 是否包含已确认 FO
* 是否重新计算安全库存

---

### 2️⃣ 需求 / 供给来源选择

**需求来源**

* ☑ 客户订单（SO）
* ☑ 厂订单（FO）
* ☑ 预测需求（来自 SCM / CRM）

**供给来源**

* ☑ 现有库存
* ☑ 已下采购单（PO）
* ☑ 已释放生产指令（MO）

---

### 3️⃣ 进阶运算参数

* 批量策略（LFL / EOQ / 固定批量）
* 最小生产量 / 最小采购量
* 交期提前 / 延后容许天数

---

## 五、主要操作按钮（关键 UX）

* ▶【模拟运算】

  * 不写入正式单据
  * 仅产生暂存结果

* ▶▶【正式运算】

  * 产生一笔 MRP Run
  * 可转 PLO / PR

* ⛔【中断 / 取消】

⚠ **设计红线**：禁止直接产出 MO / PO

---

## Tab 1：需求总览（Summary）— 页面区块线框

> 目的：让计划人员 **在 1 页内判断这次 MRP 是否“合理 / 可执行 / 有风险”**，而不是看细表。

### 一、页面整体区块结构（Wireframe）

```
┌──────────────────────────────────────────────────────────────┐
│ Summary Header                                                │
│ Run No | Plant | Scenario | Run Date | Status | [Compare]     │
└──────────────────────────────────────────────────────────────┘

┌──────────────┬───────────────────────────────────────────────┐
│ KPI Cards    │ Demand vs Supply Chart                         │
│              │                                               │
│ - Total Req  │  折线 / 柱状：                                │
│ - Shortage   │  • Gross Demand                               │
│ - Coverage   │  • Planned Supply (MO / PO)                   │
│ - Delay Lot  │                                               │
└──────────────┴───────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────┐
│ Demand Summary Table                                          │
│ Material | Type | Req Qty | Supply Qty | Shortage | Action    │
└──────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────┐
│ Exception Preview                                             │
│ ⚠ Shortage | ⚠ Late | ⚠ Excess (Top N)                        │
└──────────────────────────────────────────────────────────────┘
```

---

### 二、区块 1：Summary Header（运行摘要）

**信息只读，来自 MRP Run Snapshot**

| 栏位       | 说明                           |
| -------- | ---------------------------- |
| Run No   | MRP 运算批次号                    |
| Plant    | 工厂 / 组织                      |
| Scenario | Simulation / Official        |
| Run Date | 运算时间                         |
| Status   | Draft / Completed / Released |
| Compare  | 与其他 Run 比较（按钮）               |

> 设计原则：**这里不是筛选条件，是“本次运算身份”**

---

### 三、区块 2：KPI Cards（关键判断指标）

> 计划人员 30 秒内要看的数字

**4~6 张卡片即可，避免 KPI 爆炸**

| KPI          | 说明               |
| ------------ | ---------------- |
| Total Demand | 总需求量（含独立 / 相关需求） |
| Total Supply | 可供给量（库存 + 计划）    |
| Shortage Qty | 缺料数量（关键指标）       |
| Coverage %   | 需求满足率            |
| Late Lots    | 延期批次数            |
| Excess Qty   | 超额计划（选配）         |

> 颜色规则：
>
> * 正常：灰 / 蓝
> * 警告：橙
> * 严重：红

---

### 四、区块 3：Demand vs Supply Chart（趋势判断）

**默认维度：Time Bucket（日 / 周 / 月，来自 Run 参数）**

* X 轴：Period
* Y 轴：Qty

**展示数据**：

* Gross Demand
* Planned Production (MO)
* Planned Purchase (PO)
* Available Inventory（可选）

> 设计目标：
>
> * 一眼看出 **哪段时间供需断层**
> * 不取代详细表，只用于趋势判断

---

### 五、区块 4：Demand Summary Table（物料层摘要）

**Top N（默认 20），支持跳转 Drill Down**

| 栏位            | 说明                       |
| ------------- | ------------------------ |
| Material Code | 物料                       |
| Material Type | FG / RM / Semi           |
| Req Qty       | 总需求                      |
| Supply Qty    | 计划供给                     |
| Shortage Qty  | 缺口                       |
| Coverage %    | 满足率                      |
| Action        | 查看 Production / Purchase |

> 排序规则：
>
> * 默认按 Shortage Qty DESC

---

### 六、区块 5：Exception Preview（异常预览）

**只展示“最值得处理的”异常**

* Shortage Top 5
* Late Order Top 5
* Excess Plan Top 5

点击后：

* 跳转至 Exception Tab
* 或带过滤条件跳转 Production / Purchase

---

### 七、前端实现建议（Ant Design Pro）

* 布局：`PageContainer`
* KPI：`ProCard + Statistic`
* 图表：`@ant-design/plots`（不放在 Table 内）
* 表格：`ProTable`（pagination=false, scroll.y）
