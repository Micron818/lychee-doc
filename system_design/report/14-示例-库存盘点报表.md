# 14 — 示例：库存盘点单打印表单

> 编写日期：2026-08-18  
> 状态：**已实现（2026-08-18）**  
> 前置：单据 PDF 版式收敛（01 §3 / 04）、收货单 PDF 范本（12）已落地

## 1. 需求

从库存盘点单（`PhysicalInventory` + `PhysicalInventoryItem`）列表或详情抽屉发起「打印」，按 **单张盘点单号** 以 **A4 纵向**标准单据版式呈现（公司抬头、厂/仓/期间、明细表、数量合计、签核栏）。打印件与预览 PDF 像素级一致；多页明细正确分页，表头每页重复。仓务联**只印数量，不印金额 / 单价 / 成本**。

盘点单为仓务作业单据，**无归档下载需求**：省略 `ExportJobType` / `*PdfExportHandler` / 前端 `ExportButton`（对齐 04 §6 请购单 / 12 收货单分支）。**不做 Excel**（进耗存 05 的模板填充不适用于本单）。

同一套 PDF 覆盖两段现场用途（列随状态变化，见决策 #10）：


| 单据状态                       | 现场用途             | 实盘 / 差异 | 过账补偿列  |
| -------------------------- | ---------------- | ------- | ------ |
| `PLANNED`（已生成盘点行）          | **盘点表**：带到仓库对照录入 | 可空      | **不印** |
| `COUNTED`                  | **盘点差异表**：复核盈亏   | 齐全      | **不印** |
| `POSTED` / `REVERSED` 且锁库  | 差异归档             | 齐全      | **不印** |
| `POSTED` / `REVERSED` 且不锁库 | 差异 + 动盘补偿核对      | 齐全      | **才印** |


**报表名称（三语）**（单据标题，不随状态改名；状态印在头档）


| locale | 名称                       |
| ------ | ------------------------ |
| zh-CN  | 库存盘点表                    |
| en-US  | Physical inventory sheet |
| vi-VN  | Bảng kiểm kê tồn kho     |


文件名：`PI_{inventoryNo}.pdf`。

## 2. 为何不用进耗存 Excel 路径

05 进耗存是 **期间余额表** 套打，必须用「单一期间 × 工厂」收束范围。盘点单 **本身已收束**：一张 PI = 单一工厂 × 单一仓库 × 单一库存期间 × 单一计划日。仓务是「按单号拿这一张去盘 / 签字」，不是分析导出。


| 维度        | 05 进耗存    | 12 收货单       | **14 库存盘点（已确认）** |
| --------- | --------- | ------------ | ---------------- |
| 数据        | 期间余额表     | **一张单据**     | **一张盘点单**        |
| 产出        | 模板 Excel  | **仅 PDF 打印** | **仅 PDF 打印**     |
| 入口        | 列表工具栏导出   | 列表 / 详情「打印」  | **列表 / 详情「打印」**  |
| 范围        | 强制期间 × 工厂 | 单据 id        | **单据 id（单号）**    |
| 空明细       | 允许 0 行合计  | 收货单通常有行      | **拒绝打印**         |
| 归档 Export | 有         | 无            | **无**            |


跨多单「期间盘点差异汇总」若需要，另立作业，不与本打印混用（见 §10）。

## 3. 总体流程

```
前端 PI 列表 / 详情 [打印]
   │  须已有 id；0 行则前端可提示，以后端拒绝为准
   │  PdfPreviewModal + getPhysicalInventoryPdfBlob(id)
   ▼
GET /api/v1/wm/physical-inventories/{id}/pdf     ← read，inline，不建作业、不落 OSS
   │
   ▼
PhysicalInventoryPdfRenderer.renderOne(id, locale)
   ├─ PhysicalInventoryPrintService.getPrintData(id)
   │     ├─ 无盘点行 → ValidationException
   │     ├─ 抬头：factory → company（地址/电话/税号）
   │     ├─ 头档：期间 / 工厂 / 仓库 / 类型 / 锁库 / 快照
   │     └─ 明细：全量按 itemNo；fetch material / baseUnit
   └─ Thymeleaf templates/print/physical-inventory-pdf.html → PDF bytes
   │
   ▼
前端 blob → objectURL → iframe；工具栏 print()
```

禁止再开前端 HTML 打印页 / `/print` 深链 / `autoPrint` / 对外 `print-data` REST。

## 4. 业务决策（已确认）


| #   | 决策点   | 结论                                                                                                                                                            |
| --- | ----- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | 粒度    | **按单张盘点单号打印**；一次一份 PDF。不做批量多单合并                                                                                                                               |
| 2   | 产出物   | **仅 PDF 预览 + 浏览器打印**；**无 Excel**；无归档 Export                                                                                                                   |
| 3   | 纸张    | **A4 portrait**（对齐收货单）                                                                                                                                        |
| 4   | 数据范围  | 一张 PI + **该单全部明细**（`itemNo` 升序）；**忽略**抽屉内物料/批次筛选                                                                                                              |
| 5   | 空明细   | **拒绝打印**（未生成盘点行）。文案提示先「按现存量生成盘点行」                                                                                                                             |
| 6   | 未保存   | 详情无 id 不渲染打印按钮 / 拦截                                                                                                                                           |
| 7   | 账面数量  | **明盘**（印账面），与列表一致。盲盘本期不做                                                                                                                                      |
| 8   | 金额    | **不印**单价、金额、成本                                                                                                                                                |
| 9   | 状态    | 四种状态均可打（空行除外）。`REVERSED` 加水印「已冲销」。`PLANNED` / `COUNTED` / `POSTED` **无水印**（`PLANNED` 不是草稿，是正式盘点表）                                                             |
| 10  | 过账补偿列 | **过账前不印**。仅 `status ∈ {POSTED, REVERSED}` **且** `blockTransactions = false` 时印 `dynamicTransactionQuantity` / `postedDifferenceQuantity`。与列表 `hideInTable` 一致 |
| 11  | 合计    | 账面 / 实盘 / 差异数量加总；盘盈/盘亏/无差异/未盘笔数与数量。补偿列可见时另合计该两列。跨单位仍加总；多于 1 种单位时头档提示 `{mixedUnitLabel}`                                                                       |
| 12  | 权限    | 预览 `/wm/physical-inventories:read`                                                                                                                            |
| 13  | 签核栏   | **盘点人**（印 `countedByName`，未盘可空）／**审核**（印 `approvedByName`，未过账可空）／各留签字线。印打印人 / 时间                                                                              |
| 14  | 入口    | 列表操作列 + 详情抽屉「打印」；**不做**列表工具栏按筛选导出；`rowSelection` 仍只服务 `PLANNED` 批量删除                                                                                          |

## 5. 数据口径



### 5.1 行粒度

```
PhysicalInventory（id）
   └─ PhysicalInventoryItem 全量，ORDER BY itemNo ASC
         → 1 行（禁止按现存量重快照）
```

账面以生成行时写入的 `bookQuantity` 为准。差异不在打印时重算：实盘为空则差异为空。

过账补偿仅在决策 #10 为真时组装并入模板；否则 DTO 可带字段但模板 **整列不渲染**（不要留空列）。

### 5.2 打印数据模型

`PhysicalInventoryPrintResponse`（一次性返回、全部名称已解析）：

```
公司抬头：companyName / companyAddress / companyPhone / companyTaxId
单据头：inventoryNo / planDate / status(+Label) / inventoryType(+Label)
        periodLabel / factoryName / warehouseName
        blockTransactions / blockTransactionsLabel
        snapshotAt / remarks
        reversed                         ← 水印
        showPostingCompensation          ← 决策 #10
        mixedUnitLabel                   ← 单位 > 1 种才有值
明细 Item：
        itemNo / materialCode / materialName
        batchNo / stockType(+Label) / locationCode / baseUnitName
        bookQuantity / countedQuantity / differenceQuantity
        dynamicTransactionQuantity / postedDifferenceQuantity   ← 仅补偿可见时有值
        reasonCode / remarks
合计：totalBookQty / totalCountedQty / totalDifferenceQty
      totalDynamicQty / totalPostedDifferenceQty   ← 仅补偿可见时
      surplusCount / surplusQty
      shortageCount / shortageQty                  ← 盘亏数量用正数展示
      zeroDiffCount / uncountedCount / docLineCount
打印元：countedByName / approvedByName / createdByName
        printedBy / printedAt
```

数量在 Renderer 内预格式化（千分位、最多 6 位小数，对齐收货单）；模板纯展示。

盘盈盘亏只统计 **已盘行**（`countedQuantity != null`）；未盘计入 `uncountedCount`，不把空实盘当 0。

### 5.3 过账补偿列显示条件

与列表一致：

```
showPostingCompensation =
    blockTransactions == false
    && (status == POSTED || status == REVERSED)
```

`PLANNED` / `COUNTED` 即使将来误写入补偿字段，打印仍不出现这两列。

## 9. 验收标准

1. Chrome/Edge：Modal 预览正常；明细少时一页呈现头档 + 明细 + 合计 + 签核；40+ 行正确分页且每页含表头，签核栏不被截断。
2. 工具栏「打印」仅唤起一次系统对话框；无 autoPrint。
3. 未保存单据无打印入口；已保存但 0 行：前端提示或 API 返回 `items.required`，不生成空 PDF。
4. 数量右对齐、千分位；中/英/越标签正确；不展示金额 / 单价 / 成本。
5. **明盘**：各状态均印账面数量。
6. `PLANNED` / `COUNTED`：**无**动盘、过账差异列；实盘/差异可空（`PLANNED`）。
7. `POSTED` / `REVERSED` 且锁库：仍无补偿列。
8. `POSTED` / `REVERSED` 且不锁库：出现补偿列，数值与列表一致。
9. `REVERSED` 带「已冲销」水印；其余状态无水印。
10. 明细行数、顺序与抽屉未筛选时一致（`itemNo`）。
11. 盘盈盘亏只计已盘行；未盘单独计数。
12. 无 `read` 权限访问预览 PDF 返回 403。
