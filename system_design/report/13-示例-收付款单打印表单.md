# 13 — 示例：收付款单可打印格式表单

> 编写日期：2026-08-18  
> 状态：**已实现**  
> 前置：单据 PDF 版式收敛（01 §3 / 04）、收货单 PDF 范本（12）已落地；收付款「先资金后核销」（FI 09）已上线

## 1. 需求

从收付款单（Payment）列表或详情抽屉发起「打印」，以 **A4 纵向**标准单据版式呈现收款单 / 付款单（公司抬头、往来单位、资金账户、核销明细、金额合计、签核栏）。打印件与预览 PDF 像素级一致；多页明细正确分页，表头每页重复。

收付款为财务资金单据，**本期无归档下载需求**：省略 `ExportJobType` / `*PdfExportHandler` / 前端 `ExportButton`（对齐 04 §6 请购单 / 12 收货单分支）。后续若需寄送银行或归档中心，再复用订购单导出作业。

**RECEIPT 与 DISBURSEMENT 共用一套渲染链路**，仅标题、账户标签与「缴款人 / 领款人」文案按类型切换。无线（过账后尚未核销）仍可打印——这是先资金后核销的主路径，不是异常。

## 2. 总体流程

```
前端 Payment 列表 / 详情 [打印]
   │  PdfPreviewModal + getPaymentPdfBlob(id)
   ▼
GET /api/v1/fi/payments/{id}/pdf     ← read，inline，不建作业、不落 OSS
   │
   ▼
PaymentPdfRenderer.renderOne(id, locale)
   ├─ PaymentPrintService.getPrintData(id)
   │     ├─ 抬头：BasisCacheService.findCompanyById（无工厂；含地址/电话/税号）
   │     ├─ 往来：header 快照 code/name + BusinessPartner.taxId
   │     ├─ 账户：header 银行快照（本公司 / 往来）
   │     ├─ 币别：currencyOptionId → OptionValue.code
   │     ├─ 凭证：journalEntryId → journalNo（未过账可空）
   │     └─ 明细：fetch apInvoice / arInvoice / glAccount / appliedPayment；
   │           departmentId → BasisCacheService.getAllDepartments（可空）
   └─ Thymeleaf templates/print/payment-pdf.html → PDF bytes
   │
   ▼
前端 blob → objectURL → iframe；工具栏 print()
```

禁止再开前端 HTML 打印页 / `/print` 深链 / `autoPrint` / 对外 `print-data` REST。

## 3. 业务决策

| # | 决策点 | 结论 |
|---|--------|------|
| 1 | 产出物 | **仅 PDF 预览 + 浏览器打印**；无归档 Export |
| 2 | 纸张 | **A4 portrait**（对齐订购单 / 收货单） |
| 3 | 数据范围 | 一张 Payment + 全量 `payment_lines`（按 `lineNo`）；**无行亦可打** |
| 4 | 单据标题 | 同一模板：`RECEIPT` → 收款单；`DISBURSEMENT` → 付款单 |
| 5 | 金额 / 币别 | **必须展示**：头档 `amount`、币别、汇率（≠ 1 才印）、核销额、折扣、未核销 |
| 6 | 金额大写 | **本期落地并封装为共用能力**：头档 `amount` 按 UI locale 输出中 / 英 / 越大写（见 §5.1 `AmountInWordsSupport`） |
| 7 | 银行账户 | 印 **提交/过账快照**（`internal_*` / `partner_*`），不回查主档现况；现金付款往来账户可空 |
| 8 | 核销行 | `INVOICE`：系统发票号 + 税务/外部发票号 + 发票日叠在单据区；`PREPAYMENT`：被冲收付款单号；`GL_ACCOUNT`：科目 + 部门（可空） |
| 9 | 发票余额 | **不印** `remainingAmount`（会随后续核销变动，历史重打会错）；发票原额可作参考小字 |
| 10 | 预收/预付 | 头档印 `isPrepayment` 标记；未核销金额始终展示（即使为 0） |
| 11 | DRAFT | **允许打印**，模板加「草稿」水印 |
| 12 | PENDING_APPROVAL | **允许打印**，模板加水印文案 **「待审核」**（便于传签） |
| 13 | APPROVED / POSTED | 正式版式，无水印 |
| 14 | VOIDED | **允许打印**，模板加「已作废」水印 |
| 15 | 权限 | 预览 `/fi/payments:read` |
| 16 | 签核栏 | 左→右固定四栏，**不印出纳 / `postedBy`**。详见 §6.1 |
| 17 | 过账凭证 | POSTED 后印 `journalNo`；未过账不占位 |

金额语义与 FI 09 一致，打印只展示已落库字段、不重算：

```
amount              = 银行实收/实付（头档）
unallocatedAmount   = 头档未核销余额
行：allocatedAmount / discountAmount
```

## 4. 打印数据模型

`PaymentPrintResponse`（一次性返回、全部名称已解析）：

```
公司抬头：companyName / companyAddress / companyPhone / companyTaxId
单据头：paymentNo / paymentDate / status(+Label)
        paymentType(+Label) / partnerType(+Label)
        draft / pendingApproval / voided
        isPrepayment
        currencyCode / exchangeRate / amount / unallocatedAmount
        paymentMethod(+Label) / referenceNo / remarks
        journalNo
往来：partnerCode / partnerName / partnerTaxId
本公司账户：internalBankName / internalBankBranch /
            internalAccountNo / internalAccountName
往来账户：partnerBankName / partnerBankBranch /
          partnerAccountNo / partnerAccountName
明细 Item：
        lineNo / allocationType(+Label)
        docNo / docSub   ← 发票 code 或 appliedPaymentNo；税号/外部号为 sub
        invoiceDate / invoiceTotal
        glAccountCode / glAccountName / departmentName
        allocatedAmount / discountAmount / description
合计：allocatedTotal / discountTotal / unallocatedAmount / amount
      amountInWords          ← Renderer 调 AmountInWordsSupport
打印元：createdByName / approvedByName / printedBy / printedAt
        （不组装 postedByName）
```

Renderer 内用 `MoneyFormatSupport` 按 **单据币别** 预格式化金额（与订购单一致）；汇率 ≠ 1 才输出。

文件名：`RECEIPT` → `RCP_{paymentNo}.pdf`；`DISBURSEMENT` → `PAY_{paymentNo}.pdf`。

### 5.1 金额大写共用能力

放在 `lychee-erp-common`，**不绑收付款**，后续发票 / 凭证打印直接调用。

```
com.lychee.erp.common.export.AmountInWordsSupport
  toWords(BigDecimal amount, String currencyCode, Locale locale) → String
```

约定：

- locale 跟 **UI `Accept-Language`**（zh-CN / en / vi），不是单据币别 locale。
- 数字读法跟 locale；末尾附 ISO 币别代码（如 `… 整 CNY` / `… only USD` / `… đồng VND`），避免本币/外币混读。
- `null` / 非正数：返回 `null`，模板不印该行（收付款头档金额业务上 > 0，正常路径必有大写）。
- 小数位跟 `MoneyFormatSupport.fractionDigits(currencyCode)`（VND / JPY 按整数读）。
- 单测：整数、带小数、VND 零小数、三语各一条黄金样例；不在领域 Renderer 内手写转换。

## 6. 版式示意

```
┌──────────────────────────────────────────────────────────┐
│  {公司名}                          收 款 单 / 付 款 单   │
│  地址/电话/税号            单号 / 日期 / 状态            │
│                            凭证号（过账后）               │
├──────────────────────────────────────────────────────────┤
│ 往来单位 / 类型 / 税号                                    │
│ 收付方式 / 参考号 / 预收预付                              │
│ 本公司账户 / 往来账户                                     │
│ 币别 / 汇率（≠1） / 金额（大写另起一行）                   │
├──────────────────────────────────────────────────────────┤
│ 核销明细（跨页表头重复；无行则空表 +「暂无核销明细」）      │
│ 项次 | 类型 | 单据 / 科目 | 说明 | 核销金额 | 折扣         │
├──────────────────────────────────────────────────────────┤
│ 核销合计 / 折扣合计 / 未核销 / 收付金额                   │
│ 备注                                                     │
│ 财务 ________ │ 缴/领款人 ________ │ 审核 {approvedBy} │ 制单 {createdBy} │
│               │                    │  ______________   │  ________       │
│               │                    │ （加高供主管签）  │                 │
│ 打印人 / 时间                                            │
└──────────────────────────────────────────────────────────┘
```

头档信息区标签随类型微调：收款印「入账账户」，付款印「出账账户」；往来账户统一「对方账户」。

### 6.1 签核栏（左 → 右）

| 顺序 | 栏位 | 印姓名 | 签字空白 |
|------|------|--------|----------|
| 1 | **财务** | 不印 | 常规签字线，留白 |
| 2 | **缴款人**（收款）／**领款人**（付款） | 不印 | 常规签字线，留白 |
| 3 | **审核** | 印 `approvedByName`（未审可空） | **加高 / 双线**，供主管手签；姓名与签字线分开，避免挤在一行 |
| 4 | **制单** | 印 `createdByName` | 常规签字线 |

四栏同一行排布（各约 25% 宽）。审核栏垂直空间大于其余三栏（`min-height` 或第二条签字线），保证主管有落笔位置。`page-break-inside: avoid`。不设出纳栏、不印 `postedBy`。

单据区叠字规则（对齐收货单品名区）：

- `INVOICE`：主行系统发票号；次行税务发票号（AR）或外部发票号（AP）+ 发票日；再次行发票原额。
- `PREPAYMENT`：被冲收付款单号。
- `GL_ACCOUNT`：科目代码 - 名称；次行部门（有则印）。

## 7. 验收标准

1. Chrome/Edge：Modal 预览正常；无核销行时一页呈现头档 + 空表明细 + 合计 + 签核；40+ 行正确分页且每页含表头，签核栏不被截断。
2. 工具栏「打印」仅唤起一次系统对话框；无 autoPrint。
3. 金额右对齐、按单据币别小数位与千分位（VND 无小数）；汇率 = 1 不印；中/英/越标题分别为 收款单/付款单、RECEIPT VOUCHER/PAYMENT VOUCHER、PHIẾU THU/PHIẾU CHI。
4. 金额大写与头档 `amount`、当前 locale 一致。
5. DRAFT 带「草稿」水印；PENDING_APPROVAL 带「待审核」水印；VOIDED 带「已作废」水印；APPROVED / POSTED 无水印。
6. 签核左→右为财务（留白）、缴/领款人（留白）、审核（姓名 + 加高签字区）、制单（姓名）；收款印缴款人、付款印领款人；审核栏空白明显多于其他栏。
7. RECEIPT / DISBURSEMENT 标题正确；现金付款对方账户可空。
8. POSTED 显示凭证号；未过账不显示凭证行。
9. 无 `read` 权限访问预览 PDF 返回 403。
10. 不展示发票 `remainingAmount`。
11. 金额大写走 `AmountInWordsSupport`；后续模块可直接复用，无复制粘贴转换逻辑。
