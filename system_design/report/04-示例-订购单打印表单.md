# 04 — 示例：订购单可打印格式表单

> **现行架构（版式收敛后）**：服务端 PDF 单一版式（Thymeleaf + openhtmltopdf）→ 同步预览 `GET /{id}/pdf` → 前端通用 `PdfPreview*`（iframe）→ 打印；归档下载走导出作业。  
> 一期「前端 HTML 打印页 / `/print` 深链 / `autoPrint` / `print-data` REST」已废弃，仅作历史参考见文末附录。

## 1. 需求

从订购单列表或详情抽屉发起「打印」，以 A4 纵向标准单据版式呈现订购单（公司抬头、供应商信息、明细表、金额合计、签核栏）；打印件与归档 PDF 像素级一致；多页明细正确分页，表头每页重复。

## 2. 后端：打印数据与 PDF 渲染（`lychee-erp-scm` + common）

`PurchaseOrderPrintService.getPrintData(id)` 内部聚合打印所需全部已解析字段（公司抬头、供应商、字典、明细等），供 Renderer / 导出 Handler 复用；**不再对外暴露** `print-data` REST。

```
内部：PurchaseOrderPrintService.getPrintData(id)
共用渲染：PurchaseOrderPdfRenderer → PdfRenderSupport（Thymeleaf + openhtmltopdf）
对外预览：GET /api/v1/scm/purchase-orders/{id}/pdf   （inline，不建作业、不落 OSS）
归档导出：ExportJobType.SCM_PURCHASE_ORDER_PDF + PurchaseOrderPdfExportHandler
权限：预览 /scm/purchase-orders:read；下载 /scm/purchase-orders:export
```

打印数据模型（`PurchaseOrderPrintResponse`，一次性返回、全部名称已解析）：

```java
public class PurchaseOrderPrintResponse {
    // 抬头（租户公司信息，来源：租户/公司主数据）
    private String companyName;
    private String companyAddress;
    private String companyPhone;
    private String companyTaxId;

    // 单据头
    private String orderNo;
    private LocalDate orderDate;
    private String status;                 // 枚举翻译文本
    private String factoryName;
    private String currencyName;           // currencyOptionId → 字典
    private BigDecimal exchangeRate;
    private String paymentTermName;        // paymentTermOptionId → 字典
    private String billingAddress;
    private String shippingAddress;
    private String remarks;

    // 供应商（打印需要完整信息，非仅 code/name）
    private String supplierCode;
    private String supplierName;
    private String supplierTaxId;
    private String supplierAddress;
    private String supplierContactPerson;
    private String supplierContactPhone;
    private String supplierContactEmail;

    // 明细（全量，按 itemNo 排序）
    private List<Item> items;
    public static class Item {
        private Integer itemNo;
        private String materialCode;
        private String materialName;
        private String materialSpec;
        private BigDecimal orderedQuantity;
        private String unitName;
        private BigDecimal unitPrice;
        private BigDecimal taxRate;
        private BigDecimal amount;          // 行金额
        private LocalDate expectedDeliveryDate;
        private String remarks;
    }

    // 合计
    private BigDecimal subtotalAmount;
    private BigDecimal taxAmount;
    private BigDecimal totalAmount;
    private String totalAmountInWords;      // 金额大写（按语言，可选）

    // 打印元信息
    private String printedBy;
    private LocalDateTime printedAt;
}
```

实现要点：

- Service 内 `DynamicSpecifications.fetch(...)` 一次抓取 supplier/material/unit，避免 N+1。
- 枚举与字典翻译按请求 `Accept-Language`（现有 `MessageService` 机制）。
- 业务规则建议：仅 `APPROVED` 及之后状态可正式打印；`DRAFT` 打印时响应带 `draft: true` 标记，模板加"草稿"水印（规则由业务确认，接口先不做硬限制）。
- 模板：`templates/print/purchase-order-pdf.html`（良构 XHTML + CSS 2.1 子集；跨页表头、页码、草稿水印）。
- 字体：Noto Sans + Noto Sans SC 子集打包进 common classpath，`PdfRenderSupport` 注册。

## 3. 前端：原页 Modal + iframe 预览（现行）

### 3.1 入口

- 列表操作列「打印」、详情抽屉「打印」：打开原页近全屏 Modal（不新开标签、无 `/print` 深链）。
- 权限：预览走 `read`（拉取 PDF 时后端 403）；「下载 PDF」走 `ExportButton` + `export` 动作门控。

### 3.2 结构

```
src/components/PdfPreview/          // 通用基座（后续单据复用）
├─ PdfBlobViewer.tsx                // iframe + 打印工具条 + loading/error
├─ PdfPreviewModal.tsx              // 近全屏 Modal 壳
└─ pdf-preview.less

src/pages/scm/purchase-orders/print/
└─ PurchaseOrderPdfPreviewModal.tsx // 领域单文件适配：取 blob + ExportButton + Modal（范本）
```

### 3.3 交互约定

- 预览：`GET /{id}/pdf` → blob → `assertPdfBlob` → objectURL → iframe；关闭 Modal 时 `revokeObjectURL`。
- 打印：工具栏按钮 → `iframe.contentWindow.print()`（可临时改 `document.title` 以影响另存文件名）；**不提供 autoPrint**（Modal 下自动弹框体验差且易重复触发）。
- 下载：`ExportButton` / `SCM_PURCHASE_ORDER_PDF`（可批量 `params.ids`；列表多选入口待勾选语义调整后开放）。
- 不引入 PDF.js / react-pdf / 前端 HTML 版式双轨。

### 3.4 验收标准

1. Chrome/Edge：Modal 预览正常；单页 ≤ 15 行明细时一页呈现；40+ 行明细正确分 2~3 页，每页含表头，签核栏不被截断。
2. 工具栏「打印」仅唤起一次系统对话框；无自动弹打印框。
3. 金额/数量列右对齐、千分位、按币别小数位显示；中/英/越标签与数据翻译正确。
4. 无 `read` 权限访问预览 PDF 返回 403，页面 Result + 重试；非 PDF 错误 blob 解析 `message`/`error`。

## 4. 服务端 PDF 实施记录（✅）

- 依赖：`openhtmltopdf-pdfbox` + `thymeleaf-spring6` 于 `lychee-erp-common`；`PdfRenderSupport` 独立 TemplateEngine。
- `PurchaseOrderPdfRenderer` 组模型 + 渲染；导出 Handler 委派同一路径。
- 导出：`fileFormat()` → PDF；数值在 Handler 预格式化，模板纯展示。

## 5. 版式收敛与预览基座（✅ 2026-08）

| 项 | 调整 |
|----|------|
| 共用渲染 | `PurchaseOrderPdfRenderer`；导出与预览委派 |
| 预览接口 | `GET /{id}/pdf`（inline）；删除 `print-data` REST |
| 打印预览 | blob → iframe；原页 Modal；无 `/print`、无 `autoPrint` |
| 前端基座 | `PdfBlobViewer` / `PdfPreviewModal` / `utils/blob`；订购单仅薄适配 |
| 删除 | `PrintablePO`、一期打印页文案（保留 `previewTitle`）；`loadFailed` 迁至 `component.pdf.loadFailed` |

## 6. 新单据 PDF 清单（复用约定）

后续单据（出库单、委外单等）按同一模式扩展，禁止再开前端打印页双轨：

| 层 | 交付物 |
|----|--------|
| 后端 | `*PrintService`（内部聚合）+ Thymeleaf 模板 + `*PdfRenderer` + `GET /{id}/pdf` + 可选 `*PdfExportHandler` |
| 前端 | `getXxxPdfBlob` + **单文件**领域入口（比照 `PurchaseOrderPdfPreviewModal`）组合 `PdfPreviewModal` / `PdfBlobViewer`；需要归档时挂 `ExportButton` |
