# 供应商退款 · 主流程 V1

本目录是 **本期开发入口**：先打通「已付 AP → 应付贷项待退款 → 供应商现金退款」主路径。

完整目标设计（换日核销、核销行状态机、付款汇兑前置、一张退款核多张贷项等）仍在 [../供应商退款](../供应商退款/README.md)，**不要按那套范围编码**。两套口径冲突时，以本目录为准。

供应商退款是资金流入，复用 `payments`：

```text
payment_type    = RECEIPT
partner_type    = SUPPLIER
payment_purpose = SUPPLIER_REFUND
```

它核销应付贷项上由已付金额形成的 **待退款开放金额**。不 VOID 原付款，不处理采购退货，不回减收货占用。

## 主路径

```text
过账贷项（可超过 remaining，拆 applied / refundable）
  → 新建一张供应商退款（一单核一张贷项，金额 = 本次退款）
  → 过账（银行凭证 + 回写贷项 + 必要时退款段汇兑）
  → 改错则整单 VOID 退款
```

## 相对完整设计砍掉的能力

| 完整设计 | 主流程 V1 |
|----------|-----------|
| 无行过账、后补核销、`clearing_date` | 过账必须带且仅带一行核销，金额全部分配 |
| 一张退款核多张贷项 | 一退款单一贷项；一张贷项可被多张退款分次退 |
| `PROPOSED / APPLIED / REVERSED` 扩到全部 PaymentLine | 不改 STANDARD 核销生命周期 |
| 单行 reverse + `reversal_date` | 只整单 VOID，冲销走现网原凭证日 |
| 外币退款依赖普通 AP 付款汇兑 | 同币外币按贷项汇率重乘；退款段可出简单汇兑 |
| 原票有折扣则禁止形成 refundable | 待退款不得超过该票剩余实付现金 |
