# 01. 主流程 V1：范围、取舍与现状要点

> 评估对象：已收款 AR 因数量型客户退货产生应收贷项后，公司把现金退回客户。  
> 供应商侧对照 [../供应商退款-主流程V1/01-范围与取舍.md](../供应商退款-主流程V1/01-范围与取舍.md)。

---

## 1. 现状缺口（必须修）

应收贷项设计若只做到 `total ≤ remaining`，全额已收后 `remaining = 0`，贷项无法过账。本专题与 [应收贷项](../应收贷项/README.md) 约定：**贷项波已拆 applied / refundable**，本波只补资金单。

`payments` 现网用途矩阵：

```text
STANDARD         RECEIPT      CUSTOMER → AR Invoice
STANDARD         DISBURSEMENT SUPPLIER → AP Invoice
SUPPLIER_REFUND  RECEIPT      SUPPLIER → AP Credit Memo
```

不能表达「付款给客户」。VOID 原收款会冲银行凭证并回减 `received_amount`，不能用来记录后来真实发生的出账。

`applyAr` 在应收贷项波必须改 remaining 公式并加行锁；本波核销 `AR_CREDIT_MEMO` 时禁止走进 `applyAr`。

---

## 2. 为什么不一次做满

与供应商退款 V1 相同：核销状态机、换日冲销、普通收付款汇兑、一张退款核多张贷项都不是「银行出账核销贷项」的必要条件。本波只做开放金额 + 最小退款资金 + 退款段汇兑。

---

## 3. 取舍对照

### 3.1 必须留下

| 项 | 原因 |
|----|------|
| 贷项可超过 `remaining`，拆 `applied / refundable` | 否则已收不能贷（在应收贷项波完成） |
| `remaining = total − received − applied_credit` | `credited` 仍表示贷项总额 |
| 新付款用途 `CUSTOMER_REFUND`，不 VOID 原收款 | 银行流水与审计 |
| 退款核贷项，不改原票 `received_amount` | 原收款仍真实发生 |
| 有有效退款则禁止 VOID 贷项 | 后置阻断前置 |
| 有 `refundable > 0` 的贷项则禁止撤原收款核销 | 拆分按过账时已收状态冻结 |
| 付款与贷项共享 AR 行锁 | 避免 remaining 丢更新；退款 POST/VOID 全序 Payment → CM → AR |
| `PaymentPurposeSupport.documentType` 三分支 | 否则客户退款单号落到 `PAYMENT` |
| 可退款查询由贷项波交付 | 本波只消费 `refundable/page` |

### 3.2 本波明确不做

| 项 | 本波做法 |
|----|----------|
| 未分配退款、资金先行 | 过账必须一行核销且 `allocated = amount` |
| 一张退款核多张贷项 | 一单核一张；多张贷项开多张退款 |
| 全表 `allocation_status` | STANDARD 行为不变 |
| 单行 reverse | 只整单 VOID |
| 核销日 / 冲销日独立 | 核销随 `payment_date`；冲销走现网 `reverseEntry` |
| 普通 AP/AR 付款汇兑改造 | 不接入 `applyAr / applyAp` |
| 折扣比例转回 | 用实收现金封顶 |
| 交叉货币 | 拒绝 |
| 预收款余额退回（无贷项） | 不做；本路径只核应收贷项 |

### 3.3 与供应商退款的方向差异

| | 供应商退款 | 客户退款 |
|--|------------|----------|
| 资金 | 流入 | 流出 |
| 组合 | `RECEIPT + SUPPLIER + SUPPLIER_REFUND` | `DISBURSEMENT + CUSTOMER + CUSTOMER_REFUND` |
| 凭证 | 借银行 / 贷 AP | 借 AR / 贷银行 |
| 核销 | `AP_CREDIT_MEMO` | `AR_CREDIT_MEMO` |
| 单号 | `SR` | `CR` |

其余规则镜像。

---

## 4. 会计边界

```text
应收贷项：贷 AR / 借收入与税；释放交货占用
客户退货：库存与 COGS
客户退款：借 AR / 贷银行；结清贷项待退款
```

部分已收示例（无折扣）：AR 100 已收 60，贷项 70 → `applied=40`、`refundable=30`。贷项凭证仍按 70；拆分不另出总账。退款只处理 30。

真实退款必须是新 `DISBURSEMENT`。VOID 只纠正该退款单本身错误或银行交易未成立。

---

## 5. 后续增强

与供应商退款完整设计相同的清单：无行过账、换日冲销、一单核多张、普通汇兑、折扣转回、交叉货币、预收款退回。回到完整设计时两边一起做，不要只做客户侧。
