# 客户退款 · 主流程 V1

本目录是 **本期开发入口**：打通「已收 AR → 应收贷项待退款 → 客户现金退款」主路径。

对标已落地的 [供应商退款-主流程V1](../供应商退款-主流程V1/README.md)。不要按供应商退款完整设计（换日核销、一张退款核多张贷项等）扩大范围。

客户退款是资金流出，复用 `payments`：

```text
payment_type    = DISBURSEMENT
partner_type    = CUSTOMER
payment_purpose = CUSTOMER_REFUND
```

它核销应收贷项上由已收金额形成的 **待退款开放金额**。不 VOID 原收款，不处理客户退货，不回减交货占用。

## 主路径

```text
过账贷项（可超过 remaining，拆 applied / refundable）
  → 新建一张客户退款（一单核一张贷项，金额 = 本次退款）
  → 过账（银行凭证 + 回写贷项 + 必要时退款段汇兑）
  → 改错则整单 VOID 退款
```

## 相对完整能力砍掉的部分

与供应商退款 V1 相同：无行过账、一张退款核多张贷项、核销行状态机、单行 reverse、交叉货币、折扣比例转回。
