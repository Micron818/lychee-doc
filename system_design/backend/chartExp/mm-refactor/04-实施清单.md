# 04. 实施清单（开发入口）

> **不**加长 `materials.code`。分隔符锁定 `-`。尺码流水按款+色从 01 起，不挂尺码组。

| 波次 | 内容 | 单独上 |
|------|------|--------|
| A | 两条变体唯一索引 + 尺码组（只定序）+ 本款色（0 行=不分色）+ 款×色流水表 + 生成 | **可以** |
| B | 打印列序；copy-from 颜色 | 依赖 A |
| C | 复制工厂/图/BOM | 依赖 A |

---

## 1. 审查结论

| 问题 | 结论 |
|------|------|
| 扩 `materials.code` | **否** |
| 拼 `colors.code` / `product_sizes.code` | **否** |
| 公式 | `款号 + "-" + [色号A–Z?] + 流水01–99` |
| 无颜色 | 本款 0 行颜色；SKU 无字母；`materials.color_id` 为空 |
| 色号 | `product_model_colors.sku_code` |
| 尺码流水 | `product_model_size_codes`，作用域 **款+色（色可空）**，最小从 01 |
| 尺码组 | 只限制可选码 + 从小到大；**不**存流水 |
| 分类前缀 | **否** |
| 已有 SKU 重编码 | **否**（首次分配时懒占流水） |

## 2. 已锁定决策

| # | 决策 | 值 |
|---|------|-----|
| 1 | SKU 表 | `materials` |
| 2 | 区分色编码 | `{model}-{A}{01}` 例 `12345-A01` |
| 3 | 不分色编码 | `{model}-{01}` 例 `12345-01` |
| 4 | 分隔符 | `-`；色号与流水之间无第二分隔符 |
| 5 | 列长 | varchar(50)；区分色 +4、不分色 +3 超长则 OVERFLOW |
| 6 | 变体唯一 | 两条部分索引（有色 / 无色） |
| 7 | 流水分配 | 作用域内已有号保持；新码 max+1；该作用域全空则从 01 |
| 8 | 首次勾码 | 建议一次勾齐，保证当前最小=01；事后更小码不重排 01 |
| 9 | 尺码组 sku_code | **不建** |
| 10 | 本款 0 色 / ≥1 色 | 有完整变体后锁定（有色/无色分别看 `color_id`）；半填行不锁定 |
| 11 | 预览/生成 | 单事务；EXISTS 跳过物料；坏格或唯一冲突整批 400 |
| 12 | 批量 | NEW 1～200 |
| 13 | 单笔 | 与生成器同一套校验与流水；能拼公式才建议编码；无分类前缀 |
| 14 | token 不可变 | 流水行一旦写入不改不删（删物料也不释放）；有物料时禁止改色号字母 |
| 15 | 打印 | A 不改；B 用组内 sequence；跨款列并集按 sequence + size_id |
| 16 | 一款色 / 一色档 | 26 / 99 |
| 17 | 存量 | 不重编码、不一次性刷号；该作用域首次分配时按已有变体懒占流水 |
| 18 | 流水表唯一 | 四条部分索引（有色/无色 × size/sku），不用 `COALESCE(color_id, 0)` |
| 19 | 换尺码组 | 该款已有完整变体后禁止 |

## 3. 实现约定

### 3.1 预览 / 分配流水

```text
distinguish = (本款颜色行数 ≥ 1)
if distinguish:
    colorIds 非空且 ⊆ 本款
    scopes = 各 colorId
else:
    colorIds 必须空
    scopes = [null]

对每个 scope:
    已有流水 = product_model_size_codes where model + color=scope
    存量未占号 = 该 scope 已有物料的尺码 − 已有流水
    待编 = (存量未占号 ∪ 本次该 scope 勾选且无流水) 按组 sequence 升序
    next = max(已有流水) 或 0
    对待编：next++；拟号 = %02d
    // 存量未占号即使未勾选也要占号，否则新码会抢 01

code = model + "-" + (distinguish ? letter : "") + sizeSku
len 检查 → OVERFLOW
已有物料同变体 → EXISTS
已有物料同 code 不同变体 → CONFLICT
```

生成 / 单笔把拟号 **INSERT** 进 `product_model_size_codes`（已有则不改）。EXISTS 格不插物料，缺流水仍写占用。删除物料不删流水行；再生成同格复用该号。

### 3.2 单笔建议

```text
区分色且有字母且有/可分配流水 → `{model}-{A}{01}`
不分色且有流水 → `{model}-{01}`
否则不填
```

## 4. Wave A 改动面

DDL：两条部分唯一 + 尺码组 + 款色 + `product_model_size_codes`。  
服务：分配流水、preview/generate、手建撞车。  
前端：尺码组无流水列；款号本款色可空；向导两模式；表单建议 `12345-A01`。

单测至少：

- `12345` + A + 最小码 → `12345-A01`（不是 `12345A01`，不是组档 06）
- 不分色 → `12345-01`，`color_id` null
- 同款黑/白同一物理码都是各色的 01
- 先生成 40=01 再加更小码 → 新码 02，01 不变
- 款号 47 字区分色 OVERFLOW
- 该色已有 40（旧编码）再生成 41 → 40 占 01（不改旧 code）、41 为 02
- 删物料后再生成同格 → 复用原流水，不新分配
- 有色完整变体后禁止改不分色；仅挂款号无尺码不锁定

## 6. 验收

- [ ] `12345-A01` / `12345-B01`；主数据 code 不进 SKU  
- [ ] 不分色 `12345-01`，无字母  
- [ ] 同组另一款从自己的 01 起，不继承组档号  
- [ ] 本款有完整变体后不能从有色改成不分色（仅挂款号不锁定）  
- [ ] 事后插入更小码不重排已占用 01  
- [ ] 存量旧编码不重算；同色已有尺码先占流水  
- [ ] 删物料后再生成同格复用流水  
- [ ] 有色/无色两条唯一索引均拦重复（含流水表）  
- [ ] 表单不再建议分类+款号

## 7. 训练

成品：尺码组（只排大小）→ 款号绑组 → 有色则赋 A/B → 首次把该色尺码勾齐再生成。  
说明：编号里的 01 是「这一款这一色的最小码」，不是欧码 35。
