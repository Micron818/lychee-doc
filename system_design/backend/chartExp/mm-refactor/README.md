# MM 重构：款号 × 颜色 × 尺码 → 物料（SKU）

本目录描述如何把成品物料从「逐笔手建 / 复制再改」升级为规范 ERP 的 **变体生成（Variant Generation）**。

`materials` 仍是库存与单据唯一引用的 SKU。`product_models` / `colors` / `product_sizes` 仍是变体维度，不并进物料表。

尺码排序 Phase 1（`PrefixedCode`）只服务色卡/尺码主数据列表序，**不**拼进物料号。

```text
款号 ProductModel.code                    例 12345
  ├─ 可选：本款颜色 sku_code（1 位 A–Z）     黑→A  白→B     ≠ colors.code
  │     不区分颜色 → 无此字母
  ├─ 尺码流水（2 位 01–99）
  │     按「该款 + 该色（或不分色）」从最小码编 01
  │     ≠ product_sizes.code，≠ 尺码组档位号
  └─ 变体矩阵（可剔除格子）
        ▼
     区分颜色：12345-A01
     不分颜色：12345-01
     materials.code varchar(50) 不扩
```

| 波次 | 内容 | 对业务 |
|------|------|--------|
| **A** | 变体唯一 + 尺码组（只定可选码与从小到大顺序）+ 本款颜色（可空=不分色）+ 款×色尺码流水表 + 预览生成 | 编码与现场一致 |
| **B** | 打印列序用组内 `sequence`；从它款复制颜色 | 打印/录入 |
| **C** | 可选复制工厂物料 / 同色图 / BOM | 生成后少补资料 |
